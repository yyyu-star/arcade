# 难度和收益的配平（所有游戏共用）

> 2026-10-16 主线定，所有者要求：每个游戏都好玩、爱玩；拿筹码的时间期望和难度要平衡、逻辑清楚；小白在低难度下不能被电脑碾压，开盘不能又长又难又赚得少。
> 这份是**量化目标**，各游戏用自己的模拟器量出来写进自己的设计文档（德州 DESIGN、掼蛋 docs/stake.md 和 docs/ai.md、麻将 DESIGN、开盘的设计文档），PR 说明里贴对照表。
> 档位、每份多少、封顶仍以 [economy.md](economy.md) 第 2 节为准，这份只管"多难、多快、赚多少"。

## 1. 两个玩家模型（每个游戏的模拟器都要有）

| 模型 | 打法 | 用途 |
|---|---|---|
| **小白** | 只会最直白的打法，常犯错：德州 见牌就跟、偶尔乱加、不会弃好牌以外的牌；掼蛋 能出就出最小的、炸弹乱用、不记牌；麻将 打孤张、不防守、见碰就碰；开盘 追热门、不止损、不看消息真假 | 定"低难度够不够友好" |
| **普通** | economy.md 说的"简单合理的打法"：会看牌力、会弃、会留炸弹、会防守、会止损 | 定"认真玩能不能赚" |

模型写成确定性的机器人（带种子），不读隐藏信息；每个数字至少 2,000 场，报 均值 ± 2 倍标准误。

## 2. 实盘：每场期望（单位：份）

| 档位 | 小白 | 普通 | 电脑 |
|---|---|---|---|
| 小 | **+0.05 ～ +0.15**，赢的场次 ≥ 50% | **+0.20 ～ +0.40** | 最弱一档，偶尔犯错 |
| 中 | −0.05 ～ +0.05 | +0.10 ～ +0.20 | 普通 |
| 大 | −0.20 ～ −0.10 | 0 ～ +0.10 | 强 |
| 豪华 | ≤ −0.20 | −0.05 ～ +0.05 | 最强 |

- 仍守 economy.md 第 2 节第 1 条：一场最多输一份、最多赢 3 份、大多数场次在 ±1 份以内。
- **一场 15–25 分钟**（真人速度，按每个游戏的模拟器记的"每步耗时"估）。超过 25 分钟的要缩（开盘见第 4 节）。
- 由此每小时的期望大致对齐：小档普通玩家 **每小时 +0.6 ～ +1.2 份**，四个游戏互相差不超过一倍。每个游戏的设计文档写出"小档普通玩家每小时期望多少份"。

## 3. 娱乐：难度档（不挂筹码）

娱乐的难度档统一叫 **新手 / 普通 / 高手**（已有的档位改名或合并到这三档；想留更多档的放在"高手"之后）。

| 难度 | 小白的胜率 | 普通的胜率 |
|---|---|---|
| 新手 | **≥ 60%** | ≥ 75% |
| 普通 | 40–50% | 55–65% |
| 高手 | ≤ 30% | 40–50% |

"胜"按游戏定义写清楚：德州 打完 N 手筹码比上桌多；掼蛋 一场我方赢；麻将 一场结束分数为正；开盘 一局达成最终目标。

- 新手档的电脑要"看起来像人"地弱：少记牌、少配合、偶尔放水（德州 多跟注少诈唬；掼蛋 不拆炸弹压队友；麻将 不刻意防守），**不靠明显的蠢操作**。
- 第一次玩默认新手档；选档时每档一行说明：电脑多强（★）、一场多久、适合谁。

## 4. 开盘的特别要求

所有者原话："开盘需要花费很长时间，收益率却不高，难度还很高"。

- 实盘一局缩到 **15–25 分钟**：可以按月数、每月天数、或"快进"做，开盘自己定，设计文档写清楚为什么这样缩。
- 小档：小白结回倍数中位数 **≥ 1.0**，普通 **≥ 1.25**；破产（结回 0）的局小白 ≤ 15%、普通 ≤ 5%。往上按第 2 节逐档变难。
- 娱乐新手档：新手引导之后第一局，小白有 ≥ 60% 达成最终目标。

## 5. 给玩家看的（逻辑清楚）

各游戏的选档页每档一张卡，统一写三件事：**电脑多强**（1–4 颗星）、**一场约多久**、**一场最多赢 / 最多输**（实盘写筹码数）。文字和图标四个游戏一致。

## 6. 验收

- 每个游戏的 PR 贴一张表：第 2、3 节每一格的实测值（均值 ± 2SE）和目标区间，超出的写原因。
- 改数值只改电脑强弱、行情、计分系数，**不改规则本身**；规则核心的确定性和"电脑不看牌"的测试照样过。
- 主线汇总四个游戏的表进这份文档第 7 节。
