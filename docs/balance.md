# 难度和收益的配平（所有游戏共用）

> 目标：每个游戏都好玩、爱玩；拿筹码的时间期望和难度要平衡、逻辑清楚；小白在低难度下不能被电脑碾压，开盘不能又长又难又赚得少。
> 这份是**量化目标**，各游戏用自己的模拟器量出来写进自己的设计文档（德州 DESIGN、牌馆（掼蛋、斗地主）docs/stake.md 和 docs/ai.md、麻将 DESIGN、开盘的设计文档），PR 说明里贴对照表。
> 档位、每份多少、封顶仍以 [economy.md](economy.md) 第 2 节为准，这份只管"多难、多快、赚多少"。

## 1. 两个玩家模型（每个游戏的模拟器都要有）

| 模型 | 打法 | 用途 |
|---|---|---|
| **小白** | 只会最直白的打法，常犯错：德州 见牌就跟、偶尔乱加、不会弃好牌以外的牌；掼蛋 能出就出最小的、炸弹乱用、不记牌；斗地主 叫分凭感觉、领出最小的一手、能压就压、炸弹乱用；麻将 打孤张、不防守、见碰就碰；开盘 追热门、不止损、不看消息真假 | 定"低难度够不够友好" |
| **普通** | economy.md 说的"简单合理的打法"：会看牌力、会弃、会留炸弹、会防守、会止损 | 定"认真玩能不能赚" |

模型写成确定性的机器人（带种子），不读隐藏信息；每个数字至少 2,000 场，报 均值 ± 2 倍标准误。

## 2. 实盘：每场期望（单位：份）

| 档位 | 小白 | 普通 | 电脑 |
|---|---|---|---|
| 小 | **+0.05 ～ +0.15**，赢的场次 ≥ 50% | **+0.20 ～ +0.40** | 最弱一档，偶尔犯错 |
| 中 | −0.05 ～ +0.05 | +0.10 ～ +0.20 | 普通 |
| 大 | −0.20 ～ −0.10 | 0 ～ +0.10 | 强 |
| 豪华 | ≤ −0.20 | −0.05 ～ +0.05 | 最强 |

- 仍守 economy.md 第 2 节第 1 条：一场最多输一份、最多赢 3 份、大多数场次在 ±1 份以内。
- **一场 15–25 分钟**（真人速度，按每个游戏的模拟器记的"每步耗时"估）。超过 25 分钟的要缩（开盘见第 4 节）。
- 由此每小时的期望大致对齐：小档普通玩家 **每小时 +0.6 ～ +1.2 份**，各游戏互相差不超过一倍。每个游戏的设计文档写出"小档普通玩家每小时期望多少份"。

## 3. 娱乐：难度档（不挂筹码）

娱乐的难度档统一叫 **新手 / 普通 / 高手**（已有的档位改名或合并到这三档；想留更多档的放在"高手"之后）。

| 难度 | 小白的胜率 | 普通的胜率 |
|---|---|---|
| 新手 | **≥ 60%** | ≥ 75% |
| 普通 | 40–50% | 55–65% |
| 高手 | ≤ 30% | 40–50% |

"胜"按游戏定义写清楚：德州 打完 N 手筹码比上桌多；掼蛋 一场我方赢；麻将 一场结束分数为正；开盘 一局达成最终目标。

- 新手档的电脑要"看起来像人"地弱：少记牌、少配合、偶尔放水（德州 多跟注少诈唬；掼蛋 不拆炸弹压队友；麻将 不刻意防守），**不靠明显的蠢操作**。
- 第一次玩默认新手档；选档时每档一行说明：电脑多强（★）、一场多久、适合谁。

## 4. 开盘的特别要求

开盘要避免的问题：花费很长时间、收益率不高、难度还很高。

- 实盘一局缩到 **15–25 分钟**：可以按月数、每月天数、或"快进"做，开盘自己定，设计文档写清楚为什么这样缩。
- 小档：小白结回倍数中位数 **≥ 1.0**，普通 **≥ 1.25**；破产（结回 0）的局小白 ≤ 15%、普通 ≤ 5%。往上按第 2 节逐档变难。
- 娱乐新手档：新手引导之后第一局，小白有 ≥ 60% 达成最终目标。
### 4.1 杠杆：开盘是"高风险高回报"的那个游戏（要更刺激、真能赚到很多）

- 实盘开局选杠杆：**稳健 1× / 进取 2× / 疯狂 3×**（默认稳健）。结回 = 带入 × clamp(1 + 杠杆 × (倍数 − 1), 0, 封顶)，封顶依次 3 / 5 / 7 倍；**最多输一份不变**。
- 只放大不加代价的话，"输最多一份、赢跟着放大"会让期望一路涨；所以杠杆越高，**融资利息越高、爆仓线越近**：会玩的人杠杆越高赚得越多，小白开高杠杆更容易输光。
- 小档目标（每格 2,000 局；往上逐档变难）：

| 杠杆 | 普通每场 | 小白每场 | 普通 ≥3 倍的局 | 普通输光 |
|---|---|---|---|---|
| 1× | ≈ +0.30 | +0.05 ～ +0.15 | — | ≤ 5% |
| 2× | +0.40 ～ +0.50 | −0.05 ～ +0.05 | — | ≤ 15% |
| 3× | +0.55 ～ +0.70 | −0.25 ～ −0.10 | 10–20% | ≤ 25% |

- 这是第 2 节"每小时期望各游戏差不超过一倍"的**唯一例外**：开盘疯狂档的普通玩家每小时可以到 +2 份以上，代价是方差大。economy.md 第 2 节"一场最多赢 3 份"对开盘按杠杆的封顶放宽到 5 / 7 份。
- 每个游戏每天净赢的上限（economy.md 第 4 节，默认 10 份）照旧，管理页可调。

### 4.2 掼蛋：技巧差最大的游戏

掼蛋模拟里小白比普通每场少 0.45–0.55 份（四人两队、要配合、要记牌、炸弹时机），第 2、3 节两列的差装不下。取舍：

- **实盘小档、娱乐新手档按小白调**：小档小白 0 ～ +0.10 份/场，新手档小白胜率 ≥ 60%；这时普通在小档约 +0.5 份/场，超出第 2 节上限，接受（所有者要求低难度对小白友好）。
- **中、大、豪华档和娱乐普通、高手档按普通那列调**，小白那列照实写。
- 不用"输了打折"之类加规则、庄家多送的办法；也不把小白换成更聪明的机器人凑数。

### 4.3 夜巡：只管走位的动作游戏，小白和普通差得也大

夜巡没有电脑对手，难度是怪的多少和强弱，档位叫危险 0–5（第 3 节的新手 / 普通 / 高手对应危险 0 / 2 / 4，1、3、5 是中间档）。
4c 每格 500 局：危险 2 小白 27%、普通 57–76%（五个流派），两列差约 40 个点，第 3 节的两列装不下（小白主要死在躲不开）。取舍同掼蛋：

- **小白的主目标是危险 0 ≥ 60%**；危险 2 的小白放宽到 30–40%；高手档小白照第 3 节 ≤ 30%。
- **危险 2 只按普通查 55–65%**（五个流派各算一格，流派之间差 ≤ 20 个点）；危险 4 普通 40–50%。
- 帮小白靠危险 0 本身（怪少、怪弱、吸珠范围大、前几次升级先给法器）和"受伤补偿"：血低于四成时肉包掉率 ×3，补出来的肉包最多每 20 秒一个。
  规则确定、有上限，故意站着挨打不占便宜（机器人"站着挨打"的胜率远低于正常躲怪，有测试锁住）。不加"输了打折"之类的规则，也不换更聪明的机器人凑数。
- 实盘四档固定危险档：小 = 危险 0、中 = 危险 2、大 = 危险 3、豪华 = 危险 4，期望照第 2 节两列；按撑到的时间结回（3 分钟开始回本、10 分钟保本、天亮 1.8 份、打倒尸王 3 份）。
  实盘的期望不用第 2 节的表，用 4.4 的表。

### 4.4 夜巡是普通玩家每天拿筹码最有效的途径

夜巡定位成"每天的低保"：普通玩家打夜巡实盘，比打别的游戏更稳地攒到筹码。所以夜巡的实盘期望**不用第 2 节的表**，用下面这张（守夜、夜探同一张表）：

| 档位 | 小白 | 普通 |
|---|---|---|
| 小 | +0.15 ～ +0.30 | **+0.45 ～ +0.60** |
| 中 | 0 ～ +0.15 | +0.30 ～ +0.45 |
| 大 | −0.10 ～ 0 | +0.20 ～ +0.30 |
| 豪华（只有守夜） | −0.25 ～ −0.10 | +0.05 ～ +0.15 |

- 不变的：一场最多输一份、最多赢 3 份（economy.md 第 2 节）；天亮倍数随档位不降（游戏里单测锁着）；client 模式每个游戏每天净赢的上限照 economy.md 第 4 节（管理页可调），它就是"低保"的天花板。
- 档越高期望越低：让人愿意多打低档攒，少拿高档去赌。
- 于是小档普通玩家每小时约 +2 份，是别的游戏的两倍左右；第 2 节"各游戏互相差不超过一倍"对夜巡不适用。
- 夜探的档位对应的危险档可以和守夜不同（夜探更难撤出、方差更大），由夜巡按模拟定、主线批，写进夜巡 DESIGN 第 4 节。

## 5. 给玩家看的（逻辑清楚）

各游戏的选档页每档一张卡，统一写三件事：**电脑多强**（1–4 颗星）、**一场约多久**、**一场最多赢 / 最多输**（实盘写筹码数）。文字和图标各游戏一致。

## 6. 验收

- 每个游戏的 PR 贴一张表：第 2、3 节每一格的实测值（均值 ± 2SE）和目标区间，超出的写原因。
- 改数值只改电脑强弱、行情、计分系数，**不改规则本身**；规则核心的确定性和"电脑不看牌"的测试照样过。
- 主线汇总各游戏的表进这份文档第 7 节。
