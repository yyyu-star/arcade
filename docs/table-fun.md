# 牌桌互动规范（掼蛋、德州、麻将共用）

> 2026-10-16 主线定，所有者要求：三个牌桌游戏的互动行为对齐，好玩、有趣、互动性强。各游戏照这份做，做法不同的地方以这份为准；
> 游戏自己的 DESIGN 里只写本游戏特有的部分（短语、名场面），并链接到这里。素材和动画统一用 `arcade-kit/fun`（表情包 `STICKERS`、道具 `PROPS`），不各画一套。
> 底线不变：人人一样、免费，不挂筹码；只是画面和声音，不停计时、不改规则；电脑出牌不读这些；不转发任何隐藏信息。

## 1. 入口（三个游戏一模一样）

| 操作 | 结果 |
|---|---|
| 点别人的头像 | 头像旁弹出小菜单：第一行 8 个道具（kit `PROPS` 原顺序），第二行 3 句点名短语，最后一个「屏蔽他」。点道具立刻扔，菜单收起 |
| 点自己的头像 | 弹出表情包（kit `STICKERS` 12 个），点了在自己头像上冒 |
| 左下角常驻「互动」按钮（笑脸图标，≥44px） | 打开完整面板：短语 / 表情 / 道具三个页签；道具页先选人再选道具 |
| 首次进牌桌 | 对一个电脑头像冒一次提示气泡「点头像扔道具」，3 秒后消失；只出一次（`<游戏id>.hint.fun`） |

- 菜单和面板不盖自己的手牌和操作按钮；轮到自己时照样能点（不打断出牌）。
- 原来的「嘲讽」「聊」按钮并进「互动」按钮，名字统一叫「互动」。

## 2. 节奏和限额

- 每人扔道具冷却 1.5 秒，冷却中道具按钮转圈显示剩余；表情和短语冷却 1 秒。
- 同一个人 10 秒内最多被扔 6 次，多的这人头像上显示「护盾」一闪，不播（防刷屏）。
- 好友房由房间按同样数字限流（kit 已有 emote 转发，限额照 kit 的做法）。

## 3. 反馈（让扔东西"有手感"）

- 命中：被扔的头像抖一下 + 污渍（kit 处理），道具有自己的声音（`playFunSound`，跟静音开关）。
- **连击**：同一个人 3 秒内连续扔同一人，第 2 次起在目标头像上冒「×2」「×3」……（金色数字，放大弹一下）。
- **回敬**：被扔后 3 秒内扔回给扔你的人，道具上方冒「回敬！」。
- 玫瑰、点赞、干杯这三个善意道具：用 kit 现有的动画（花瓣飘落、星星、泡泡），不留脏污渍（玫瑰本身在头像上停一会儿）。

## 4. 电脑也会玩（单机的乐趣主要来自这里）

电脑的反应只在画面层，随机数用画面层自己的，不进规则核心、不影响出牌。

- **被扔时**：60% 在 0.8–2 秒后回一个反应：被扔脏东西 → 生气 / 流汗表情或一句短语；被送玫瑰 → 爱心表情；
  其中 25% 直接回敬一个道具（同类：番茄还番茄，鸡蛋还拖鞋）。同一个电脑 20 秒内最多回敬 2 次。
  电脑回应的间隔不能比扔道具的冷却长（否则连扔时回应被吞）：同一个电脑两次回应至少隔 1 秒即可（2026-10-16 德州、麻将都踩过 2.5 秒的坑）。
- **名场面**：本游戏的名场面（见各游戏 DESIGN：德州 全下赢、反超、诈唬被抓；掼蛋 炸弹、头游、双下；麻将 杠、杠上花、自摸、清一色），
  输的电脑 40% 扔一个道具或冒表情给赢家，赢的电脑 30% 冒得意表情。每手最多 2 次电脑主动互动，避免吵。
- **性格**：每个电脑人物有一个互动性格（爱闹 / 普通 / 高冷），爱闹的概率 ×1.5、高冷 ×0.3，写在人物表里。

## 5. 设置

设置里一个总开关「互动：开 / 不看」，面板里「全部屏蔽」，头像菜单里「屏蔽他」（真人、电脑都能屏蔽）。屏蔽只是自己不看。
key 一律带游戏前缀；按人屏蔽只对这一局 / 这个房间有效（sessionStorage）。

## 6. 验收

- 三个游戏点头像的菜单长得一样、位置规则一样（菜单在头像朝桌心那侧）；电脑在单机里会回敬、会在名场面扔东西。
- 冒烟里点一次别人头像扔一个道具、点一次自己头像发表情，控制台零报错。
- 只用 kit 的素材和动画；同时最多 4 个效果在播（kit `MAX_PLAYING`），低内存设备照样流畅。
