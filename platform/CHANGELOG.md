# 平台（platform）更新日志

更早的版本没有单独的更新日志：各版本做了什么，见 `docs/platform-backend.md` 各节里的版本标注。

## 0.10.25

界面改版第一步：主题、按钮、对齐（不加新素材，线上接口和数据不变）。
- 颜色、间距（4/8 的倍数）、字号、圆角、阴影收进 `styles.css` 开头的变量，组件只用变量；样式表按组件重新整理，删掉按版本堆叠、互相覆盖的规则。
- 一套按钮：次要（白）、主要（橙）、危险（红）；悬停抬起、按下压下去、键盘焦点有蓝框、禁用变灰（以前是半透明，橙按钮看着像还能点）、
  忙的时候前面一个小圈在转（`aria-busy`）。能点的东西至少 44 px 高。
- 登录/注册、哪个榜、全部/好友、哪个游戏这三种切换统一成一个样子（同样高、选中都是橙底白字）。
- 手机竖屏的顶栏不再横着溢出：放到标题上面一行，头像只露头像（昵称留给读屏），管理员多一个"管理"也放得下；排行榜的标签不再折行。
- 大厅的提醒和公告与卡片网格一样宽，账号这些页面的横幅与中间那一栏一样宽。
- 管理页：今日概况五个数排成 3+2，不剩一个孤零零的；宽表格手机上横着滑，右沿有阴影提示还有列；钱包页、账号页的数字等宽、行对齐。
- 浅底上的橙色字（链接、恢复码、好友码）换成深一点的橙，看得清；`viewport-fit=cover`，四边让出刘海。
- 不用钱包的游戏在 `games.ts` 写 `wallet: false`（飞驰）：排行榜"本周净赢"不再给它一个总是空的标签，管理页的筹码趋势不给它列。接口的白名单不变。

## 0.10.24

- 《飞驰》上线：大厅卡片从"即将上线"改成能玩，有"进入游戏"和"好友房"（`?online=1`）。游戏 0.1.0 部署后在线上验证过：没登录跳登录页，单机跑完一局，好友房开房、进房、开跑。

## 0.10.23

- 登录、注册、找回等表单遇到 429（太频繁）时一定说"太频繁"：网关限速回的不是我们的 JSON，以前被说成"连不上服务器，过一会儿再试"，
  现在说"试得太频繁了，稍等一会儿再来"，响应头有 `Retry-After` 就写多久后再试（秒数和日期都认）。平台自己的 429 照旧用服务端的说法加时间。
- 出错后按钮照样恢复能点；5xx、网关出错页、断网也都各有一句话（加了单测，冒烟在登录页模拟了一遍这几种）。

- 大厅登记《飞驰》（`racing`，回合制卡牌赛车，外部贡献者的游戏）：先是"即将上线"（卡片只有"敬请期待"），游戏上线后再改成能玩；好友房入口按 `?online=1` 写好，上线后才露。

## 0.10.21

- 删掉 `tools/deploy-config.ts`（和 `.gitignore` 里它生成的 `wrangler.deploy.json`）：正式部署改由仓库级的部署程序 `tools/deployer` 从审过的 `wrangler.jsonc` 生成最终配置，平台这份不用了。
- README 的部署一节改写：本仓库的正式站只由 `main` 上的 GitHub Actions 部署（`production` 要维护者批准）；fork 后自己部署整站照仓库根 README；Deploy to Cloudflare 按钮只部署平台本身。
- 线上行为不变。

## 0.10.20

开源整改，线上行为不变（同一个域名、同一个库）：
- 仓库里不再写正式站的域名和 D1 的 id。正式部署时由工作流从 GitHub `production` 环境的 secret 注入：
  域名用 `--domain` 挂成自定义域名，`SITE_ORIGIN` 用 `--var` 注入；D1 的 id 由 `tools/deploy-config.ts` 写进一份不进 Git 的部署配置，迁移和部署都用它。
  id 没设或不像 id 时直接失败，不会让 wrangler 自动新建空库。
- `SITE_ORIGIN` 改成可选：设了照旧只认这个主机名；没设（一键部署）按请求自己的地址，写请求的同站检查照样挡得住跨站。
- 支持 Deploy to Cloudflare 一键部署：`.dev.vars.example` 列全 Secret 并写明说明，`package.json` 加 `cloudflare.bindings` 说明，
  `npm run deploy` 先跑 D1 迁移再部署；部署后绑自定义域名、建第一个管理员的步骤写在 README。
- 管理命令行工具（`npm run admin`）不再有默认地址，必须用 `--base` 或环境变量 `ARCADE_BASE_URL` 给。
- 恢复码图片上的站点地址改成当前页面的地址（`location.host`）。
- 测试里的域名换成 `game.example.com`；文档和注释去掉内部分工的说法；`package.json` 加 `"license": "MIT"`。
- 搬家前旧仓库的 PR 编号不再写成 `#NN`（公开仓库里会被链接到同号的无关 PR）：能靠版本号说清的删掉，其余写成"旧仓库 PR NN"。
