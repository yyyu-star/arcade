# 平台配色表（卡通风格，0.25.2）

变量都在 `src/styles.css` 的 `:root`，界面里不写死颜色。

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面底（奶油） | `--paper` / 顶部渐到 `#ffe9c7` | `#fdf6e8` |
| 卡片、面板底 | `--surface` | `#fffaf0` |
| 描边、阴影、正文 | `--line` / `--ink` | `#2b1d14`（深棕，2–3px 描边） |
| 次要文字 | `--muted` | `#74646a` |
| 主色（按钮平涂、标题字） | `--accent-deep` / `--accent` | `#e0601f` / `#f07a3a` |
| 提示条、高亮行 | `--highlight` / `--highlight-warm` | `#fff3c4` / `#fff3d6` |
| 赢 / 输 | `--good` / `--bad` | `#2f7a3a` / `#b4232d` |

形状：圆角 12（按钮、小卡片）/ 16（大卡片）；按钮下沿实色阴影 4px（小按钮 3px），按下下沉；大卡片斜向阴影 4px。
