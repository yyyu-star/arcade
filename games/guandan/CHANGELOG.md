# 更新日志

## 0.8.2（2026-10-16）

单机娱乐的难度多一档"较强"，排在普通和困难之间。原来普通（普通玩家胜率 76%）和困难（47%）之间断了一大截。
- **较强**：搭档、对手都是普通电脑，普通玩家胜率约 57%（`ai-sim solo`，docs/ai.md 第 2 节）。设置面板的难度改成四档：简单、普通、较强、困难；默认仍是普通。
- **兼容旧值**：本机设置、存档里的难度只认这四档；旧版本存的三档照用，认不得的（以后的版本存的、手改坏的）按普通，别的设置不丢。URL 参数 `difficulty=good` 也认。

## 0.8.1（2026-10-16）

电脑不看牌：做法写清楚，检查写进测试，谁都能自己跑（README"电脑不看牌"一节）。打法没有变化，只是同一个种子下电脑的随机选择换了一套。
- **单机电脑不再拿牌局种子**：出牌的随机流、这一场的状态、"提示"排序都改用按用途从种子派生的数（`session.ts` 的 `soloSeeds`），和好友房的 `aiSeed`、`formSeed` 一个做法；
  种子能重算发牌，电脑手里没有它，才说得清没借此看牌。调试跳转（`jump.ts`）和试玩日志复盘工具同样改了。
- **反事实测试**（`tests/ai.test.ts`）：每个要做决定的时刻，保持这个座位看得到的一切不变，把另外三家没亮出来的牌重新分一遍，电脑的决定必须一次都不变。
  单机（娱乐三档、实盘豪华档）496 个决策点、好友房（`guandanRoom.ai`，带性格的电脑和替真人代打）345 个，0 不一致；两个故意偷看的电脑作阳性对照，同样的方法抓得出来。
- **架构测试**：`src/ai` 不准引用完整牌局状态 `GameState`，不准出现发牌、首出的随机流名 `'deal'`、`'firstLead'`。
- **单独部署打开页面不再冒红字**：共用包升到 0.10.2，`/api/me` 也先进 Worker，没有平台时由 kit 回 `{ standalone: true }`（原来落到静态资源的 404，控制台有一条报错）。

## 0.7.1（2026-10-16）

互动全覆盖：单机对电脑也能嘲讽、发表情、扔道具，电脑会回、会催；好友房里的电脑也会互动。
- **单机也有互动面板**：和好友房同一套（嘲讽 / 表情 / 道具三个页签，点头像对他扔道具、点名嘲讽、屏蔽他），对象是电脑。
- **电脑会互动**（按性格和这一场的状态）：炸了人显摆、被炸了不服、头游得意、队友漂亮时捧一句、双下时庆祝或认怂；被扔东西、被点名时回怼、装没看见或认怂——阿强基本都扔回去，小美多半不理；
  你想太久，最没耐心的那个会催（阿强扔个催促炸弹，小美做队友时说"别急，慢慢想"）。只看公开的事，同一个电脑隔一会儿才发一次，不刷屏。
- **好友房的电脑也会说话**：和单机一样按性格显摆、不服、回怼你扔的东西、点名；只看公开的事，等出牌画面播完才冒出来。好友房里电脑不催人，真人之间照旧能扔催促炸弹。
- **名场面**：炸上炸当场冒一句；结算页的复盘多一行"名场面"（落后 3 级打出双下、天王炸、炸上炸、一副炸三次、几手出完）。
- **单机轮到你**：手机振一下；切到别的标签页时标题闪"轮到你了"。
- **屏蔽**：面板里多了"全部屏蔽"；设置里"嘲讽和道具：不看"在单机里也管用（电脑一句也不发）。
- 修：页面还没被点过时不再调用振动（Chrome 会在控制台报错）。
- 公平照旧：互动免费、人人一样，不挂筹码，不停、不延长计时，不挡牌和按钮；电脑出牌完全不看你发了什么。

## 0.7.0（2026-10-16）

电脑重新训练：按场地分强弱，三个电脑有了性格和状态（设计和模拟见 `docs/ai.md`）。
- **新手场不吓人**：单机娱乐默认的"普通"对手换成简单的电脑（普通水平的玩家每场期望 +0.29 份、胜率约四分之三）；"简单"的对手是新手，对手快走完时常常手软；"困难"四个都是最强。
- **好友房实盘**：电脑照旧一律最强（真人之间可以互通配合，最强更稳），现在也带性格；模拟里两个普通水平的真人搭档对困难的电脑每人每场期望为负（对普通电脑能小赚），写在 `docs/ai.md` 作佐证。
- **单机实盘**：小档对手简单、中档对手较强（新加的一档，介于普通和困难之间）、大档对手困难、豪华档搭档简单对手困难；每档期望写在 `docs/stake.md` 1.3，每小时期望和以前相差不到 0.2 份。
- **性格**：老张爱炸、炸得早，小美捂着炸弹、不乱抢、细心，阿强什么都想压、急、输了上头；越强的电脑性格露得越少。
- **每场的状态**：每一场开局抽一次手热或手冷（每副再抖一下），同一个人这场放开打、下场收着打；落后多了就拼、领先多了就稳，这一副对手炸得多就早点防。
- **说话和节奏跟着性格**：开场按状态说"今天手气旺"或"手有点生"，落后、领先、上头各有台词，同一句不连着说；老张出手爽快、小美想得细、阿强最快（上头更快），要紧的一手多想一会儿。
- **好友房里电脑的名字按真实座位**：同一个电脑在每个人屏幕上叫同一个名字，名字、打法、口吻对得上。
- 电脑照旧只看自己的牌和公开信息，同一个种子同一串操作结果完全一样；单次决策的耗时和没性格时一样。

## 0.6.4（2026-10-15）

收尾自查发现的三处：
- **连回来自动恢复**：掉线时被代出的那几手也算"走开了"，以前重连回来还得点一下"我回来了"；现在一连上（断线重连、刷新页面）就自动恢复 30 秒。
  人一直连着、只是走开的照旧要自己点。
- **屏蔽跟人走**：点头像"屏蔽他"以前记的是座位，被屏蔽的人走了、别人来接管这个座位，新来的人也被屏蔽着；现在记"座位 + 名字"，换了人就不算。
- 机器忙时偶发超时的两个测试时限放宽（下一副预告的单测、联机冒烟打开页面），不影响游戏。

## 0.6.0（2026-10-15）

好友房更好玩、更顺手（目标：更有趣、更欢乐；联机体验要顺，不设没必要的限制）。表情包和道具来自 arcade-kit 0.7.0 的 `arcade-kit/fun`。

**嘲讽系统**（人人一样、免费，不能买、不挂筹码，只是画面和声音）

- 聊天按钮（或者点自己的头像）打开面板，三个页签：**嘲讽**（原来 8 句客气话 + 12 句只说牌局的嘲讽，比如"就这？""炸弹准备好了""等得花都谢了"）、**表情**（12 个自绘表情包）、**道具**（番茄、鸡蛋、臭鸡蛋、拖鞋、炸弹、玫瑰、点赞、干杯 8 样，选好扔给谁）。
- 点别人的头像：直接对他扔道具、点名嘲讽，或者"屏蔽他"（只对这一局）。道具从扔的人头像飞出去，砸中有各自的效果（番茄糊一片、鸡蛋流黄、炸弹熏黑……），被砸的头像抖一下。
- **催促炸弹**：轮到谁想了 8 秒以上，他头像旁冒出一个小炸弹，别人一点就扔过去（引信嘶嘶、一声爆炸、头像熏黑）。只是画面和声音，不缩短他的时间。
- **顺手提示**：我炸了对手、对手炸了我们、有人拿头游时，聊天按钮旁冒 1–2 句合适的嘲讽，一点就发，6 秒后自己收起。只看公开的出牌。
- **称号**：每副结算页写这一副的称号（炸弹狂魔、最佳搭档、背锅侠、忍者），整局结束页写整局的（头游王、炸弹狂魔、背锅侠、最佳搭档）。只用公开的出牌和名次。
- 嘲讽的气泡是红边的，和平常说话分得开。设置里有"嘲讽和道具：看 / 不看"总开关（不看时也不冒提示和催促炸弹，客气话照常显示）。
- 发得快了不提示、不丢：每人每秒 1 个、能攒 3 个，多的自动排队（房间的限速在 KIT_QUOTA 里可调）。

**声音**

- 轮到我：一声清楚的"叮"，手机上振一下；页面在后台时标题闪"【轮到你了】"，切回来就停。
- 我的最后 5 秒：每秒"嗒"一声，最后 2 秒每半秒一声、更高更急。
- 嘲讽、表情、每样道具各有自己的声音，都跟着静音设置。

**好友房更顺**

- **叫朋友来**：房间里一个大按钮，手机上弹系统分享（微信、短信……），电脑上复制链接 `/games/guandan/?room=房间码`。朋友点开链接直接进房；没登录的先去登录，登录完回到这个房间（平台登录页的 `next`）。
- **点开链接自动坐下**：等人时坐第一个空位，开打了自动接管电脑的座位，不用再找"坐这里"。实盘房间坐下要从钱包带入，仍由自己点。
- **开房不再受限**：每人同时 5 个房间、每天 100 个（原来 1 个、6 个）；"开个房间"永远开新的，不再提示"你已经有一个房间了，先回去"。
- **离开马上结算**：实盘房间点"离开"，按这一刻的分马上结回钱包，之后电脑接着打、输赢不再算你的（原来要等整场打完）。
  走了又回来：用新的一份重新带入（钱包里按 ref 分开），到账以后打完的副算这一份，离开时照常结回。带入被拒时实盘条旁边有"重新带入"，原因写成大白话。
- **没真人就结束**：房间里的真人都点了"离开"，这一局马上结束、还开房名额，结完回再关房（原来电脑会一直打到房间超时）。
- 所有会碰到的限制盘点了一遍，留下的写在 README"好友房里会碰到的限制"，每一条都有一句大白话。
- 没登录时去登录（打开页面被闸门拦下、云朵、开房、进房被拒）一律带 `next`，登录完回到原来那一页、查询原样带回（平台 0.10.1）。

**钱包和平台的错误说人话**（平台 0.10.2 的错误码对照表，docs/platform-backend.md 15.10）

- 实盘的每种错误都写清楚出了什么事、怎么办（比如"钱包里的筹码不够这一档，换小一点的档，或者去大厅领补给""今天开局太多了，明早 0 点恢复；桌上的照常结回"），不再有"钱包暂时忙""服务器有点忙"这种笼统的话。
- 别的设备上还有一场单机实盘没打完，不再挡着开新的（平台 0.9.5 起同一个游戏能同时有好几份），只是给个"原样退回那一份"。
- 开房没成功、登录确认不了时也说清楚是怎么回事、该怎么做。

**战绩**（平台 0.10.0）

- 实盘结回时带上这一份的小结给平台的战绩页：打了几副、赢了几副（本队升级）、最大一副赢多少筹码、拿到的称号，外加炸弹、头游的累计次数。单机经 `/api/stake/settle` 原样转发，好友房随结回走钱包 RPC；中途离开的按离开那一刻的。
- 称号的名字放在 `/games/guandan/titles.json`（平台的称号墙读），id 只往后加、不改。

**另外优化的 5 件事**

1. 电脑（简单、普通）偶尔犯错时，不再拆自己的炸弹，也不再去压队友的牌（以前约每两副一次拆炸弹、每五副一次压队友）。
2. 对手快出完时，电脑手里有炸弹就直接炸，不再拆了炸弹去出一张大牌（困难档每 2000 副从 315 次降到 111 次，剩下的多是逢人配凑的炸弹）。犯错少了以后按原来的强弱重调了失误率：简单对普通胜率约 25%，困难对普通约 73%。
3. 嘲讽和平常说话的气泡分开：嘲讽红边淡红底，一眼看出是在逗人。
4. 点自己的头像也能打开嘲讽面板（手机上比聊天小按钮好点）。
5. 表情、道具的图进了好友房才烘焙，单机不多占内存；道具动画在单独的图层上、点击穿透，弹窗打开时藏起来，不挡牌和按钮。
