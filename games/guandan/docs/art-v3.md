# 掼蛋 美术与界面打磨 v3（方案，待主线审）

> 2026-10-17。所有者原话：界面粗糙、"就是一个简单的扑克游戏，不是一个好玩的"、要先精心准备。本文是第一步：审计、对标、方向、进入流程、拆分。
> 审过以后按第 7 节分 PR 做；每个 PR 附改前改后 1280 / 1920 / 手机截图，冒烟零报错，规则核心不动。
> 改前截图：本机 `.local/qa/guandan/art-v3/before/`（不进仓库），由 `npm run shot -- --gallery --out <目录>` 生成（本 PR 加的，三种尺寸 × 12 个画面 + 手机竖屏，改后照同一命令再截一套对比）。

## 0. 结论先说

掼蛋现在的问题不是"没美术"（人物、牌面、木框、印章都是自己画的，质量不差），而是**排版没跟着屏幕走、层次太平、关键时刻没有戏**：

1. **宽屏不铺开**：标题页主视觉是一张定宽的图，1920 下在 x≈1215 处被硬切，右边一整块深色空底；牌桌 1920 下手牌靠左、右侧空 40%，按钮、头像、顶栏都没跟着放大。
2. **层级扁平**：牌桌顶栏 14 个元素一样大一样重；操作条悬在桌子中间、和手牌分开；结算卡战况 5 行红黑混排没分组。
3. **两套样式**：画布里是木纹、缎带、金边，好友房面板、分享预览、竖屏提示是 DOM 的扁平小按钮，字号也小一截。
4. **进入就是菜单**：标题页 = 标题字 + 四个竖排按钮，没有"这是个热闹牌局"的感觉；选模式、选难度是两层小弹窗。
5. **空状态和细节**：新账号战绩 0/0、"—" 没引导；版本号、云朵图标、规则示例牌太小。

方向：保留现有人物和红金 + 墨绿的基调，做成**"老茶馆夜局"**——暖灯、木桌、绒布、热闹的四个人。重点投在进入主页（所有者第一眼）、牌桌分层和网格、关键时刻的戏。

## 1. 现状审计

截图三种尺寸：1280×720（dpr 1）、1920×1080（dpr 1）、844×390（手机横屏 dpr 2，触屏），外加 390×844 竖屏。下面"位置"按截图坐标。

### 1.1 进入页（标题页，`01-title`）
- 1920：主视觉（圆窗、灯笼、四个人、桌子）是定宽图，x≈1215 处硬切，右侧是纯深色底，接缝最扎眼。844 同样在 x≈1055 有接缝。
- 1920：标题字和按钮挤在右栏中间，约 35% 宽度是空的；左上"大厅""好友房"和右上云朵相对画面偏小。
- 按钮是四个一样宽的竖排（开始 / 规则 / 设置 / 战绩），"开始"之外没有内容：看不到模式、难度、战绩、上局进度。有存档时变成 5 个按钮加一行小字，1280 下底部只剩约 80px。
- 动效只有飘金粉和 logo 上下浮，人物是静的；版本号几乎看不见；云朵图标无文字，语义不明。

### 1.2 选模式 / 选难度（`02-mode`、`03-level`）
- 两层小弹窗：先选娱乐 / 实盘，再选难度。1920 下弹窗只占中间一小块，四周空；娱乐、实盘两张卡说明行数不同、上下留白不对称。
- 选难度三行的"电脑 ★☆☆☆""一局约 20 分钟"字号偏小；三个"开始"一模一样，没有推荐项。844 下是最挤的画面之一。
- 弹窗盖不住标题字上沿，背后露着一截"掼蛋"。

### 1.3 牌桌（`04-table-myturn`、`05-table-played`）
- 背景只有一层：木框 + 墨绿绒面 + 极淡的"掼"字水印，没有远景和灯光；宽屏时桌面大片空绿。
- 顶栏 14 个元素（大厅、我方、对方、云朵、本副打、双方的级、第几副、1234 名次、规则、设置、声音、返回）同一高度同一分量，主次不分；844 下顶栏约占 1/6 高度。
- 操作条（按牌型 / 不要 / 提示 / 出牌 / 重选 / 上一墩）悬在桌子中线附近，和手牌之间隔着一大块空绿；1920 下分成左中右三段、中间空档很大，按钮相对屏幕偏小。
- 手牌按列从左排起，1920 下右侧约 40% 是空的；1280 下叠得重，每列只露一个角。
- 左下角"我的头像 + 互动 + 按牌型"挤成一团，大小不一；"轮到你：压过它，或者不要"提示条和出牌区、操作条贴得很近。
- 记牌器（大小 A…2 剩几张）位置好，但是一块平的深色条。
- 注：1920 的 `05-table-played` 截在发牌动画中间（手牌是牌背），改后对比时要截定稿时刻。

### 1.4 一副结算、整局结束（`06-settle`、`07-gameover`）
- 结算卡：左边四个名次条清楚；右边升级和进贡之间留白过大；战况 5 行（炸弹、最大一炸、名场面、称号…）红黑混排、没分组，844 下压在卡底、行距紧。
- 名次印章半透明叠在头像上，辨认不清。
- 整局结束：纸屑挡住顶栏；字号层级对比小；新账号"战绩 0/0 胜率 0%"突兀，没有空状态；分享只有一个小图标，最不显眼。
- 1920 下两张卡都只占中间约 60%，四周空。

### 1.5 分享预览（`08-share-preview`，kit 的组件）
- 白色扁平圆角按钮和游戏的木纹风格不一致；844 下说明文字压在背后结算卡的按钮上，最乱。这部分是 kit 的 DOM，风格统一要在 kit 加一个可选的主题参数（见 7.6），掼蛋这边不自己改 kit 的 DOM。

### 1.6 设置、规则、战绩（`09`–`11`）
- 三个弹窗宽度各不相同；设置在 1920 下撑到约 95% 宽而内容只在左上，844 下行距过大。
- 设置两栏高度不齐，"能 / 不能"比别的选项窄，"重看引导"是木纹按钮、和其余选项风格不同。
- 规则：牌型示例牌太小（三连对、钢板几乎看不清），页签选中态不明显，底部空约 120px。
- 战绩：6 格里多是 0 和"—"，没有空状态引导。

### 1.7 好友房面板（`12-online`，DOM）
- 字体、按钮、输入框是另一套扁平样式，字号小；1920 下只占约 28% 宽；关闭是底部宽按钮，和画布弹窗的右上 ✕ 不统一。

### 1.8 手机竖屏（`390-13-portrait`）
- 纯绿渐变 + 手机图标 + 两行字，上下各空 1/3，和木纹红金的主风格不一致，偏简陋。

### 1.9 静态截图看不到、要录屏再看的
发牌、出牌飞入、炸弹震屏、头游印章、升级、进贡的动效节奏；这些在 PR ④ 前用 `--playtest` 录一遍再定。

## 3. 美术方向

**一句话**：灯下的老茶馆夜局——暖黄的灯、红漆木桌、墨绿绒布，四个熟面孔围坐，热闹但不吵。

**色板（沿用 `theme.ts` 的 COLOR，收成 7 个主色，别的只做明暗变体）**

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 漆红 | #B3202A | 主按钮、我方、大标题 |
| 金 | #E0B45A | 描边、高光、强调数字、选中 |
| 墨绿绒 | #1F5A43 | 桌面 |
| 胡桃木 | #6B3B1F（暗 #3E2110） | 桌框、次按钮、面板边 |
| 象牙纸 | #FBF1DC | 弹窗、卡片底、牌面 |
| 墨 | #2B1D14 | 正文字、深底 |
| 青蓝 | #3A78C8 | 对方队色（只做队色，不做装饰） |

**字体层级**（世界坐标高 720；手机横屏约 0.54 倍）：标题用内嵌的思源宋体子集（60–96）；大数字用粗黑体（40–68）；正文 23、标签 20、最小 18（手机约 10 CSS 像素，不再往下）。一个画面最多三级字号。

**材质**：桌框是红漆胡桃木（现有的 feTurbulence 木纹，加一道漆面高光）；桌面是绒布（细噪点 + 中心亮四周暗的灯光圈）；面板是象牙纸 + 金边 + 胡桃木缎带标题；按钮保持现有的立体按钮（`ui/kit.ts`），只统一尺寸档位。

**主视觉怎么画**：全部继续用程序生成的 SVG（`src/view/art/`），不引外部图片；来源照旧写在 README"素材"一节。新增的分层背景（远景屋檐、窗格、灯笼、桌面）各自一张，按世界宽度烘焙，宽屏时远景层左右延展、不再硬切。

**网格**：8px 基准（`theme.ts` 的 `SPACE` 已经是 4 的倍数，改成以 8 为主），左右安全边 24，面板内边距 24，组间距 16，组内 8。所有画面按"顶栏 / 主区 / 操作区"三段排，宽屏多出来的宽度给主区，不给空边。

## 4. 进入流程（新主页）

现在：标题页 = 标题字 + 开始 / 规则 / 设置 / 战绩 → 点开始 → 弹窗选娱乐 / 实盘 → 弹窗选难度 → 牌桌。

改成：

```
主页（一屏，不弹窗）
├─ 左（约 55%）：分层主视觉
│    远景：屋檐、圆窗格、两盏灯笼（轻摆）、暖光（呼吸）
│    中景：四个人（待机：眨眼、小美扇子、阿强挠头，随机错开）
│    前景：桌角、茶杯热气、几张牌
├─ 右（约 45%）：
│    标题"掼蛋" + 一句玩法（"两两搭档，先把牌出完、先打过 A 的一队赢"）
│    主按钮：继续上局（有存档时，带"第 3 副 · 我方 5 对方 4"）或 快速开始（按上次的模式和难度直接开）
│    三张模式卡：娱乐（选难度）、实盘（选档，带钱包余额）、好友房（开房 / 输码）
│    战绩小卡：胜率、连胜、头游次数；新账号写"打完第一局这里会记下你的战绩"
└─ 顶角：左上大厅（不变），右上 规则 / 设置 / 云存档（图标 + 短字）
```

- 点模式卡进**选档页**（同一场景切换，不是弹窗）：娱乐是三张难度卡（新手 / 普通 / 高手，标"推荐"），实盘是档位卡（档位、带入、电脑是谁）；有返回箭头。
- 快速开始：第一次没有"上次"，等于娱乐新手。
- 手机横屏：主视觉缩到左 45%，人物只留上半身；模式卡变成一行三张小卡；战绩小卡收进右上图标。
- 单独部署（没平台）：没有实盘卡和云存档，好友房卡照常。
- 省内存设备（`guandan.boot` 降过档、iOS 1 倍渲染）：人物待机和灯笼摆动关掉，只留一张静图。

## 5. 牌桌 / 对局

**背景分三层**：远景（桌框外的暗室和两侧灯笼的光，宽屏时露出来，不再只是木框）、桌面（绒布 + 正上方一盏灯的光圈，中心亮四周暗）、桌上（淡水印"掼"和回纹圈，比现在再淡、更小）。三层都按世界宽度烘焙一次，不逐帧画。

**统一网格**（8px）：
- 顶栏分三组：左"大厅"；中"本副打 2"大字 + 两队的级（我方 / 对方）；右 图标组（规则、设置、声音、返回）。名次 1234 和第几副收进中组的小字；云存档挪到设置里。高度 1280 下 56（现 ~64），手机下 44。
- 四个座位对齐到同一组锚点：头像、名字、剩余张数一律"头像 + 右下角数字"同一个部件；对家在上中，左右两家垂直居中。
- 操作条**贴在手牌正上方、居中**，提示条在操作条上一行；"按牌型"挪到手牌左端，"重选 / 上一墩"挪到右端，和主按钮分开一个组距。
- 手牌**整体居中**（现在靠左排）；1920 下按宽度放大牌（列宽随世界宽度增大，每列最多 5 张不变，手机上逐张点得中这条测试照守）。
- 记牌器改成纸签样式，放在对家右侧。

**质感**：牌加一层很浅的投影和边缘高光；选中抬起时投影加深；出牌区的牌稍微有角度散开（现在是一排平铺）。

**关键时刻**（音效配现有合成音，不加文件）：
- 发牌：从桌心向四家扇形飞出，有节奏的"唰唰"；
- 炸弹：现有震屏 + 大字，按炸弹大小分三档（四炸 / 五六炸 / 同花顺和天王炸），大炸加光圈和纸屑；
- 头游：金色印章盖在头像上（不透明，换掉现在半透明叠头像）；双下：两张印章同时落；
- 结算：分数和级数滚动、升级时级牌翻过去；进贡用牌从一家飞到另一家。
- 所有动效走 `anim.ts` 的 `dur()`（设置里的速度、`anim=0` 冒烟），省内存模式关掉装饰粒子。

## 6. 电脑和手机

- 电脑（宽 1280–1720 的世界坐标）：多出的宽度给主区（牌桌放大手牌、主页放大主视觉），不是空边；1920 下控件和字号跟着世界缩放（现在已经是按高度缩放，问题在于内容按 1280 排死，没用上多出的宽度）。
- 手机横屏：顶栏 44、手牌区约 40% 高度、操作条最小点按 44 CSS 像素（`minHit` 照守）。
- 手机竖屏：现在是绿色提示页；改成主页的竖版（主视觉在上、模式卡在下，可以看、可以选好模式），只有进牌桌时才提示横过来，提示页换成木纹红金风格。

## 7. 拆分计划（每个 PR 能单独上线）

| PR | 内容 | 主要文件 | 怎么验 |
|---|---|---|---|
| ① 主页 | 新主页（第 4 节）：分层主视觉、宽屏延展、继续 / 快速开始、三张模式卡、战绩小卡、选档页替代两层弹窗；竖屏主页 | `scenes/TitleScene.ts`、`art/scene.ts`、`ui/stake.ts` | gallery 三尺寸；冒烟里"开始"的路径改成点模式卡；`mem.ts` 看新纹理 |
| ② 牌桌背景和布局 | 三层背景、顶栏分组、座位锚点、操作条贴手牌、手牌居中、宽屏放大 | `art/scene.ts`、`scenes/TableScene.ts`、`table/*` | gallery；手机逐张点手牌；`checkHits` |
| ③ 弹窗统一 | 设置 / 规则 / 战绩同宽同结构、空状态、规则示例牌放大、好友房 DOM 面板换成同一套样式（`THEME_CSS`） | `ui/panels.ts`、`online.ts`、`theme.ts` | gallery；online-smoke |
| ④ 结算和关键时刻 | 结算分组和滚动、印章、整局结束空状态和分享按钮放大；发牌、炸弹三档、头游、双下、进贡的动效 | `scenes/TableScene.ts`、`recap.ts`、`highlights.ts` | `--playtest` 录一遍；冒烟 gameover |
| ⑤（可选）细节 | 牌面质感、出牌散开、记牌器纸签、竖屏提示页 | `art/cards.ts` 等 | gallery |

- 顺序：① → ② 先做（所有者最先看到），③④ 之后，⑤ 看时间。
- 每个 PR：版本号 + CHANGELOG；规则核心（`src/core`、`src/ai`）不动；`npm test`、`test:room`、构建、相关冒烟零报错；`node tools/mem.ts` 对比手机内存不涨（背景按世界宽度烘焙一次、省内存模式关动效）。
- 7.6 跨模块（不在掼蛋 PR 里做）：kit 的分享预览、"叫朋友来"面板、互动面板是 kit 的 DOM，风格和各游戏都不一样。建议 kit 加一个可选的主题参数（底色、边框、按钮色、字体），各游戏传自己的色板；要做的话我另开 kit PR，先问主线。

## 8. 不做的

- 不引外部图片、字体、音频（继续程序生成，许可简单）；
- 不改规则、电脑、联机协议；
- 不做"可换装饰、头像框"这类要存储和商品化的东西（和"不碰真钱"冲突的风险，先不碰）；
- 不做出牌按钮位置可调（欢乐掼蛋 2025 年才加，先把默认位置做对）。
