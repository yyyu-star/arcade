# 掼蛋的美术与界面现状

> 主页和牌桌长什么样、为什么这样画。方向是"灯下的老茶馆夜局"：暖黄的灯、红漆木桌、墨绿绒布，四个熟面孔围坐，热闹但不吵。
> 逐版改动见 `CHANGELOG.md`；代码里的注释会引用本文的第 4 节（主页）和第 9 节（卡通配色表）。

## 1. 原则

- 全部图片程序生成（`src/view/art/` 的 SVG），音效 WebAudio 合成，不引外部图片和音频；唯一的外部素材是内嵌的标题字体子集，来源见 README"素材"一节。
- 宽屏多出来的宽度给主区（主页的主视觉、牌桌两侧的远景），不留空边；世界坐标高 720、宽 1280..1720（`theme.ts` 的 `worldWidthFor`）。
- 画布和 DOM 同一套风格：好友房面板、分享预览、竖屏提示用 `THEME_CSS` 的变量和 kit 的 `--ak-*` 主题变量，和画布里的弹窗一致。
- 不做可换装饰、头像框这类要存储和商品化的东西（和"不碰真钱"冲突的风险）。

## 2. 字体与网格

- 字号只用 `theme.ts` 的 `TYPE` 几级（huge 68、big 40、title 28、body 23、label 20、small 18，世界坐标）；一个画面最多三级。标题和大字用内嵌的思源宋体子集，大数字用粗黑体。
- 手机横屏画布缩到约 0.52–0.54 倍，由 `typeFloor` 托底到字 12、数字 14 CSS 像素，放不下的地方按 `phoneType()` 删字、不缩字（`AGENTS.md` 第 3 节）。
- 间距、圆角、投影、按钮配色只从 `theme.ts` 取（`SPACE`、`RADIUS`、`SHADOW`、`BUTTON`），点按区域至少 44 CSS 像素（`minHit()`）。

## 3. 材质

桌框是红漆胡桃木（feTurbulence 木纹加漆面高光），桌面是绒布（细噪点加中心亮四周暗的灯光圈），面板是象牙纸加木框金线；按钮是卡通立体按钮（第 9 节）。
大背景按世界宽度烘焙一次，不逐帧画；省内存设备不放装饰粒子，灯笼、人物、火星也不动。

## 4. 主页（标题页）

一屏，不弹窗（`TitleScene`，排版是纯函数 `src/view/home-layout.ts`，背景 SVG 和场景共用，有单测）：

- 左边是主视觉：茶馆一角（月洞窗、屋檐、两盏会晃的灯笼 `home:lantern`），围桌的四个人（`home:fig:<id>`，会轻轻呼吸），火星；宽屏时主视觉跟着铺开，面板贴右（宽 500，随世界宽度加到 560）。
- 右边一块漆面板，从上到下：标题"掼蛋"、一句玩法、主按钮、三张模式卡（娱乐 `fun`、实盘 `stake`、好友房 `online`）、战绩条（胜率、最高连胜、头游次数；没打过时写"打完第一局，这里会记下你的战绩"）。
- 主按钮一步开局：有实盘存档是"接着打实盘"（`resumeStake`），有存档是"继续上局"（`continue`），否则"快速开始"（`quick`，娱乐，按设置里的难度）。
- 右上角圆图标：战绩 `stats`、设置 `settings`、规则 `rules`、云存档 `cloud`；左上"大厅"（单独部署叫"首页"）。
- 点模式卡进选档页（同一场景切换，不是弹窗）：娱乐是三张难度卡（新手 / 普通 / 高手），实盘是档位卡。
- 单独部署（没平台）没有实盘卡和云存档；手机竖屏显示"把屏幕横过来"，背景同主页的茶馆。
- 灯笼晃、人物呼吸、火星只在 `LOW_MEMORY === 0` 且没关动画时开。

## 5. 牌桌

- 背景三层（`art/scene.ts` 的 `tableSvg`）：远景暗室和两侧灯笼的光（世界比 1280 宽时桌子两边让出来，左右两家跟着坐进桌沿，`table/layout.ts` 的 `tableSide`）；绒布上一盏顶灯；桌心淡淡的回纹章。
- 顶栏高 56（`TOPBAR_H`），分三组：左"大厅"（好友房加邀请）；中 我方的级 · 本副打几 · 第几副 · 对方的级，坐庄的一队描金边；右 云存档、规则、设置、声音、返回。
  云存档留在顶栏而不收进设置：它的红点提示要一直看得见。
- 四个座位的锚点是 `seatAnchors`：我在下，对家在上中，左右两家垂直居中；三家的剩余张数是头像右下角压一张小牌背加数字，联机的电脑角标在左下角。
- 操作条贴在手牌上方、居中；手牌分列由纯函数 `table/columns.ts` 排，一列最多 5 张，保证手机横屏每张都点得中。
- 记牌器是米黄纸签，级牌那格红字。名次不再单列：出完的人头像上盖名次印章（米色实底，头游加金边）。
- 关键时刻：发牌从桌心往四家各飞牌背；炸弹按大小分三档（四炸、五六炸、同花顺和七炸以上，`highlights.ts` 的 `bombDrama`），越大闪得越亮、震得越久，加光圈和纸屑（省内存设备不放粒子）；
  每副结算的复盘分两框，上面数据（炸弹、最大一炸），下面故事（名场面、称号）；整局结束有"晒战绩"按钮，战绩一行只在真有战绩时写。
- 所有动画时长走 `anim.ts` 的 `dur()`（设置里的速度、`anim=0` 冒烟）。

## 6. 弹窗与 DOM

设置、规则、战绩三个弹窗同宽（`panelW`：世界宽减两边留白，封顶 1200）；战绩没打过时是空状态；规则的牌型示例牌 54 宽。好友房面板（DOM）标题是红飘带、卡片是木框描金。
kit 的 DOM 组件（邀请横条、叫朋友来、分享预览、互动菜单）靠 `--ak-*` 变量取掼蛋的红金木色，不在掼蛋这边改 kit 的 DOM。

## 7. 截图图集

`npm run shot -- --gallery --out <目录>` 按 1280×720、1920×1080、844×390（手机）三种尺寸截主要画面加手机竖屏，改前改后对比用；
加 `--audit --sizes 667x375,844x390` 逐屏量字号和点按区（写 `audit.md`）。浏览器任务一律先 `flock -w 3600 <仓库>/.local/locks/browser.lock` 排队。

## 8. 不做的

不改规则、电脑、联机协议；不做出牌按钮位置可调；不引外部图片、字体、音频。

## 9. 卡通风格配色表

各游戏统一照开盘的卡通风格：主色是掼蛋红；按钮、面板、名牌一律深墨描边加实色下沿（按下时下沉）；表面上亮下暗的轻渐变加顶边白高光、柔和投影；弹窗是木框金线加象牙纸纹。色值在 `src/view/theme.ts`。

| 用途 | 色值 | 用在哪 |
|---|---|---|
| 描边、下沿 | `#2b1d14`（`OUTLINE`，描边 3px、下沿 4px） | 按钮、面板、名牌、图标圆钮、选项组选中项、DOM 按钮和好友房卡片 |
| 主按钮红 | `#d8352f` | 主按钮、标题飘带、选项组选中项 |
| 金 / 绿 / 蓝 / 木 | `#f2b840` / `#2f9a55` / `#3474c4` / `#8a5530`（绿蓝木收沉，红金保持亮） | 要紧、确认、联机、次要按钮和顶栏圆钮 |
| 禁用 | `#8a8079` 底、`#f2ece4` 字 | 灰掉的按钮 |
| 奶油底 | `#fbf1dc`（上 `#fffaf0`、下 `#f3e3c0` 渐变） | 弹窗面板（外套木框 `#6b3f20`/`#8a5530` 金线）、好友房卡片 |
| 正文 | `#2b1d14` 深墨、`#7a6555` 次要 | 面板里的字（对比度够，手机字号仍按 typeFloor 托底） |

场景色（桌面墨绿绒 `#1f5a43`、胡桃木 `#6b3b1f`、漆红 `#b3202a`、金 `#e0b45a`、象牙纸 `#fbf1dc`、对方队色青蓝 `#3a78c8`）是 `theme.ts` 的 `COLOR`，只做队色的青蓝不做装饰。
