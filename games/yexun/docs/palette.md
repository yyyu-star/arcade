# 夜巡配色（卡通风格，2026-10-19）

夜蓝是夜巡的主色调；界面元素一律奶油底 + 深墨描边 + 实色下沿阴影，照开盘的卡通样子。

| 色值 | 用在哪 |
|---|---|
| `#17131c` 墨 | 所有描边（2.5–3px）、下沿阴影（按钮 3–4px，按下沉到 1px）、正文字 |
| `#fbf5e4` / `#f6efdc` 奶油 | 卡片、按钮、面板底；选中的卡反过来：墨底奶油字 |
| `#1c2440` 夜蓝 | 菜单背景、HUD 倒计时底（主色调） |
| `#c8402f` 朱红 | 主按钮（开始、确认）、危险提示 |
| `#ffd23a` / `#f2c94c` 金 | 选中描边光、钥匙、铜钱、强调数字 |
| `#8f6110` 暗金 | 奶油底上的小字说明（13px 起，对比度够） |
| `#5a4a3a` 褐 | 奶油底上的次要正文（14px） |

圆角：按钮、卡片 12–14px，面板 14–16px；正文 ≥ 14px，按钮下的小字说明 ≥ 13px。
