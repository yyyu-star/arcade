# 夜巡 10-20 升级计划

> 所有者 10-20：继续优化夜巡（调优、升级、加地图、流派、搭配组合、优化布局和体验、空气墙更显眼、丰富玩法、竖屏地图和人物占比不合理）。
> 起点 0.3.14，RULES_VERSION 20。一次只有一个 PR 在审，每个部署的 PR 升一次版本。

## 现状（读源码，0.3.14）

- 竖屏比例：缩放 `worldZoom`（`src/view/viewport.ts`）按屏高定：`cssH / 560`。
  - 手机竖屏 390×844：缩放 1.51，看得见的世界只有 260×560，主角显得很大，两侧几乎看不到怪。
  - 手机横屏 844×390：缩放 0.78，看得见 1082×500。
  - 竖屏视野只有横屏的 30%，这就是所有者说的"占比不合理"。
- 空气墙：守夜场地 3200×3200，核心把人钳在边上 20 以内（`step.ts`）。画面上只有四周一圈压暗，撞上去没有反馈。夜探镇子的外缘同样只有压暗。

## P0 体验硬伤（交计划后直接做，两个 PR）

### P0-1 竖屏比例 + 空气墙（0.3.15，纯画面，不动核心、不升 RULES_VERSION）

**竖屏比例**
- 缩放改为按短边定：`min(w, h) / (短边 < 500 ? 500 : 560)`，再保留按宽兜底。
- 效果：竖屏 390×844 缩放约 0.78，看得见约 500×1080，和横屏的视野面积一样，只是方向转了 90°。
- 主角占屏高的比例：横屏约 1/10 不变；竖屏从现在约 1/5 降到约 1/20 屏高（按屏宽算约 1/10，和横屏的屏高占比一致）。
- 如果这样太小，就把短边基数在 420–500 之间取一个值：三档对比截图后定，结果写进 PR。
- 竖屏下 HUD（顶栏、经验条、摇杆）只占上下边，不往中间伸。
- 验收：手机竖屏 3 档（360×780、390×844、430×932）各截一张真人局，加一张横屏对照，量主角和怪的屏幕像素；`smoke --only 7`（HUD 不相交）过。

**空气墙**
- 守夜：场地四边画一圈墙。按地图换样子：雪原、冰湖画木栅栏，竹林画竹篱，河滩画石堤，义庄画院墙。墙外再盖一层雾，一眼看出走不出去。
- 撞墙反馈：主角贴边且还在往外推时，墙上闪一下火花、轻微震屏（跟设置里的震屏开关走），并出一个往回指的小箭头。反馈有冷却，不连着刷。
- 夜探：镇子外缘和不可进的房块描深色边线；撞上时用同样的火花反馈。
- 都只读核心的位置和输入，判断"贴边还往外推"在画面层做，不改规则。
- 验收：守夜边上和夜探墙边各截一张真人局截图；冒烟零报错。

### P0-2 布局补查（0.3.16，接 10-19 没跑完的几屏）

## P1 内容（等主线看过；每项一个 PR，依次排队）

- **P1-1 新地图「荒庙」**：小庙、残墙、香炉。特色机制是香炉区：站在里面慢慢回血，但会引来更多怪。特色怪是会掷香灰（减速）的庙祝鬼。
  - 0.4.0，RULES_VERSION +1。
  - 验收：sim 每难度 × 3 流派 ≥ 500 局，在 GitHub runner 上跑；胜率落在现有地图的区间内（同档和雪原差 ≤ 5 个百分点），节奏表过 `pace.test.ts`。
- **P1-2 新地图「渡口」（可选）**：会定时漂来浮冰当桥，特色怪是水鬼（从水里冒出来）。口径同上。主线觉得一张就够就不做。
- **P1-3 新流派「纸人」**：
  - 一件新法器"纸人"：召唤会走的纸人替你挡怪。
  - 一件新被动"剪刀"：纸人数量和寿命。
  - 一个进化。
  - 两条新双修组合：纸人 + 葫芦 = 纸人着火；纸人 + 铃 = 纸人一起响铃。
  - 图鉴可见。
  - 验收：sim 新流派胜率和现有最强、最弱流派相比在中间；双修组合不超过现有组合的最高胜率。
- **P1-4 升级选卡更有取舍**：
  - 卡上标稀有度（普通、少见、稀有，按现有掉率着色，不改概率）。
  - 能和已持有的法器组成双修或进化的卡，显示"和你的 X 可组成 Y"。
  - 纯画面加文案，不改规则。
  - 验收：选卡竖屏、横屏截图。

## P2 玩法丰富（等主线看过，挑一个先做）

- **P2-1 地图事件「夜市」**（推荐先做）：每局中段随机出一次。几个摊位开 20 秒，用这局捡的铜钱换回血、临时增益或重抽一次卡。
  - 只在娱乐模式开；实盘不开，等单独配系数再说。
  - 验收：sim 胜率变化 ≤ 3 个百分点。
- **P2-2 精英词缀**：精英怪随机带一个词缀（分裂、冲刺、护盾），名字上标出来。口径同上，只在娱乐模式开。

## 规矩

- 核心确定性照旧。改数值必跑 sim（GitHub runner）。规则改动升 RULES_VERSION 并更新金标准指纹。
- 实盘的倍数口径不动。新地图、新流派在实盘里先不开放，等单独配系数。
- 截图都在浏览器锁下拍，每个 PR 至少一张不开 auto 的真人局。子代理只用 haiku、sonnet。
