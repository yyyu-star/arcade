# 夜巡 · 界面流程与布局规则

> 现行规范（原"美术与界面打磨 v3"方案已落地，过程留在 CHANGELOG 0.3.x–0.4.3）。配色见 [palette.md](palette.md)，画风和声音见 DESIGN.md 第 7 节。
> 只写改界面时要守的东西：流程、各屏该放什么、各尺寸怎么排、怎么验收。

## 1. 流程

主页（`Home`）→ 选模式 / 地图（`Select`）→ 对局；暂停、结算、玩法说明、角色与加成、图鉴、藏宝阁是叠在上面的面板（`screens.ts`、`prep.ts`、`codex.ts`、`vault.ts`、`guide.ts`）。

- 第一次打开只有一个大按钮（开始守夜），玩过一局以后才出模式卡和难度（DESIGN.md 13.7）。
- 主页：主视觉（月、灯笼、飘雪、道士）+ 标题 + 快速开始 + 两张模式卡 + 战绩；每日、排行、回放、图鉴、玩法说明收成一排小入口，不压标题。
- 选模式 / 地图：地图是大卡、按难度排（雪原、竹林、冰湖、河滩、义庄、荒庙），带缩略图（`drawMapThumb`）和特色怪；锁着的灰着并写怎么解锁；难度、角色和加成、开始都在这一屏。
- 实盘（有平台钱包才显示）作为"模式"的开关放在选模式屏，不占整块卡。

## 2. 对局 HUD：少挡视野

- 左上回大厅（≥ 44×44，窄屏只留小房子）和头像血条，上中计时（夜探加撤离目标条），右上击杀、铜钱，右侧法器格；夜探多背包价值和小地图。
- 手机竖屏顶栏并成一行，血条和计时始终可见；小手机横屏、窄竖屏（≤ 400 宽）、平板竖屏（768–884 宽）各有一档收法（`hud.css`、`raidhud.css`），改 HUD 先看这几档。
- 新手提示条是一行小条，放在计时下面，不盖底部视野和小地图。
- 摇杆默认浮动（按哪儿出现在哪儿）；固定摇杆在设置里开，位置避开小地图。只动摇杆外观和位置，不碰输入逻辑（会影响 `tools/feel.ts` 测的手感）。
- 空气墙看得见：守夜场地四边按地图画栅栏、竹篱、石堤或院墙，墙外盖夜雾；顶着墙还在推时冒火星、轻震屏（跟震屏开关走）。

## 3. 各尺寸的排法

- 电脑（≥ 1100 宽）：主页左视觉右信息；选地图页大卡排网格，右边固定一栏放选中地图的信息和开始。1920 下面板跟菜单一起放大（约 1.3 倍），不是缩在中间一小块。
- 手机横屏：主页单行；地图卡一屏看到三张以上，不要靠横向滑动藏起来。
- 手机竖屏：主页单列；地图卡竖向单列；"开始"始终在屏幕内。竖屏的世界缩放按屏宽定（一屏宽看 460 单位，`worldZoom`），刷怪圈转 90°（`setup.tall`）。
- 字号：说明不小于 12 像素，正文 14，数字 20，毛笔标题 24–40；按钮高度 40 / 48 / 56 三档，点击区仍 ≥ 44。
- 窄屏、小屏放不下的先收（去图标、去月亮、挪行），再考虑缩字；320×568 放不下时整层能上下滑。

## 4. 省内存设备

渲染倍数封顶 2、`100dvh` 加 `--app-h`、safe-area 带兜底值（`viewport.ts`）；主页飘雪减半或静止，待机小动作静止；新界面都写在 `--app-h` 之内。

## 5. 验收

- 每次改界面：`npm run shot -- --flow --view desktop,phone,phonep,wide` 看每屏截图，至少一张不开 `auto` 的真实对局；`npm run smoke` 第 7 段断言 HUD 各块互不相交。
- 多尺寸：手机竖横、平板、折叠屏、电脑共 26 个尺寸，查溢出、点击区 ≥ 44、元素相交、截字、字号 ≥ 12、控制台报错（0.4.3 做过一遍，矩阵脚本在维护者本机，没有放进仓库）。
- 有意的省略号只留在结算页夜探宝物名这种格子很窄的地方，悬停看全名。
