## 0. 一句话

夜巡的**画和手感已经不错**（Q 版道士、雪地、灯笼、毛笔字），粗糙的是**界面的排版**：主页是两张并排的大卡，手机上摆不下，竖屏整个坏掉；对局的顶栏在手机竖屏上互相压住，计时和血条被遮；地图缩略图是手画示意，不像真地形。方向是：先修手机竖屏（最严重），再拆出"主页 → 选模式/地图 → 对局"，最后补动效和细节。

### 1.6 通病

1. **布局靠固定宽度，不靠屏幕**：菜单两张卡是固定宽度的横排，没有为竖屏、大屏写不同的布局。
2. **HUD 没有按屏幕收**：顶栏六样东西是同一行，没有"窄屏并成两行/收起"的规则。
3. **大屏只是放大**：1920 下元素大小和 1280 一样，空的地方更空。
4. **字号**：卡内说明和地图一行 11–12px，低于 12px 的验收线。
5. **缺少"开场感"**：进入对局没有任何过场，精英和特色怪出场没有名牌。

## 3. 方向

### 3.1 美术（定调，沿用 DESIGN.md 第 7 节）

宣纸色卡片 + 墨色粗描边 + 朱红印章强调，毛笔字做标题（马善政楷书子集，已有）。色板（已在用，不换）：墨 `#17131c`、宣纸 `#f6efdc`、深宣纸 `#e8dcc0`、朱红 `#c8402f`、金 `#f2c94c`、夜蓝（主页天空）`#141a38` → `#55649a`、雪 `#cdd6ea`。字体层级收成四级：毛笔大标题（24–40）、粗体数字（20）、正文（14）、说明（12，不再有 11）。所有图继续程序生成，来源写进 ASSETS.md（有改动的话）；不引入图片文件。

### 3.2 进入流程：主页 → 选模式/地图 → 对局

**主页**（一屏，不滚）：
- 主视觉（现有：月、灯笼、飘雪、道士，保留并整理构图）；
- 中间：毛笔标题 + 一句玩法 + **一个大"快速开始"**（用上次的模式、地图、难度；第一次是教学守夜）；
- 下面两张**模式卡**（守夜、夜探），每张只有：名字、一句话、一张场景图、"进入"；不在主页上放难度、地图、加成；
- 一个**战绩小卡**：最好成绩（撑了多久、斩了多少）、今日挑战（每日榜入口）、铜钱数；
- 顶部：大厅（左）、设置（右）；排行、回放、图鉴三个入口收成一排小图标放在战绩小卡旁，不再是一列竖按钮压在标题上。

**选模式/地图**（第二屏）：
- 守夜：地图**大卡**（雪原、竹林、冰湖、河滩、义庄，按难度排，一屏竖排或网格，不再横向滑动），每张：真实地形缩略图、名字、一句话、**特色怪头像一排**（竹精、蛇精、河蟹、冰傀等，已有程序画的形象）、锁定的灰着并写怎么解锁；下面是难度一排、角色和加成一排、"开始"；
- 夜探：镇子大卡（古镇、渡口、山寺，教学镇在第一次），同样带缩略图和特色怪（更夫鬼、石僧、溺鬼）；
- 实盘（有钱包才显示）：作为"模式"的一个开关放在选模式屏最上，不再占一整块卡。

**对局**：保持现状入口，加一个 1 秒左右的"开场"（地图名 + 今晚的特色怪）。

### 3.3 对局 HUD：不挡视野

- **手机竖屏并成一行**：大厅图标化（只留房子，≥44×44）、头像带血条（血条在头像右边，宽度按屏幕）、计时居中、击杀和铜钱合成一个胶囊（两个数字并排）、暂停；夜探的背包件数并进同一个胶囊或放第二行很窄的位置。验收：390 宽下六样东西互不重叠，血条和计时始终可见；
- **手机横屏**：HUD 贴四角，中间让出；法器格和被动格改到右侧竖条并缩小（图标 36px，点击区仍 ≥44），不放在场上怪的中线上；
- **新手提示条**：缩成一行小条放在屏幕最上（计时下面），第一次移动后自动收起，不再盖底部视野和夜探小地图；
- **摇杆**：浮动摇杆的圈半透明度降低、直径 120 → 96px（触点仍是整个下半屏，不影响操作）；固定摇杆开关打开时位置避开小地图：小地图固定在左上（计时之下）或收成可折叠小图，摇杆固定在右下。由冒烟脚本断言两者外框不相交；
- **电脑**：HUD 随屏幕放大一档（1920 下 ×1.25），左上血条、中间计时、右上统计的间距缩短；小地图按屏幕尺寸放大。

### 3.4 精英入场名牌、特色怪出场

精英和特色怪首次出现时，从屏幕上沿滑出一块"名牌"：怪的头像 + 名字 + 一句怎么打（例如"竹王：打倒它竹林才安静"），1.2 秒淡出，同一种怪一局只出一次，同时最多一块。复用 `banner.ts` 里已有的预警条，加头像。怪的头像用现有图集里的形象。省内存设备同样出（只是一个 DOM 条，开销小）。

### 3.5 角色待机小动作

主页和选角页的道士加待机：每隔几秒眨眼一次、衣袖轻摆、符纸飘；用现有 `heroes.ts` 的画法拆出"眼睛/袖口"层，主页的动层（`drawTitleLive`）里叠加；**省内存设备（`?lowmem`、触屏手机平板）静止**，只显示静态一帧，不跑动层以外的额外绘制。动作频率低，不拉高帧耗。

### 3.6 地图缩略图改用真实地形低倍渲染

现在 `drawMapThumb`（`terrain.ts`）按地图定义手画色块。改成：复用 `paintTerrain`（河、冰、桥、竹地面）按 1/16 左右的倍数画一次，再叠障碍块（`blocks`）用各自的小图，画好缓存成 data URL，每张图只画一次。缩略图尺寸按卡片大小出（电脑大卡 ~240px，手机 ~120px）。风险：`paintTerrain` 对大场地的开销，需要实测单张 < 30 ms；低倍渲染要避开图集依赖（选图页时图集可能还没生成，先用现在的手画图占位，图集好了替换）。

## 4. 电脑版和手机版各自的布局

- **电脑（≥1100 宽）**：主页是"左主视觉 + 右信息"两栏，不是居中一列；选地图页地图大卡排成网格（3–5 列），右侧固定一栏放当前选中地图的特色怪、解锁条件、难度、开始；一屏看全，不滚。1920 下用 `clamp()` 放大字号和卡片，不再是 1280 的原样放大。
- **手机横屏**：主页单行（左视觉、右三个按钮）；选地图页横向一屏 3 张加一栏选中信息。
- **手机竖屏**：主页单列（视觉在上 35%，下面是快速开始、两张模式卡、战绩小卡）；选地图页**竖向单列**地图卡（缩略图在左、文字在右，一屏约 3 张，可滚动），底部固定"开始"按钮（始终可见）。
- 统一栅格：以 8px 为基准；按钮高度三档（40 小、48 常规、56 主按钮，点击区仍 ≥44）；卡片内边距 16px。

## 5. 性能与兼容

- 手机和平板渲染倍数封顶 2、`100dvh` 变量、safe-area 带兜底值，全部沿用现有 `viewport.ts`，新页面全部写在 `--app-h` 之内；
- 主页的粒子（飘雪）省内存设备减半或静止；待机小动作省内存设备静止；
- 帧率：改前基线（本机软渲染，仅作参考）守夜约 10–20 帧/秒、夜探约 11–16 帧/秒；改后不得低于改前，用 `--cpu 4` 对比；
- 冒烟新增：每个视口下 HUD 元素外框互不相交（含摇杆、小地图）、选地图页"开始"始终在屏幕内、`--lowmem` 下待机动作不跑；双指放大和 WebGL 上下文丢失/恢复沿用现有的。

## 6. 拆分（每个 PR 可单独上线）

## 7. 风险和不做的事

风险：
1. 主页拆成两屏会改变"打开到开打 ≤ 30 秒"（DESIGN.md 13.7）的路径，所以"快速开始"必须一步直达，第一次仍是单按钮；
2. 缩略图用真地形渲染，图集没好之前要占位，不能拖慢首屏；
3. HUD 并行后在极窄屏（320）下仍可能挤，冒烟加 320 宽视口；
4. 摇杆改动只动外观和位置，不碰输入逻辑，否则会影响 `tools/feel.ts` 测的手感；
5. 1920 的亮带还没查出原因，可能不在 UI 层，如果在核心渲染里就单独报，不在本方案里硬修。

不做：
- 不改规则核心、数值、刷怪表、`RULES_VERSION`；
- 不换画风、不换毛笔字体、不加图片文件、不引入别人的图或音频；
- 不加联机、不加账号相关界面；
- 不做整屏开场动画和剧情；
- 不重画怪和法器（形象现在已经够好）；
- 不做新手教程的大改（只缩小提示条）。

4. 1920 亮带的成因。
