# 更新日志

## 0.0.4（2026-10-16）

- 开始菜单：第一次打开只有一个"开始守夜"大按钮（新手难度）；玩过以后是模式卡（守夜选新手 / 普通 / 高手，显示这个难度的最好成绩；夜探标着"还在做"）。左上回大厅，右上设置。
- 暂停：本局法器（等级、伤害、击杀）和被动，音效、音乐、震屏、固定摇杆（触屏）四个开关，继续 / 认输 / 回大厅（离开先确认）；切到后台自动暂停，暂停时声音一起停。
- 结算：天亮了 / 尸王伏诛 / 倒下了 / 收工，斩、级、铜钱、撑了多久，每件法器的伤害条，被动；新纪录标出来；再来一局、换难度、大厅。
- 第一局引导（最多 3 条，可"不再提示"）：开局拖动走位、第一次升级卡片带说明、第一次开宝箱讲进化。
- 本机存档 `yexun.save`：局数、胜场、每个难度的最好成绩、引导做过哪几条、上次选的难度（认输的局不算纪录）。
- 主线 2b 的两条意见：地上的魂珠最多 80 颗，多的经验并进最远的一颗变成大珠（放大、一闪一闪）；魂珠缩小一号、颜色淡一些；磁吸半径随等级涨（每级 +1.5%，40 级封顶 +60%）。
  桃木剑斩痕随等级变长变亮，满级多一层金光。
- 规则版本 2（魂珠合并、磁吸随等级、每件法器记伤害和击杀），旧录像会标"旧版本"。

## 0.0.3（2026-10-16）

- 真正的守夜对局：打开就开打，键盘（WASD / 方向键）或触屏浮动摇杆走位；核心每秒 30 拍，画面在两拍之间插值，主角按当前输入本地预测，摇杆一动当帧就走。
- 打击感：命中闪白、伤害数字（同屏最多 30，暴击金色）、击退、死亡碎片和墨迹、击杀大怪时顿帧和震屏、雷落点闪光圈、连斩横幅、100 / 500 / 1000 斩里程碑、捡魂珠音调递增、低血红框加心跳。
- 主线的五条画面意见：斩痕更大、两层；飞剑绕身、符咒拖尾、铜钱残影；主角脚下月光圈、加粗描边、四角压暗；雪地月光蓝调、雪堆、冰面、石灯、残碑、枯树、身后脚印；
  经验改成绿、紫、红三色魂珠（和蓝色鬼火分开）；怪按种类大小不一、精英紫气；右侧法器格和被动格垫半透明底板。
- 新画的怪和物件：狐妖、石狮怪、跳尸将军、尸王、鬼火球、魂珠、肉包、符纸卷、宝箱、石灯、冰面、雪堆、脚印、光圈、升级光柱，以及进化和被动的图标。
- 升级三选一卡片（点、1/2/3、方向键加回车）、宝箱和进化演出（点一下跳过）、精英和尸王出场预警、尸王跳砸落点红圈和血条。
- 合成音效和音乐接进对局（打开页面后第一次点击或按键时解锁声音）。临时的暂停层（继续 / 回大厅确认）；菜单、结算、引导、声音开关在下一个版本。

## 0.0.2（2026-10-16）

- 守夜的规则核心（`src/core/`）：每秒 30 拍、确定性（只用四则运算、写死的方向表、牛顿法开方、按用途分流的随机数），原地推进，状态指纹锁住重放。
  六件法器（桃木剑、符咒、铜钱剑、飞剑、雷符、镇魂铃）和两个进化（斩妖剑、天师符雨）、八件被动、升级三选一、宝箱；
  五种常规怪（纸人、鬼火、跳尸、灯笼鬼、狐妖）、两种精英（石狮怪、跳尸将军）、尸王（跳砸、召唤、尸气）；15 分钟天亮。
- 机器人（`tools/bots.ts`、`tools/sim.ts`）：小白、普通两个玩家模型，普通按剑阵、符箓、镇守三个流派选卡；`tools/bench.ts` 量每拍耗时。
- 画面还是样图，下一个版本接上真正的对局。
