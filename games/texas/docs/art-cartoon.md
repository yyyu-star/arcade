# 德州 · 卡通换皮（2026-10-19，只改 style.css / skin.css）

照开盘的卡通风格：暖奶油底、饱和平涂、深棕描边、按钮带实色下沿。德州保留牌桌绿和金。覆盖写在 skin.css 末尾，全部限定在 `.stage` / `.mask` / `.scene` 根下。

第二版（有质感）：奶油降饱和改成 `#f5e6c0` / `#ead29a`，背景是深一点的暖褐黄加暗角；按钮、名牌、面板、牌加上下 6–10% 的轻渐变、顶边 1px 高光、柔和投影；呢子加噪声细纹和中心亮四周暗的暗角，木框加细木纹。亮金 `#f7c43a`、亮绿只给主按钮和重点数字。

| 色值 | 用在哪 |
|---|---|
| `#2b1d14` 深棕 | 描边（2–3px）、正文字、按钮实色下沿 |
| `#fff4d6` / `#ffe7ae` 奶油 | 背景、名牌、面板、弹窗、次按钮 |
| `#1f9a5f` 牌桌绿（主题房仍按 `--felt-*` 换） | 毡面平涂 |
| `#ffc933` 金 / `#a85a00` 深金 | 主按钮、选中态 / 奶油底上的金色字 |
| `#2fbf71` 翠绿、`#ff8a2a` 橙、`#e8453c` 红、`#c9c2b2` 灰 | 跟注、加注、全下、弃牌 |

规矩：卡片、按钮、名牌、弹窗 2–3px 描边，圆角 12–16；按钮下沿 3–4px 实色阴影，按下下沉。描边都在 border-box 内，不改尺寸。kit 面板走 `--ak-*` 变量（奶油底、深棕字、金色强调）。正文不小于 14px。
