## 3. 美术方向

**定调：深夜的私人牌室**（夜场版）：毡面、黄铜和木头、一盏聚光灯打在桌上，四周是暗下去的房间和散景灯光；热闹的时候（赢牌、全下）灯会亮一下、金币会飞。现行皮肤把颜色换成卡通的暖色平涂，结构不变。

**四个档位的主题桌**（同一套画法换参数，`rooms.ts` / `rooms.css`，DESIGN.md 8.9）：小桌"街角牌室"、中桌"湖畔会所"、大桌"红厅"、豪华桌"黑金"，一档比一档华丽。娱乐的三个难度用小桌的主题。

**素材**：全部程序生成——CSS 渐变和内联 SVG，不用图片文件、不用外部素材；散景灯、吊灯和吧台的剪影、荷官都用 SVG 路径画，来源写进 `ASSETS.md`。字体用系统字体，不下载。
筹码按面额分色（1、5、25、100、500、1k、5k、25k、100k），侧面有镶边。

## 4. 进入流程

```
进来 → 游戏主页 ──快速开始──────────────→ 牌桌
                ├─继续上局（有没打完的才出）→ 牌桌
                ├─模式卡：娱乐 / 实盘 ──→ 选桌（档位主题房 + 人数 + 带多少）→ 牌桌
                ├─模式卡：好友房 ──────→ 开房 / 输码（选桌页的好友房版）→ 等人页 → 牌桌
                └─左上"大厅"（常驻）
```

- **游戏主页**（第一屏，电脑和手机都不滚动）：主视觉（分层背景、桌子的一角、筹码和一扇牌）；大按钮"快速开始"（按上次的设置，第一次来是娱乐·新手·6 人），有没打完的一桌时换成"继续上局"；
  三张模式卡：**娱乐**（随便玩，筹码不算数）、**实盘**（带筹码上桌，显示钱包余额）、**好友房**（开房间 / 输房间码）；小卡：我的战绩；钱和"无任何现金价值"一行放在实盘卡里。德州不做每日挑战卡。
- **选桌**（第二屏）：档位是四间主题房的卡片（桌子小图 + 名字 + 盲注 + 星），下面人数、带多少、"坐下开打"；娱乐是三个难度卡；返回回主页。
- **好友房**：输码框在最上面（进别人的房不用选档位），下面选档位和人数开房。
- **等人页**：画成一张桌子，座位是桌边的椅子（有人显示头像和名字，空椅子点了坐下），房间码和"叫朋友来"在桌子上方，"开打"在桌子下方。

## 5. 牌桌

- **背景分层**（从远到近）：墙面渐变和散景光斑；吊灯和吧台的剪影（按主题换颜色）；桌面（毡面 + 木边，中间的水印是主题房名）；一层从上往下的光锥。
- **关键时刻的动效**（都只动 `transform` / `opacity`，"减少动态效果"和省内存模式下换成淡入淡出或静止，DESIGN.md 8.10）：发牌从荷官手里飞出；下注推筹码、收池；赢牌金币飞向赢家、大锅边缘泛金；全下聚光灯收在这个人身上；名场面用 kit 的横幅。每个特效不超过 1.5 秒。
- **音效**：WebAudio 合成，有筹码、金币、全下低鼓等（`sound.ts`）。

## 6. 电脑版和手机版

- **电脑（1280、1920、更宽）**：横屏舞台按比例铺满；超宽屏两侧的远景继续延伸，不留黑边。主页模式卡横排三张，选桌四间主题房一排。
- **手机横屏**：底栏三块按比例收窄，互动按钮只留图标；选桌页档位卡两行两列，不用滚动。
- **手机竖屏**：竖的牌桌（`layout.ts` 的 `fit`，DESIGN.md 8.2）；主页按"主视觉 → 快速开始 → 模式卡两行 → 战绩"竖排，一屏放下（iPhone SE 375 × 667 为准）。
- 平板竖着仍用横屏舞台；省内存设备（触屏 + `deviceMemory ≤ 4` 或 `saveData`）关掉远景漂动、浮尘和光扫，只留静止画面。
