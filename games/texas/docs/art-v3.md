## 1. 现状审计

截图在同一套冒烟流程里拍（`node scripts/smoke.ts`，1920 用本地加的 `--desk 1920x1080`，本地假平台），1280 × 720、1920 × 1080、手机横屏 844 × 390、竖屏 375 × 667 / 390 × 844。
1920 和 1280 画面一样：舞台是 540 个设计单位高、按比例整体放大（`layout.ts`），所以大屏不会多出空边，但也只是"放大了的 1280"，问题相同。

### 1.1 标题页（`lobby.png`、`lobby-real.png`、`phone-lobby.png`、`se-lobby.png`）

- 层级：一进来最大的是"德州扑克"四个字和一扇牌，真正要点的"坐下开打"在右栏底部；钱包、免责一行、模式、档位、人数、带多少、开打、好友房 8 层挤在一栏里。
- 对齐：左栏标题、扇形牌、版本号居中，右栏左对齐，两栏顶边、底边都不齐；左栏下半截空着（1280 下约 1/3 屏）。
- 字号：档位卡里 5 行字（名字、星、盲注、一场多久、最多输、赢很少过），11–13px 一堆，手机上要眯眼；模式说明和按钮挤在一行，长了就折成两行。
- 背景：一层墨绿 + 斜纹，没有景深；扇形牌是唯一的画面元素。
- 手机横屏：右栏要滚动，好友房一行在第一屏外（0.17.4 已修，第 7 节 PR 0）；竖屏：标题和扇形牌占掉上面 40%。
- 空状态：钱包连不上时只是一行灰字。

### 1.2 新手提示（`tips.png`）

- 弹窗盖在牌桌正中，牌桌其余部分没有变暗到"聚焦"，看不出在指哪里。

### 1.3 牌桌（`table-turn-1.png`、`raise-panel.png`、`desk-hand-end.png`、`solo-fun.png`、`phone-table.png`、`phone-portrait.png`）

- 背景：桌子外面一圈纯黑（1280 两侧各约 120px），没有环境；毡面是一块平的绿，中间"德州扑克"水印很淡，看着像占位。
- 对齐：
  - 赔率那一行（"底池 50 · 跟 20 · 赔率 2.5 : 1"）横穿右下座位的名牌；
  - 加注面板展开时，右下座位被挪到右上座位上面，两张名牌叠在一起（`raise-panel.png`）；
  - 一手结束的横幅"老好 一对 赢 500"压在我的底牌上（`desk-hand-end.png`）；
  - 底栏"互动 · 第 1 手 · 歇一手"、我的头像名牌、操作按钮三组的基线不一样高；
  - 1920 下"互动"按钮的图标和字没跟着放大（按钮框是大的，里面是 1280 的小字，`1920/table-turn-1.png`）；
  - 点开别人的资料卡，卡片盖住左半张桌子和我的底牌左边；
  - 下注额筹码和座位的距离每个座位不一样（有的贴着头像，有的在桌子中间）。
- 层级：操作区三颗大按钮颜色很重，桌面上的公共牌、底池反而不显眼；底池字号和下注额一样。
- 质感：筹码只有一种红色圆片，看不出面额；牌背、头像框是好的，木边偏平。
- 动效：发牌、下注只是位移，没有"飞出、落下"的节奏；赢了只有名牌上一个 +500 和金光；全下没有特别处理。
- 手机横屏：互动按钮、第几手、歇一手、头像、操作区五组挤在底边一行；竖屏还可以，但上半屏空。

### 1.4 结算（`summary.png`、`summary-share.png`、`room-summary.png`、`phone-summary.png`）

- 单机结算是一张清单（带上桌、结回、这一场、打了几手、最大一手），称号是三个小灰标签；赢了 +920 和输了 −160 长得一样，没有情绪。
- 好友房颁奖：1280 下颁奖区把弹窗顶高，第一排奖被裁掉一截（`room-summary.png`）；人名过长被截成"本机sm…"；三个奖卡等宽但内容高度不一。
- 分享卡（kit 画）本身是好的，预览层按钮四个一排，在 1280 下压到弹窗外面的"回标题"。

### 1.5 好友房（`room-wait-host.png`、`room-host-4.png`、`room-spectate.png`、`room-wait-phone.png`）

- 等人页：一块面板放在空的深色背景上，上下左右大片空白；房间码很大但"叫朋友来"和"开打"两个金按钮抢主次；座位是四个灰框，看不出谁是谁（没有头像）。
- 牌桌：和单机同一张，顶栏多了"好友房 933866"；旁观的"旁观中"、"坐下"、"也可以点蓝圈的座位"一行字挤在左下。

### 1.6 设置、规则

- 设置不是一页：顶栏四个圆按钮（云存档、快/慢、互动、音量），没有文字，第一次来的人不知道是什么；
- 没有规则页：新手只有三步提示；牌型大小只能在 DESIGN 里看。

### 1.7 通病

- 只有一层背景、一种墨绿，所有页面看着一样；
- 按钮高度 40/44/48/52 混用，圆角 8/12/16/999 混用；
- 小字太多（11–13px 的说明），要靠"能用图标、数字、颜色表达的不写长句"收；
- 没有转场：主页→牌桌、牌桌→结算是硬切。

## 3. 美术方向

**一句话定调：深夜的私人牌室。** 墨绿毡面、黄铜和木头、一盏暖黄聚光灯打在桌上，四周是暗下去的房间和散景灯光；热闹的时候（赢牌、全下）灯会亮一下、金币会飞。

**色板（7 色）**

| 名字 | 色值 | 用在 |
|---|---|---|
| 夜 | `#06100c` | 远景、最暗的底 |
| 墨绿 | `#0f2a1f` | 面板、中景 |
| 毡绿 | `#1f6b4a` | 牌桌毡面（小桌；其他档位换主题色，见下） |
| 黄铜金 | `#f3c86b` | 主按钮、金额、高光 |
| 木 | `#6b3d1d` | 桌边、卡片框 |
| 酒红 | `#8a1f2b` | 牌背、筹码、强调 |
| 象牙 | `#fbf7ea` | 牌面、主要文字 |

**四个档位的主题桌**（同一套画法换参数）：小桌"街角牌室"（毡绿 + 原木 + 暖黄灯）、中桌"湖畔会所"（深蓝毡 + 胡桃木 + 冷白灯）、大桌"红厅"（酒红毡 + 黑木 + 金灯）、豪华桌"黑金"（黑毡 + 黄铜边 + 金色聚光和金粉）。娱乐的三个难度用小桌的主题。

**字体层级**（系统字体，不下载字体文件）：标题 40/30（加粗、金色渐变）、H2 20、正文 16、说明 13（最小，不再出现 11）；数字一律等宽数字（`font-variant-numeric: tabular-nums`）。

**材质**：毡面 = 底色 + 细噪点 + 中间亮四周暗的灯光；木边 = 两层渐变 + 一道高光 + 一道暗线；黄铜 = 金色渐变 + 顶沿高光；纸 = 象牙底 + 很淡的纸纹；筹码按面额分色（白 1、红 5、绿 25、黑 100、紫 500、金 1000 份，按大盲换算），侧面有镶边。

**主视觉怎么画**：全部程序生成——CSS 渐变和内联 SVG（和现在一样），不用图片文件、不用外部素材；
新加的远景散景灯、吊灯剪影、荷官和桌边人物都用 SVG 路径画，来源写进模块的 `ASSETS.md`（README 的"素材"一节指向它）。

## 4. 进入流程

```
进来 → 游戏主页 ──快速开始──────────────→ 牌桌
                ├─继续上局（有没打完的才出）→ 牌桌
                ├─模式卡：娱乐 / 实盘 ──→ 选桌（档位主题房 + 人数 + 带多少）→ 牌桌
                ├─模式卡：好友房 ──────→ 开房 / 输码（选桌页的好友房版）→ 等人页 → 牌桌
                └─左上"大厅"（常驻）
```

- **游戏主页**（第一屏，电脑和手机都不滚动）：
  - 主视觉：分层背景（远景散景灯慢慢漂、聚光灯下一张桌子的一角、几枚筹码和一扇牌，牌边有光扫过）；省内存模式下是静止的同一张；
  - 一句玩法："两张底牌、五张公共牌，凑出最大的五张"；
  - 大按钮"快速开始"（按上次的设置，第一次来是娱乐·新手·6 人），有没打完的一桌时换成"继续上局"；
  - 三张模式卡，横排（手机竖屏两行）：**娱乐**（随便玩，筹码不算数）、**实盘**（带筹码上桌，显示钱包余额）、**好友房**（开房间 / 输房间码）；
  - 小卡：我的战绩（打了几手、赢了几手、最好的一手）、拿过的称号；德州没有每日挑战榜，就不放挑战卡；
  - 钱包和"无任何现金价值"一行放在实盘卡里，不再占主页一整行。
- **选桌**（第二屏）：档位是四间主题房的卡片（每张卡是那一档的桌子小图 + 名字 + 盲注 + 星），下面人数、带多少、"坐下开打"；娱乐是三个难度卡；返回回主页。
- **好友房**：输码框在最上面（进别人的房不用选档位），下面选档位和人数开房。
- **等人页**：画成一张桌子，座位是桌边的椅子（有人显示头像和名字，空椅子点了坐下），房间码和"叫朋友来"在桌子上方，"开打"在桌子下方。

## 5. 牌桌

- **背景分层**（从远到近）：
  1. 远景：房间墙面的暗色渐变 + 8–12 个散景光斑（径向渐变的圆，慢慢漂，`transform`/`opacity` 动画）；
  2. 中景：吊灯和吧台的剪影（SVG），按主题换颜色；
  3. 桌面：毡面（主题色）+ 噪点 + 聚光灯光斑（中间亮），木边；中间的水印换成主题房的小徽记；
  4. 灯光：一层从上往下的光锥，赢牌和全下时亮一下。
- **对齐**：8px 网格；座位 = 头像 64 + 名牌 120 × 48，所有座位同尺寸；下注额固定在"座位到桌心连线"离座位 1/3 处；
  底栏分三块固定区域：左（互动、第几手、歇一手）、中（我的头像和底牌）、右（操作区），三块底边对齐；赔率条、加注面板、结算横幅都放在不和座位相交的固定格子里，冒烟里断言互不相交。
- **按钮**：三档高度 36（小）、44（常规，也是最小点按区域）、56（主操作），圆角 12 和全圆两种。
- **筹码和牌**：筹码按面额分色、侧面镶边，下注时一摞一摞叠起来；底池按面额分成几摞；牌面保持现在的画法，翻牌时加一点厚度和阴影。
- **关键时刻的动效**（都只动 `transform`/`opacity`，"减少动态效果"和省内存模式下换成淡入淡出）：
  - 发牌：从荷官位置一张张飞出、轻转落下；
  - 下注：筹码从座位推到下注位，叠起来；一轮结束收进底池；
  - 赢牌：底池拆成几摞飞向赢家，金币闪一下，赢家名牌亮；大锅（≥ 50 个大盲）全屏边缘泛金、短促的金币声；
  - 全下：聚光灯收窄打在全下的人身上，其他座位暗一点，摊牌后恢复；
  - 名场面（河牌逆转、四条、同花顺）：现在的横幅换成画面中间的大字特写，1.2 秒；
  - 转场：主页→牌桌是灯光推近；牌桌→结算是桌面暗下、结算从下面升起。
- **音效**：在现有 WebAudio 合成上补"筹码叠起来""金币""全下低鼓"三种，和上面的动效对齐。

## 6. 电脑版和手机版

- **电脑（1280、1920、更宽）**：横屏舞台照旧按比例铺满；超宽屏（> 2.1 : 1）两侧的远景继续延伸，不留黑边。主页模式卡横排三张，选桌四间主题房一排。
- **手机横屏**：底栏三块按比例收窄，互动按钮只留图标；选桌页档位卡两行两列，不用滚动。
- **手机竖屏**（现在已有竖的牌桌，`layout.ts` 的 `fit`）：主页按"主视觉 → 快速开始 → 模式卡两行 → 战绩"竖排，一屏放下（iPhone SE 375 × 667 为准）；
  牌桌上半屏是桌子和别人，下半屏是我和操作区，底池放在桌子中间偏下（拇指附近看得到）。
- 平板竖着仍用横屏舞台；省内存设备（触屏 + `deviceMemory ≤ 4` 或 `saveData`）关掉远景漂动、浮尘和光扫，只留静止画面。
