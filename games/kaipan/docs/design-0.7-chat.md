# 0.7.0 群友再打磨：性格、每局状态、按局面说话

> 2026-10-16。维护者要求各游戏的电脑"新手场不能太强、性格不能一成不变、性格丰富、体验更好"。
> 开盘没有对手电脑，玩家打交道的"电脑"是韭菜交流群里的群友和股票小人，这一版按开盘的实际情况落地。

## 1. 先评估，再决定改什么

| 问题 | 结论 | 依据 |
|---|---|---|
| 新手难度曲线陡不陡 | 不陡，不改 | 第一次点「快速开始」是阿韭、难度 1。真实行情、正式开关下各 500 局：1–5 月出局 0%，第一次还不上账单最早在 6 月；乱买乱卖的通关 4.8%、跟群的 17%、normal 33–35%、smart 64%。实盘小档乱买乱卖结回约 0.91，最多亏几个百分点 |
| 群友性格单调、说话重复 | 是，主要工作 | 每人每个方向只有 3 句，老王全是"X，可以。"。20 局统计：一局约 450 条群聊，27.6% 是之前见过的原句，同一句一局最多 8 次 |
| 跟不跟局面变 | 基本不跟 | 收盘的道贺、安慰是共用池，谁说随机；连赚、这个月亏多了、月底钱不够、账户新高、大盘转牛转熊都没人接话 |
| 每局一样不一样 | 一样 | 群友的可信度是固定表，玩家记住"老王八成准"就够了，不用看本局战绩 |
| 股票小人 | 重复更严重 | 买入、卖出时的角色台词每种只有 2 句，一局约 100 句里 54% 是重复的，同一句最多 12 次 |

开盘只有单机（娱乐局难度 1–8、实盘四档用难度 1–4），没有好友房，所以"按场地分强弱"在开盘就是难度表本身，这一版不动。

## 2. 每局状态（`friendForm`，隐藏）

每个群友每一局有自己的状态，按种子和群友 id 均匀抽，整局不变：

| 项 | 范围 | 均值 | 作用 |
|---|---|---|---|
| 可信度偏移 | ±0.05（`BALANCE.chat.form.cred`） | 0 | 消息和推荐说对的概率整体挪一点：这局可能比平时准，也可能更不靠谱 |
| 说话权重倍数 | 1 ± 0.25（`BALANCE.chat.form.talk`） | 1 | 这局话多还是话少 |

- 只在真实行情下有。0.3 的合成行情是离线兜底，保持和 0.3 逐位相同（`tests/replay-030.test.ts`）。
- 不进存档：中途读档、中途入群的群友都由种子算出来，结果一样。
- 一天要查几十次（每只候选股都要算一次可信度），按种子缓存，不影响确定性。模拟器 300 局的耗时和改之前在机器负载噪声范围内（6.4–7.4 秒对 6.9–7.7 秒）。
- 加成顺序：基础可信度 + 每局状态 + 擅长题材加成 + 道具 − 难度，再封顶 `credMax`；道具指定的必中（老王的小本本）不受影响。

效果（150 局，normal 打法，本局揭晓 ≥ 10 条的群友）：平均准度不变，单局准度更分散，例如张姐的标准差从 8.6 个百分点到 10.1、老王从 9.2 到 10.0、小李从 9.2 到 9.9。±0.05 比一局几十条消息本身的抽样波动小，效果是温和的；要让"这局他特别准/特别不准"更明显，可以加大 `form.cred`，但要重跑第 7 节的模拟。

## 3. 这局手气（`handOf`，公开）

只看本局公开战绩（和画面上的"说对 x/y"同一个数）：揭晓的消息至少 4 条，说对七成以上算手气好，三成五以下算手气差。手气好或差时，一半的消息句尾带一句口气（`HAND_TAILS`），比如小李手气好时"（又说对了吧）"、手气差时"（再信我一次）"，群主手气差时"（之前是大户在针对我）"。

- 接在句尾，不在开头：气泡只显示一行（13 号字约 15 个字），开头要留给风口和方向，整句在悬停提示里。
- 用单独的随机流（`hand`），消息本身怎么抽一点不变。

## 5. 收盘按局面接话（`makeComments`）

每天收盘最多两条：先按局面有人接一句，再挑一条早上的消息，说对的得意、说错的甩锅（不变）。局面按下面的先后取第一个：

| 时机 | 条件 | 说的概率 |
|---|---|---|
| 账户新高 | 第一次到开局的 2、3、5、10、20、50、100 倍 | 必说 |
| 大赚、大亏 | 有持仓、当天账户涨跌 ±4% 以上（原有） | 必说 |
| 月底钱不够 | 当月最后两个交易日、账户不够还本月账单 | 60% |
| 持仓涨停、跌停 | 原有 | 必说 |
| 连赚 | 有持仓、连续赚钱 3 天以上 | 50% |
| 这个月亏多了 | 比月初少两成以上，月中第 2 天起 | 40% |
| 大盘转牛、转熊 | 今天大环境变了 | 必说 |
| 踩空 | 某个风口涨疯了你一只都没有（原有） | 必说 |

会连着好几天成立的几种按概率说，免得天天念叨。谁接话：只从在群里、对这种时机有台词的人里挑（`REACT_LINES`），表情按人定（`REACT_MOOD`：空军老周看你亏、看转熊是得意，小李自己也难受）。原来的通用道贺、安慰台词留着，有 25% 是随便谁说一句通用的。

收盘的话只是事件，不影响局面。

## 6. 股票小人

- 牛市、熊市时多几句按大盘的说法（`MOOD_QUIPS`）：熊市里涨停"大家都在跌，我偏要涨"，牛市里跌停"我是不是走错片场了"。
- 五种角色的通用台词扩池（买入、卖出每种 9–12 句）。
- 抽法从每次随机改成按种子打乱、按序号轮着用（买入、卖出按第几次买卖，收盘按交易日和格子）。打乱按角色，因为同一角色的通用台词几只股票共用，按股票各抽各的会几只大哥说同一句。推荐语也一样轮着用，推荐语是推荐里最后才定的东西，不从推荐的随机流里抽，推哪只股票不受影响。

## 7. 验证

台词重复（同一套 20 局，真实行情、正式开关、normal 打法；"重复率" = 1 − 不同句数 / 总条数）：

| | 0.6.16 | 0.7.0 |
|---|---|---|
| 群聊合计（消息 + 推荐 + 收盘） | 27.6%，同一句一局最多 8 次 | 9.6%，最多 4 次 |
| 其中盘前消息 | 26.1% | 9.0% |
| 推荐 | 27.0% | 8.6% |
| 收盘吐槽 | 33.1% | 13.6% |
| 股票小人（8 局） | 53.7%，最多 12 次 | 24.5%，最多 4 次 |

另跑 60 局：群聊重复率 9.1%，60 局里有一局的一句推荐出现了 5 次（同一个群友反复推同一只股票）。

模拟器（真实行情、正式开关，每格 2000 局，同一批种子；通关率的标准误约 0.8–1.1 个百分点）：

| 难度 | normal 0.6.16 → 0.7.0 | smart 0.6.16 → 0.7.0 |
|---|---|---|
| 1 | 35.3% → 36.6% | 64.8% → 65.4% |
| 2 | 22.6% → 21.6% | 52.6% → 54.6% |
| 3 | 15.4% → 15.8% | 41.9% → 43.4% |

实盘小档（540 局）：normal 结回 1.051 ± 0.008 → 1.062 ± 0.008，乱买乱卖 0.909 ± 0.007 → 0.905 ± 0.007，跟群 0.930 ± 0.011 → 0.933 ± 0.010，都在误差内。

消息诊断（`--mention`，500 局）：拐点被聊到的倍数 2.14 / 2.43 / 2.35 → 2.13 / 2.41 / 2.36，各类说对率变化不超过 1.5 个百分点。验收第 5 项"消息有用"（真实行情、1000 局）：只关消息时 normal 降 6.2 → 8.5 个百分点，从差一点到达标；其余各项和 0.6.16 一样。

测试：`tests/chat-retrain.test.ts`（每局状态的范围、均值、确定性和接线；手气阈值；各种局面的接话和说的概率；台词表覆盖；股票小人按大盘；正式局群聊和小人台词同种子一字不差、重复率上限）。
