## 0. 约定

### 0.1 基调和写作规范

- 幽默、有人味，像真实的炒股群：有人吹牛、有人装死、有人半夜三点发长语音。不说教，道理放在后果和复盘里。
- 笑点只落在人物和炒股心态上：贪婪、侥幸、马后炮、互相吹牛。不嘲弄真实的个人；写到公司只写时间线里有出处的事实。
- 不使用 emoji。群聊里的表情用文字代替，例如"（哭）""（已撤回）""（沉默）"。
- 术语用真实的美股和券商说法，第一次出现时附一句大白话，例如：
  - 盘前（正式开盘前就能交易的时段）
  - 融资（向券商借钱买股票）
  - 追加保证金，英文叫 margin call（亏到一定程度，券商让你补钱）
  - 强平（补不上钱，券商直接替你卖股票还债）
  - 拆股（一股拆成几股，总价值不变）
  - IPO（新股第一次上市）
  - 熔断/停市（跌太狠或出大事时，交易所暂停交易）
  - 止损单（跌到你定的价格自动卖出）
- 研究结论只写定性结论，不凭记忆写数字；需要数字的地方用回放数据现算。

### 0.2 内容边界（维护者已拍板）

| 类别 | 处理 | 本稿里的例子 |
|---|---|---|
| 有人员伤亡的真实事件 | 严肃、如实，只写它对市场的影响；当天群友不开玩笑，通用模板和段子全部静音（见 10 节 `serious_day`） | 1999 亚特兰大日内交易公司枪击案、1999 台湾集集地震、2000 轮胎召回、2008 汶川地震、2008 飓风艾克 |
| 政治或军事冲突 | 一律不进游戏 | 弹劾案、科索沃、误炸使馆、美舰遇袭、俄格战争、孟买袭击、两届大选的竞选与计票、州长丑闻、澳门回归，全部不写 |
| 经贸政策 | 保留，只客观写对市场的影响 | 中美入世协议、对华永久正常贸易关系法案、中概股赴美上市、救市法案、利率决议 |
| 真实的个人 | 不嘲弄；用化名或职务 | 例如"美联储主席""财政部长""奥马哈老股神" |
| 时间线里"可能缺失"的公司 | 只能作为新闻和群聊话题，不能出现"买入它"的选项 | 见 1 节"可交易"列 |

政治类事件被删掉后，有些行情日没有了"原因"，例如 2000-11-08 纳指大跌。处理办法是新闻条只写行情本身，比如"科技股领跌"，不编造别的原因。

### 0.3 id 规则

- 化名股票 `s_<代码小写>`，例如 `s_qcom`；机构、人物、指数 `x_<名>`。
- 新闻 `n<年两位>_<月日>_<短名>`，例如 `n99_0329_dow10k`。
- 群友 `xiaoli` `laowang` `zhangjie` `qunzhu` `laozhao` `liuge`；成长阶段 `xiaoli_s1`；介入节点 `xiaoli_n1`，选项 `xiaoli_n1_a`。
- 通用反应模板 `tpl_<类型>_<群友>_<序号>`。
- 人设 `ajiu` `zhou` `fang` `coder` `youzi`；章节 `ajiu_c1`；选项 `ajiu_c1_a`；年份变体 `ajiu_c1@1999`。
- 账单 `bill_<人设>_<月>`。事件 `ev_<名>`，年份专属的是 `ev99_` `ev00_` `ev08_`。结局 `end_<人设>_<名>`。偏差 `bias_<名>`。
- 剧情标记（flag）：小写下划线。

### 0.4 剧情可用的机制（只用这些）

| 机制 | 说明 |
|---|---|
| 现金增减 | 一次性加减账户现金（美元） |
| 月供变化 | 某几个月的月底账单加减。借钱 = 现金增加 + 之后几个月月供增加；别人还钱 = 之后几个月月供减少 |
| 融资开关 | 开通或关闭融资账户（按美股规则，见 10 节） |
| 工具 | 低佣金券商、条件单、仓位计算器、资产配置课、交易日志、付费资讯 |
| 信息 | 把某只股票或某条新闻提前展示给玩家，不替玩家下单 |
| 群友关系 | 每个群友一个关系值 `rel`，取 -3 到 +3，开局 0（人设可改）。`rel ≥ 2` 时他会私聊（多给信息或工具）；`rel ≤ -2` 时他把你屏蔽，介入节点里的"劝说"选项失效 |

需要事件替玩家下单、某天无法交易这类能力的地方，单列在 10 节，不假设已实现。

### 0.5 货币、作息和年代外壳

- **货币**：只用美元。开局时主角把人民币换成美元转进美股账户，开局对话里注一句"约合人民币 X 元"。汇率按年份取：1999、2000 年 1 美元约合 8.28 元人民币（几乎固定）；2008 年年初约 7.2，7 月起稳定在 6.83 左右（美联储 H.10 / FRED EXCHUS，见 `docs/research/verification-0.4.md` 第八节；具体数值由数据管线填）。之后每月账单都从账户里按美元扣，账单弹窗可以加一行小字"约合人民币 X 元"。
- **开户的真实性**：1999、2000 年的中国散户开美股账户门槛高、手续麻烦。剧情里用一句话交代：据常见说法，通过在国外的亲戚开户，或者通过香港的券商开户（当时没有合法渠道，这么做属于灰色地带）。不展开，也不教人怎么绕监管。
- **熬夜**：美股交易时间是北京时间深夜，夏令时 21:30–04:00，冬令时 22:30–05:00。游戏里的"昨夜"就是美股的"今天"。群聊时间戳用北京时间，所以大事多半发生在凌晨两三点。
- **群聊外壳随年代变**（建议，具体产品名不写，形式待核对）：
  - 1999：炒股论坛的聊天室，昵称加头像框，消息有"刷新"按钮；
  - 2000：早期即时通讯软件的群，消息有"嘀嘀"提示音；
  - 2008：成熟的即时通讯群，可以发截图。

  群聊里"截图""撤回"等功能按年代换成对应的说法：1999、2000 年的"晒截图"写成"贴战绩"。

## 2. 群友成长线

### 2.0 通用规则

- **人物**：群友都是熬夜炒美股的中国散户。小李是老周的侄子，也是阿韭的大学室友。老王是老周的老同事。张姐是芳姐妈妈群里的朋友。三个人设因此共用同一个群。
- **开口和准不准**：群友说什么由他的偏差决定，说得准不准由真实回放的后续走势决定。规则层只决定"他挑哪只股票、在什么时候开口"，不对结果作弊。复盘时可以如实统计"他喊过的票后来怎样了"。
- **虚拟账户**：小李、老王、刘哥有虚拟账户，只持有可交易的股票，盈亏按回放计算，用来触发"爆仓""套牢股再跌一段"等节点。时间线里不可交易的股票（例如熊斯登），他们只能"嘴上说买了"，由脚本台词处理，结果照史实写（10 节）。
- **阶段时间**：每人一年四个阶段，每个年份的落点见 2.7。
- **严肃日**：遇到有伤亡的事件（`serious_day`），所有人只说严肃台词，或者不说话。

### 2.1 小李：过度自信、频繁交易

- **偏差**：
  - 过度自信能解释为什么交易太多；扣除成本后，交易越多收益越差（Barber & Odean 2000；Barber & Odean 2001）；
  - 赚钱后把运气归功于自己，因此越来越自信（Gervais & Odean 2001）；
  - 偏爱像彩票一样、小概率暴涨的股票（Kumar 2009）。
- **人物**：老周的侄子，阿韭的大学室友，手机和电脑上开着四个看盘窗口，白天上班打瞌睡。
- **开口规则**：
  - 挑近 5 个交易日涨幅最大、成交量突然放大、刚上市或者刚上新闻的股票，喊"还能涨"。
  - 他的发言跟着热度走，所以关注度最高的时候也是他嗓门最大的时候（这是游戏设定；依据是散户的买入集中在正受关注的股票上，Barber & Odean 2008）。
  - 说对了领功，说错了怪别人。
- **四个阶段**：
  1. `xiaoli_s1` 新手运气：小仓位，几次说对，开始自称"美股短线之王"。
  2. `xiaoli_s2` 加码：开融资，一晚上交易十几次，天天贴战绩。
  3. `xiaoli_s3` 爆仓：一次大跌里收到追加保证金通知，补不上，被强平。
  4. `xiaoli_s4` 分岔：
     - `xiaoli_s4_reform`：开始复盘，交易变少；
     - `xiaoli_s4_relapse`：找家里借钱翻本。

     注意：在牛市年份里 `relapse` 线可能反而赚钱，Gervais & Odean 说的正是这种顺序：不是过度自信让人赚钱，而是赚钱让人过度自信。复盘里如实写。

### 2.2 老王：处置效应

- **偏差**：
  - 赚了急着卖，亏了死扛（Shefrin & Statman 1985；Odean 1998）；

## 3. 群聊通用反应模板

用于没有专属新闻台词的日子。严肃日（`serious_day`）全部静音。

### 3.1 触发类型

| 类型 id | 触发条件（建议值） |
|---|---|
| `big_up` 大涨 | 开盘大盘单日 ≥ +3%，或玩家持仓单日 ≥ +10% |
| `big_down` 大跌 | 开盘大盘单日 ≤ -3%，或玩家持仓单日 ≤ -10% |
| `streak_up` 连续上涨 | 开盘大盘连涨 ≥ 5 天，或某只股票连涨 ≥ 5 天且累计 ≥ 20% |
| `blowup` 暴雷 | 某只股票单日 ≤ -25%，且当天有预警、财报重述、降级、破产一类的新闻标签 |
| `ipo_frenzy` IPO 狂热 | 新闻标签为 `ipo`，首日涨幅 ≥ 100% |
| `rate_hike` 加息 | 新闻标签为 `rate_hike` |
| `rate_cut` 降息 | 新闻标签为 `rate_cut` |
| `halt` 熔断或停市 | 新闻标签为 `halt`（例如 2008-10-24 股指期货盘前跌到交易所设的跌幅上限，T08 L139；2000-04-14 道指大跌但并未触发熔断，不打此标签），或者美股休市而别的市场在暴跌（2008-01-21，T08 L19） |

### 3.2 占位符

- `{stock}`：股票化名。
- `{index}`：指数化名，默认"开盘大盘"。
- `{pct}`：涨跌幅，带正负号，例如 -7.3%。
- `{days}`：天数。
- `{rate}`：利率水平。
- `{bp}`：调整幅度，例如 25bp（0.25 个百分点）。
- `{first_day_pct}`：新股首日涨幅。
- `{loss}`：说话人虚拟账户的浮亏金额。
- `{bag}`：老王当年的套牢股。
- `{time}`：北京时间，例如 03:40。

### 3.3 阶段标签

行尾带方括号的，只在对应阶段或分岔使用：
- `[s1-2]`：第 1–2 阶段；
- `[s3+]`：第 3 阶段及以后；
- `[reform]` `[relapse]` `[cut]` `[hold]` `[calm]` `[echo]` `[exposed]` `[rebrand]` `[trend]` `[knife]`：对应的分岔。

不带标签的，任何阶段都可以用。

## 4. 新闻条与群聊

### 4.0 字段说明

每条新闻都有以下字段：

| 字段 | 含义 |
|---|---|
| id | 新闻 id |
| 日期 | 美东日期 |
| 出处 | 时间线行号 |
| `show` | 显示时机，取值见下 |
| 股票 | 关联的化名股票 |
| 标签 | 用于触发 3 节的模板类型，以及 `serious` |
| 新闻文字 | 1–2 句 |
| 群聊 | 2–4 句 |

`show` 有两种取值：
- `pre`：在当天开盘前显示，例如前一晚盘后的预警、周末的收购消息；
- `post`：当天收盘后显示，凡是写了当天涨跌结果的新闻都用 `post`。

这样新闻不会提前泄露当天的收盘结果。

**数字的写法**：带具体点位或涨跌幅的，都是时间线里没有标"待核对"的数字。时间线里标了"待核对"的，这里只写定性描述，或者写成 `{pct}`，由回放数据回填。

**群聊顺序**：大致是阅读顺序，规则层可以按时间戳间隔几分钟发出。括号里的阶段是该群友当时所处的成长阶段（见 2.7）。

**严肃日**：标签含 `serious` 的那天，通用模板、晒收益、抢红包一类的轻松内容全部静音。

## 5. 人设一年剧情

### 5.0 通用约定

**符号**：
- `S`：人设的开局资金（美元）；
- `k`：年份系数，账单按它缩放，建议 1999 = 1.0、2000 = 0.85、2008 = 0.75；
- `m`：目标系数，建议 1999 = 1.30、2000 = 1.00、2008 = 0.90。

`k` 和 `m` 都要用机器人验收后再调：有章法的稳健策略在这一年大约一半的局能达标，并且熊市年也有活路。

**留学/首付专户**：玩家可以把现金转进专户。专户里的钱不能再交易，但结局判定时计入 `nav_end`。现实里这对应"心理账户"（Thaler 1985、1999；Ashraf, Karlan & Yin 2006 的储蓄实验）：给钱贴上用途标签，会让人更不容易动它。这是新机制，见 10 节。

**章节触发**：条件优先，日期兜底。
- 第 1 章：开局第一个交易日。
- 第 2 章：条件见各人设，兜底是 4 月第一个交易日。
- 第 3 章：条件见各人设，兜底是 7 月第一个交易日。
- 第 4 章：10 月第一个交易日。

**年份变体**：章节结构不分年份。每章写三个年份变体（`@1999` `@2000` `@2008`），各用 1–3 句点出当年的背景，插在对话最前面，或者替换掉对话里标 `{year}` 的那一句。

**颜色习惯**：美股软件默认"绿涨红跌"，和 A 股相反。第 1 章教程里让玩家选一种，之后台词里出现的"红了""绿了"按这个设置写。

### 5.1 职场新人阿韭 `ajiu`

- **身份**：在国内一家互联网公司做运营，白天上班，晚上熬夜炒美股。女朋友小雨想和他一起攒首付。小李是他的大学室友。
- **开局资源**：`S` = 10,000 美元（工作两年的积蓄，加上爸妈支援的一点）；现金账户，融资未开通；小李 rel +1。
- **目标**：
  - 大目标"首付线"：`nav_end` ≥ `S × m`，例如 1999 年是 13,000 美元，开局台词里注"约合人民币 X 万"；
  - 保底"本金不亏"：`nav_end` ≥ `S`。

**账单**（`bill_ajiu_<月>`，金额是 `S × 比例 × k`）

| 月 | 名目 | 比例 | 剧情作用 |
|---|---|---|---|
| 1 | 房租 | 1.5% | 交代"工资刚够房租" |
| 2 | 春节回家的路费和红包 | 3% | 亲戚饭桌上被问"炒股赚了多少" |

### 7.1 指标定义（规则层直接计算）

**交易净值**：剔除月供、剧情现金增减、转入专户这些外部资金进出之后的时间加权净值。这样账单和借钱不会被算成"亏损"或"盈利"。下表除 `nav_end` 外，都按交易净值计算。

| 指标 id | 定义 | 建议阈值（机器人验收后再调） |
|---|---|---|
| `nav_end` | 年底净资产 = 现金 + 持仓市值 − 融资负债 + 专户余额 | 按人设目标 |
| `goal_met` | `nav_end` ≥ 目标线 | — |
| `avg_lev` | 每日"持仓市值 ÷ 账户净资产"的年均值 | 高杠杆 > 1.3；无杠杆 ≤ 1.05 |
| `peak_lev` | 同一比值的年内最大值 | — |
| `margin_calls` | 收到追加保证金通知的次数 | — |
| `liquidations` | 被强平的次数 | ≥ 1 视为"爆过" |
| `turnover` | 年内（买入额 + 卖出额）÷ 2 ÷ 平均净资产 | 低 ≤ 1–3 倍；高 ≥ 10 倍 |
| `fee_total` | 全年交易费用 | — |
| `mdd` | 交易净值的最大回撤 | 稳健 ≤ 25%；高 ≥ 40% |
| `max_hold_loser_days` | 单只持仓浮亏 ≥ 15% 之后仍不卖、持续的最长交易日数 | 扛单 ≥ 40 天 |
| `bagholder_end` | 年底仍持有浮亏 ≥ 30%、且已持有 ≥ 120 个交易日的股票 | true / false |
| `chase_ratio` | 追高买入占全部买入的比例。追高 = 买入前 5 个交易日该股涨幅排在股票池前 5%，或买入当天是近 52 周新高，或买的是上市首日的新股 | 追高型 ≥ 40% |
| `herd_ratio` | 跟群买入占全部买入的比例。跟群 = 买入前 2 个交易日内有群友喊过这只股票，或由事件代下单 | 从众型 ≥ 50% |
| `dispo` | 处置效应 PGR − PLR（Odean 1998 的方法，见 8.1） | 明显 ≥ 0.1，且卖出日 ≥ 5 个 |
| `borrowed` | 是否借过钱：`ajiu_borrowed_family`、`ajiu_credit_card`、`credit_card_cash`、`zhou_last_gamble`、`zhou_used_wife_savings`、`fang_relative_loan` 任一为真 | true / false |
| `fang_high_leverage` | `fang_relative_loan` 或 `credit_card_cash` 为真，或 `avg_lev` > 1.05 | true / false |

## 8. 复盘模板

复盘页按严重程度列出这一年最突出的 1–3 种偏差。每种偏差包括：检测方法、证据日（最典型的一天）、文案模板、反事实。反事实全部用真实回放数据现算，不估计。

文案里的日期写成"{date}（美东）／北京时间 {bj_time}"，提醒玩家那是哪个熬夜的晚上。

### 8.1 处置效应 `bias_disposition`

- **计算**（按 Odean 1998 的口径，游戏按单个账户简化）：
  - 每个有卖出的交易日，把账户里每只股票分为四类：已实现盈利（卖了且赚）、已实现亏损（卖了且亏）、账面盈利（没卖、浮盈）、账面亏损（没卖、浮亏）。
  - 全年累加后：
    - PGR = 已实现盈利 ÷（已实现盈利 + 账面盈利）；
    - PLR = 已实现亏损 ÷（已实现亏损 + 账面亏损）；
    - `dispo` = PGR − PLR。
- **证据日**：卖出盈利股、同时留着浮亏最深的股票的那一天。
- **模板**：
  > {date}，你卖掉了赚 {gain_pct} 的 {winner}，却留下了亏 {loss_pct} 的 {loser}。这一年你兑现盈利的比例是 {pgr}，兑现亏损的比例只有 {plr}。
  > 研究里怎么说：人们倾向于过早卖出赚钱的股票、过久持有亏钱的股票（Shefrin & Statman 1985）；在大量散户的真实账户里也是这样，而且被卖掉的赢家，后来往往比留下的输家表现更好（Odean 1998）。
  > 如果当时卖的是 {loser}、留下 {winner}：到年底你会多 {cf_diff}。

### 8.2 过度交易 `bias_overtrading`

- **计算**：
  - `turnover` 和 `fee_total`；
  - "换股反事实"（借鉴 Odean 1999 的思路，参数为游戏简化）：每次在 3 个交易日内卖出 A、买入 B，比较此后 60 个交易日 A 和 B 的收益。原研究看的是卖出后三周内的买入，比较 4 个月、1 年、2 年后的收益。
- **证据日**：换股反事实里亏得最多的那一次。
- **模板**：
  > 这一年你换手 {turnover} 倍，手续费一共 {fees}，相当于 {fee_months} 个月的账单。
  > {date}，你卖掉 {sold}，换成 {bought}。之后 60 个交易日，{sold} {sold_ret}，{bought} {bought_ret}。
  > 研究里怎么说：交易最频繁的散户，收益明显落后（Barber & Odean 2000）；他们卖掉的股票，后来平均比买进的更好（Odean 1999）。
  > 如果你年初的持仓一直不动：年底是 {cf_buyhold}，你实际是 {nav_end}。

### 8.3 追高 `bias_chasing`

- **计算**：`chase_ratio`；每笔追高买入此后 20 个交易日的收益，和同期开盘大盘比较。
- **证据日**：追高后 20 日跌得最多的一笔。
- **模板**：
  > {date}，{stock} 前 5 天涨了 {pre_ret}，新闻和群里都在说它，你买了。之后 20 天，它 {post_ret}，同期大盘 {mkt_ret}。
  > 研究里怎么说：散户更容易买入正受关注的股票，比如上了新闻、成交量异常、涨跌异常的股票（Barber & Odean 2008）；人们对未来收益的预期，会跟着过去的涨幅往外推（Greenwood & Shleifer 2014）。
  > 如果那天没买，等 20 天再决定：你会少亏 {cf_diff}。
- **年份提示**（只在对应年份追加一句）：
  - 1999 年：这一年追高常常被奖励。你的追高买入平均 {chase_avg}，复盘也把它写出来；接下来的一年会发生什么，见尾声。
  - 2000、2008 年：不追加。

### 8.4 杠杆过度 `bias_leverage`

- **计算**：`avg_lev`、`peak_lev`、`margin_calls`、`liquidations`、接近维持保证金线的天数；收益归因里"杠杆放大"的那一部分。
- **证据日**：强平日；没被强平就取追加保证金通知日；都没有就取杠杆最高的那天。
- **模板**：
  > {date}，你的杠杆是 {lev} 倍。账户离维持保证金线只差 {gap}。{forced_text}
  > 研究里怎么说：借钱的人在下跌时可能因保证金不足被迫卖出，卖在价格被压低的时候，大家一起被迫卖出又会让下跌更深（Brunnermeier & Pedersen 2009）；美国 2010 年给散户外汇交易设了杠杆上限，此后高杠杆者的亏损明显减少（Heimer & Simsek 2019）。
  > 如果这一年不加杠杆、其余操作不变：年底是 {cf_nolev}，最大回撤从 {mdd} 变成 {cf_mdd}。
- **借钱的补充**：如果借过钱（`borrowed`），再加一句：
  > 你还借过 {borrowed_amount}，为此多付了 {interest} 的账单。

### 8.5 从众 `bias_herding`

- **计算**：
  - `herd_ratio`；
  - 跟群买入和自主买入此后 20 日收益的对比；
  - 按群友分别统计"你跟了谁、跟得怎样"。
- **证据日**：跟群买入后 20 日亏得最多的一笔。
- **模板**：
  > 你这一年 {herd_ratio} 的买入发生在群友喊单之后。跟着 {friend} 买了 {n} 次，20 天后平均 {avg_ret}。
  > {date}，{friend} 说"{quote}"，你买了 {stock}，之后 20 天 {post_ret}。
  > 研究里怎么说：当人们照着别人的做法、而不是自己的信息做决定时，整群人可能一起锁定在错误的选择上（Bikhchandani, Hirshleifer & Welch 1992）；人们更爱分享赚钱的经历（Han, Hirshleifer & Walden 2022），所以群里看到的收益往往偏高。
  > 如果那次你没跟：少亏 {cf_diff}。

### 8.6 扛单 `bias_bagholding`

- **计算**：`max_hold_loser_days`、`bagholder_end`；挂过止损单的仓位和没挂的仓位对比。
- **模板**：
  > {stock} 从 {date_start} 开始浮亏超过 15%，你一直拿到 {date_end}，最深的时候亏了 {worst}。
  > 研究里怎么说：面对亏损，人往往宁愿赌一把，也不接受确定的损失（Kahneman & Tversky 1979）；亏了之后，"有机会回本"的选择显得特别诱人（Thaler & Johnson 1990）。实验室实验发现，提前挂好止损/止盈单的人，更肯在亏损时卖出（Fischbacher, Hoffmann & Schudy 2017）。
  > 如果当时在 -8% 挂了止损：你会少亏 {cf_diff}。
- **如实原则**：如果止损会让玩家卖在反弹之前，模板改为：
  > 这一次，止损会让你错过之后的 {missed}。止损不保证每次都对，它保证的是最坏情况有底。

### 8.7 复盘页尾：群友的成绩单

## 10. 需要规则层支持

1. **融资改按美股规则**（替代原稿里的 A 股规则和场外配资）：
   - 现金账户和融资账户两种；融资需要开通，开通后可以随时关闭（有负债时要先还清）。
   - 初始保证金按 Reg T，建议 50%；维持保证金按 FINRA 4210 的下限，建议 25%，券商通常更高，游戏里建议取一个更高的"券商线"，例如 30%。以上数值都待核对。
   - 跌破维持线 → 发出追加保证金通知（`ev_margin_call`）→ 给一个期限（建议到下一个交易日收盘）→ 仍不足就在下一个开盘价强平，按差额卖出。
   - 融资利息按年化每日计息，利率按年代取值，待核对。
   - 1999、2000、2008 年的规则差异（例如日内交易的最低净资产要求）原型阶段不做，依据页注明。
2. **场外配资删除**。高杠杆诱惑改为三种，都用"借钱 = 现金增加 + 之后几个月账单增加"的组合机制实现：
   - 信用卡取现（`ev_credit_card`）；
   - 找亲戚借钱（`ajiu_c3_b`、`fang_c3_a`、`zhou_c4_a`）；
   - 券商推销融资（`ev_broker_margin`）。
3. **新闻条数据**：每条新闻需要以下字段。
   - `id`、`date`（美东）、`show`（`pre` / `post`）、`source_ref`（时间线行号）、`stocks[]`（化名 id）、`tags[]`、`serious`（布尔）、`text`。
   - `chat[]`：每条群聊含 `friend`、`text`、`stage_filter`、`branch_filter`、`delay_min`。
   - 显示规则：`pre` 在当天开盘前显示，`post` 在当天收盘后显示；不能提前泄露当天的行情结果。
4. **群聊数据**：
   - 3 节的通用模板，按类型、群友、阶段和分岔标签筛选；占位符见 3.2。
   - 触发类型由规则层根据行情和新闻标签判定。
   - `serious_day`：新闻标签含 `serious` 的那一天，通用模板、晒收益、抢红包一类内容全部静音，只播新闻自带的严肃台词。
5. **群友系统**：
   - 关系值 `rel`；
   - 成长线阶段状态机（阶段 + 分岔），按"条件优先、日期兜底"推进（2.7）；
   - 小李、老王、刘哥的虚拟账户，只持有可交易股票；
   - 不可交易股票上的"持仓"只由脚本台词处理；
   - 喊单记录（日期、股票、方向），供 `herd_ratio`、对账节点和群友成绩单使用。
6. **化名映射**：数据管线按 1 节把真实代码映射成化名和改写代码。改写代码要检查不和 1996–2018 年任何真实代码重名，重名就换一个字母，并在本表回填。
7. **可交易表**：数据管线实查 WIKI 后输出每年的可交易股票表。剧情侧据此保证：不可交易的公司只出现在新闻和群聊里，事件和章节不出现买入它的选项。实查结果和 1 节"可交易"列不一致时，以实查为准，并通知剧情侧改台词。
8. **事件代下单**：
   - "按下一个开盘价买入 1/4 仓位"（`ev_cousin_tip`、`ev99_ipo_chase`）；
   - "打开卖出面板并预填数量"（`ev_margin_call`、`ev99_y2k`、`ev00_tax_day`）；
   - "清仓并转入专户"（`ajiu_c4_c`、`zhou_c4_c`、`fang_c4_a`）。
9. **当天无法交易**（`ev99_broker_outage`）：当天挂单失效。
10. **专户**：现金转入后不可交易、不可转回，结局计入 `nav_end`，交易净值计算时视为资金转出。
11. **剧情 flag**：布尔和计数两类，存档、复盘、结局判定都要读。本稿用到的 flag 都写在各选项里。
12. **定时现金和账单**：某个日期才生效的现金增减（`ev00_deadpool` 在 2000-11-07 返还），以及从某个日期起停止的账单减免（`ev08_stable_product` 在 2008-12-11 停发）。
13. **交易净值、7.1 的全部指标、8 节的反事实**：不加杠杆、买入持有、换股对比、假设止损、跟群和自主买入对比，都基于同一份回放。
14. **年份参数**：`k`、`m`、汇率（人民币对美元，按年份）、群聊外壳、"绿涨红跌 / 红涨绿跌"颜色设置。
15. **章节触发**：条件优先、日期兜底（5.0）。章节所在的那一周不触发事件池里的事件。
16. **"冷静三天"提醒**（`fang_cooling_rule`、`fang_c4_c`）：玩家跟群买入前弹出一次提醒，不阻止下单。
17. **借钱的组合机制**：现金增加 + 之后 N 个月账单增加；别人还钱 = 之后 N 个月账单减少。
