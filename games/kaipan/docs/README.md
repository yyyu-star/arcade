# 文档索引

文档写的是代码现状；各版改了什么看 `../CHANGELOG.md`。早期版本的设计稿已经删掉，需要时从 Git 历史里找。文档和代码对不上时以代码为准，并顺手把文档改对。

## 玩法和规则

- `design.md`：玩法总设计：设计支柱、小白词表、文案规矩、一天和一个月怎么玩、真实行情、仓位押跌抵押、群聊情报、账单、节奏、道具事件、人设难度、成就、结局。
- `core-api.md`：规则核心的接口与数值：入口函数、GameState、操作、事件、查询、行情段文件格式、隐藏信息、URL 参数。
- `design-0.7-chat.md`：群友和股票小人：每局状态、这局手气、性格表、收盘按局面接话、台词轮换和验证口径。
- `design-balance.md`：配平：小白、普通两个玩家模型，实盘各档和娱乐各难度的实测，一局多久怎么估。

## 模式和平台功能

- `design-live.md`：实盘（筹码）：一局的样子、带入结回、杠杆、钱包接口、战绩小结、错误文案对照。
- `design-challenge.md`：好友挑战：链接里带什么、怎么开局、成绩比什么、平台接口。
- `design-share.md`：分享卡：交给 `arcade-kit/share` 的数据和名场面模板。

## 画面

- `art-v3.md`：美术与界面：方向、材质、字体、小屋的光、主页、对局画面、关键时刻、铺满。
- `design-0.5-visual.md`：画面上的信息怎么放：少写字、信息不减、各处放什么。
- `mobile.md`：手机和平板：什么时候用手机布局、世界尺寸、最小字号和点击区、竖屏提示、各画面在手机上的排法。
