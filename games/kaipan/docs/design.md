> 这是《开盘》玩法的总设计稿，写"现在的游戏是什么样、为什么这样"。数值以 `src/core/balance.ts` 为准，内容以 `src/core/content/` 为准，

> 专题另有现行稿，这里只指过去：画面去文字化 `design-0.5-visual.md`、群友和小人的性格与接话 `design-0.7-chat.md`、
> 实盘（筹码）`design-live.md`、难度与收益配平 `design-balance.md`、分享 `design-share.md`、好友挑战 `design-challenge.md`、

## 1. 总览与设计支柱

一款股市主题的肉鸽网页游戏：玩家是一个散户，每天盘前看群聊里的小道消息和推荐，挑股票小人进持仓，开盘看结果，月底还一笔越来越离谱的账单，
撑过去再三选一领奖励，一直打到年底。

1. **游戏为主、娱乐为主，让人快乐。** 真实性只为让涨跌像真的；不能做成炒股软件，不堆术语、不堆长句。
   能用图标、数字、颜色、动画表达的就不写字，但删掉的信息必须有替代，画面不能空。
2. **每天最多点两下**：买一只或卖一只，然后开盘。一个数字、一条主线：账户余额是唯一的分数，所有内容都通过"风口"和"角色"起作用。
3. **有选择、有取舍**：每只买多少、押涨还是押跌、借不借钱、信哪个群友。每个新机制都要能用一句话说清楚，说不清就砍。
4. **高难但公平**：难度靠"信息与判断"变难，不靠运气杀人；牛市不能躺赢，熊市和崩盘也要有通关路径。
5. **搭配丰富**：规则表只有几行，每个道具只改其中一格，组合靠风口集中、角色搭配、消息来源。
6. **全部虚构**：股票、公司、群友都是化名和小人，不出现真实公司、真人、真实机构、政治、军事或真实社会事件；
   伤亡、灾害类事件不进故事，不拿来搞笑。真实行情只驱动涨跌，不露年份和公司。

模式有两种入口，共用同一套规则核心：**娱乐**（本稿主体：完整一年或 5 个月短局、每日挑战、好友挑战）和**实盘**（带筹码打 5 个月，见 `design-live.md`）。
规则核心在 `src/core/`，是纯函数、带种子、同一个行情段 + 种子 + 操作结果逐位相同；画面层只读状态和事件。

## 2. 小白词表

画面、道具和事件描述、群聊台词、提示一律用左边的说法；A 股原词只作括注，出现在提示和图鉴词典里。
词表的权威实现是 `src/view/glossary.ts`（词典页签逐条列出，附一句笑话式例子）和 `src/core/labels.ts`；`tests/content-terms.test.ts`、
`tests/view-copy.test.ts` 按这张表扫描文案。

| 新说法 | 原来的词 | 一句话解释（提示里用） |
|---|---|---|
| 风口 | 题材 | 大家正在炒的话题，比如 AI、新能源。同一个风口的股票一起涨跌。 |
| 热度 | 热度 | 这个风口有多火，0–100。热度涨，它的股票就涨；热度跌，股票就跌。 |
| 冷清 / 要火 / 正火 / 太火 / 降温 | 冷门 / 萌芽·升温 / 发酵·主升 / 过热·高潮 / 退潮 | 看板上的公开状态，按公开的热度和走势算，不是隐藏的真实阶段。 |
| 快正火 | 发酵 | 只有带「风口温度计」「熬夜复盘」这类道具才看得到的真实状态：刚火起来、还没到最猛；看板上算在「正火」一档。 |
| 带头大哥 | 龙头 | 风口里最猛的那只，涨得多也跌得多；它涨停时会带着小弟一起涨。 |
| 小弟 | 跟风 | 跟着大哥走，大哥涨停它也沾光。 |
| 老实股 | 白马 | 涨得慢、跌得也少，适合压舱。 |
| 过山车 | 妖股 | 经常突然暴涨或暴跌，刺激但危险。 |
| 危险股 | ST | 公司出了问题，每天最多涨跌 5%；可能翻身（连着几天涨停），也可能退市归零。 |
| 涨停 / 跌停 | 同 | 一天最多涨 10%（跌 10%），涨满就叫涨停；道具的加成可以让收益超过 10%。 |
| 连续涨停 N 天 | N 连板 | 越连越猛，但随时可能"没封住"。 |
| 涨停没封住 | 炸板 | 本来涨停，收盘前被砸下来了。 |
| 大哥带小弟 | 龙头带动 | 带头大哥涨停时，同风口的小弟额外涨一点。 |
| 今天买，明天才能卖 | T+1 | 不出现"T+1"字样。 |
| 换掉一只 | 换仓 | 持仓格满了，卖掉一只，把新的放进它的格子。 |
| 说对 5/7 | 说中 5/7 | 这个群友这局说了 7 次，说对 5 次；还没说过的写「新来的」。 |
| 要变天了 | 拐点 | 群友觉得风口要转向了：要火了、到顶了、要凉了。 |
| 不动 | 横 / 横盘 | 群友觉得风口今天不怎么涨也不怎么跌。 |
| 买入以来 +37% | 持有 +37% | 从买进到现在一共涨跌了多少。 |
| 大环境：好 / 一般 / 差 | 大盘 晴 / 阴 / 雨 | 整个市场今天好不好；窗外天气只是图，文字要直说。 |
| 这个月要还 | 月供 | 首次提示："每个月底要从账户里还一笔钱，名目越来越离谱。还不上，游戏就结束。" |
| 游戏结束 | 爆仓 | 月底账户不够还这个月要还的钱。 |
| 借钱炒股 | 两融 | 借钱放大收益：赚的时候多赚，亏的时候也多亏。 |
| 抽中新股 | 打新中签 | 每个月初账户涨一点点。 |
| 冷时买的 | 低吸 | 你是在它冷清或降温时买的，带「抄底大师」才有加成。 |
| 押跌 | 做空 | 它跌你赚，它涨你亏。 |
| 重仓 / 加仓 / 减一半 | 仓位、满仓、减仓 | 买多少自己定（见第 6 节）。"加仓"是玩法按钮的名字，所以放开；"仓位""满仓"仍不出现在正文。 |
| 银行打电话 / 收走 / 赎回 | 追保 / 强平 / 解押 | 见第 6.4 节。 |

其他原则：
- 道具、事件、日历、人设、成就、难度的名字可以保留有梗的说法，但描述一律写成"什么时候 → 发生什么"的大白话，不出现未解释的术语。
- 数字要说明意思：写"赚了 ¥5,890"，不写"+5.9%"；百分比只作补充。
- 群主在文案里叫"韭菜收割机"（群里显示的名字），"群主"只当身份标签，免得新手以为是两个人。
- "拉"只许用在"拉你去……""被拉进群"这类意思上，不当"拉升"讲。
- 实盘的"杠杆"是玩法名（稳健 1× / 进取 2× / 疯狂 3×），放开；"爆仓""融资"仍不许，说"清零线""利息"。

## 3. 面向玩家的文案规矩

- **口吻**：像群里一个靠谱的朋友在说话——短句，一句只说一件事，先结论后原因。幽默来自人物和处境（群主卖课、表舅爆仓、猫比我有钱），
  不来自术语；不说教，不用"注意""请"开头的命令句，提示用"可以……""小心……"。
- **新词**：第一次出现时，要么能悬停或点开看到解释，要么旁边直接带半句解释。
- **标点与格式**：中文全角标点；数字和单位之间不加空格（¥5,890、+10%）；不使用 emoji（没有彩色字体的环境会显示成方框）。
- **不泄露隐藏信息**：收盘小结、新闻、台词、新手提示都只用当天已经揭晓的信息或公开信息；真实阶段只通过相应道具给出。
- **押跌、借钱一律大白话**：「保证金、维持、Reg T、融资融券、追保」之类哪儿都不出现；真实说法（做空、仓位、强平……）只出现在小知识卡
  "真实世界里叫……"那一行。
- **检查靠测试**：
  - `tests/content-terms.test.ts` 扫规则层所有面向玩家的字符串字面量（内容表、labels、queries、引擎提示、新闻、台词、归因）；
  - `tests/view-copy.test.ts` 扫 `src/view` 的字符串字面量，并检查没有 emoji；词典（glossary.ts）里的括注原词除外；
  - 禁用词表以这两个测试里的列表为准（本稿第 2 节左列之外的 A 股行话，如 T+1、龙头、跟风、白马、妖股、题材、拐点、炸板、连板、换仓、两融、
    月供、大盘、爆仓、种子等），股票名里的"ST"除外；括注里的原词（"（也叫分红）"）可以，正文直接说不行。
  - 改文案或加新词时，先改词表，再改两个测试里的列表，三处保持一致。
- **小白试读**：加较大的新机制或改版后，找一个没炒过股的人（或另派一个扮演新手的审阅者）只看截图和文案，列出看不懂的地方，全部处理完才算通过。
- **画面上的短话**：画面层的文字量规则（短话、图标代文字）见 `design-0.5-visual.md`。

## 4. 一局怎么玩

### 4.1 开局

- 选**人设**（第 11 节）和**难度**（第 11 节），再选**短局还是完整一年**。第一次玩默认短局；"快速开始"沿用上次的选择。
- 后台按种子从行情段库里抽一段真实行情（第 5 节），不告诉玩家是哪段。每日挑战大家抽到同一段、同一人设、同一难度（难度 2–5 级）。
- 开局账户由人设定（默认 ¥100,000），持仓 4 格，群里有 6 个开局群友，每局登场 8 个风口里的 6 个（人设可指定必出的）。
- **完整一年**：12 个月，每月 5 个交易日（10 月国庆只有 3 个），共 58 个交易日。
- **短局**：5 个月，月供打 2.5 折（`BALANCE.short`），最后一个月月底多交一笔"首付"，数额是开局资产的几成（按难度 0.95 / 1.05 / 1.12，
  缺的按最后一个）。目标在开局和顶栏就说清楚。短局没有第 4、8 个月的中场关，月度主题照常抽。

### 4.2 每一天

1. **盘前**：群里出现 2–4 条风口消息（某群友对某风口说"涨 / 不动 / 跌"，附一句有性格的台词），并推荐 3 只股票（带推荐人和理由）。
   消息针对风口，推荐针对个股；怎么判断信谁见第 7 节。
2. **操作**：每天默认最多买 1 只（从推荐里挑）；放进空格，或换掉一只已持有的；开盘前随时可以卖出持仓。
   今天买的明天才能卖（"今天买，明天才能卖"）。买入时可选买多少、押涨还是押跌（第 6 节）。
3. **开盘**：玩家按"开盘"，一天自动结算并播放，可跳过：风口热度变化（升温冒火、降温结冰）→ 大环境天气 → 持仓小人一张张翻牌揭晓涨跌 →
   带头大哥涨停时向小弟画连线 → 道具触发闪一下并写明改动 → 账户数字滚动，涨停放烟花、跌停下雨云，群友吐槽。
4. **收盘**：
   - **收盘小结**：第一句是总账（"今天赚了 ¥5,890，主要靠 AI 风口"），下面每只持仓一行大白话说明为什么赚、为什么亏；点持仓卡看拆解条。
     可在设置里改成只显示总账一句。这样玩家总能知道钱是怎么来的。
   - **收盘新闻**：热度变化最大的风口一定有一条虚构新闻（只解释已经发生的事，不预告）；第二条要求热度变化够大；大环境涨跌够大时加一条全场新闻。
   - **股票小人台词**：涨停、跌停、连续涨停、退市、被买入、被卖出时冒一句，每只持仓每天最多一句。
   - **群友吐槽**：赚大钱、亏大钱、涨停、跌停、踩空（某风口大涨而你一只都没有）各有说法。
   - **新手提示**（可关）：猫（或阿韭的内心独白）只用公开信息说一句建议，并承认"我也是猜的"。前 3 局默认开，之后默认关。

### 4.3 每月

- **月初**：公布本月日历效果、本月主题和目标（第 9 节）、本月要还的钱（含突发账单）。顶栏一直显示"本月要还 ¥X · 还剩 N 天"。
- **月底**：账单滑入。够还就盖"已还清"；不够就盖"逾期"，**游戏结束**（有信用卡道具时自动代还一次，下个月要还的钱多两成）。
  开了借钱的局，先付利息再还月供，再看银行是否打电话或收走抵押物。
- 还清后**三选一奖励**（第 10 节），之后约 40% 的概率触发一个**事件**（二选一，后果写在选项里）。
- 第 12 个月（短局是最后一个月）还完就通关，进结局（第 13 节）。

### 4.4 快进

平淡的日子不打断节奏。盘前算平淡（`premarketQuiet`）要同时满足：不是月初、没有弹出的提示、没有重磅消息、
没有"空格还在、今天还能买、推荐还没买完"的情况、群里没人说你拿着的风口要反着走（反着信的群友按反方向读；带转折的消息只要说到你拿着的风口就算）；
上一天收盘也要平淡（`tempoClose` 的 `quiet`：没碰到高光、事件、目标变化）。
平淡日显示器上写「平静日」，给一个"快进"按钮（F 键）；设置里「平淡日」开着（默认开）时，停一小会儿后自动快进开盘，点一下或按键就这一天停下。
教程在说话、对话框开着时不自动。快进时结算节拍加快，只看账户跳动。

## 5. 真实行情怎么驱动

涨跌来自 1996–2018 年美股真实历史行情（WIKI Prices，公有领域），预先切成 135 个"行情段"，长度等于一局的交易日数，只存逐日涨跌基点。
**游戏是游戏，真实只用来让涨跌像真的**：不是炒股模拟，不露年份、公司和代码，也不展示真实价格。

- **不露年份公司**：段文件名是加盐哈希的不透明 id；局内局外画面都不出现年份、日期、真实公司名和任何 id，不展示"小人 → 真身"；
  真实公司全部用化名。年份对照只在数据管线的清单里，`tests/segments-leak.test.ts` 保证线上文件不含年份日期。
- **个股照搬真实走势**：每只股票小人绑定一只真实股票，当天涨跌 = 那只真实股票当天的真实涨跌 × 统一放大系数（所有股票相同，不改方向和相对大小），
  再按游戏规则做涨跌停截断。目标是逐日相关 ≥ 0.9（`node tools/realness.ts` 实测），大盘同样。
  连续涨停、炸板、妖股异动、大哥带小弟这些不再额外改走势，而是**从真实走势里识别出来并播报**（连续大涨就是连板，大涨后大跌就是炸板）。
- **风口来自真实行业**：每个风口对应一个真实行业，热度由该行业的相对强弱推出（跑赢别的行业热度涨，跑输就跌，没人炒慢慢凉），
  所以风口轮动是真实轮动；"冷清 → 要火 → 快正火 → 正火 → 太火 → 降温"由热度和变化走一个只能顺序前进的状态机判定
  （要火可以夭折回冷清，快正火可以被证伪直接降温）。群聊里的"要火了、到顶了、要凉了"也由此而来。
- **大环境**来自合成大盘的真实涨跌，按最近几天平均分好 / 一般 / 差，窗外天气是它的画面。
- **性格校正**：带头大哥、小弟、老实股、过山车、危险股按真实股票在这一段里的波动和与行业的相关性分配，而不是反过来改走势。
- **市况**（牛、熊、泡沫、崩盘、横盘）只在局末揭晓，但它会悄悄影响月供倍数：牛市和泡沫里拿着不动也会涨，所以月供乘一个大于 1 的数，
  让"牛市躺赢"不成立，熊市和崩盘也有通关路径。
- **道具与难度作用在"信息"和"规则"上**（多一条情报、提前看一天、手续费、涨停宽窄、月供高低），不改走势本身。
- **股灾对齐真实**：第 6 级难度的"股灾"月份里，大盘真实跌得最狠的那天就是股灾发生的那天（够狠时才对齐，否则按种子）。
- **确定性**：同一个行情段 id + 种子 + 操作，结果逐位相同；规则核心只用加减乘除和比较，不用 exp、log、三角函数。
- **合成行情**：行情段加载不上时的离线兜底（`?market=synthetic`）。它用另一套"风口生命周期 + 大盘 + 角色噪声"的随机模型，
  只为兜底和老回放（`tests/replay-030.test.ts`）保持逐位一致，不是玩法的一部分，本稿不展开。
- **数据来源与管线**：见 `AGENTS.md` 第 5 节；图鉴"行情段"页只留一句"涨跌取自真实历史行情（公有领域数据），公司和时间都隐去了"。

## 6. 仓位、押跌、抵押

### 6.1 原则

1. 快乐、好玩、一看就懂；
2. 玩法有选择、有取舍（买多少、方向、借不借钱）；
3. 顺手学到一点：只用一句大白话和图鉴里的"小知识"，不讲规则条文，学习历史和行情优先级很低。

每个机制都要能用一句话说清楚，否则砍掉。术语一律大白话，真实说法最多出现在小知识的"真实世界里叫……"一行（第 6.5 节）。
这些机制只在 `ext` 打开的局里出现（正式游戏都开）。

### 6.2 仓位：每只买多少自己定

- 买入时选"试一口 / 半仓 / 重仓"。账户按"份"算，1 份 = 账户的 1/4，总份数 = 格子数：试一口 1 份，半仓 2 份，重仓 = 剩下的全部。
  已有持仓可以"加仓"（+1 份，算一次买入）、"减一半"（按半份取整）、"清仓"。账户涨跌按份数加权。
- **冲击成本**：一次买超过 1 份，多出来的每份让这一笔多花 1.2%（重仓 4 份约多花账户的 3.6%）。为什么：不加的话"一次全压上"明显好过慢慢买，
  机器人实测会把"买多少自己定"变成没有取舍的最优解。
- 格子空着就是现金，不涨不跌，会拖累收益；多开格子能分散风险。卡片厚度或筹码堆高度表现仓位大小。
- 收盘小结照旧讲"赚亏主要来自哪只"，重仓的那只自然被点名。

### 6.3 押跌：它跌你赚，它涨你亏

- 一开始不开放。解锁途径：「押跌许可证」道具、月度主题「空头来袭」和中场「股灾来袭」（本月白送）、人设「炒股大佬」、事件奖励。
  不按难度白送：难度越高越送会让会看消息的机器人在高难度反而更好打，梯度倒挂。
- 规则：只能押推荐里的股票（空军老周的推荐默认建议押跌）；押跌的仓位也占格子；只走自动卖出，不吃"买涨"类道具；
  每天手续费 0.3%（借股票要给钱）；押跌的股票当天涨停会被"轧"，亏损再多一半（「空军墨镜」减半）。
- 顺风逆风：大环境最近在涨，押跌逆风；最近在跌，押跌顺风，每天最多 ±2 个百分点。不加的话押跌只吃风口轮动、和牛熊无关，
  牛市里押跌赚得和崩盘一样多，不合理。
- 风口降温、崩盘事件时，押跌是翻身的机会；群友里有人专门唱空（空军老周），可能对也可能是坑。

### 6.4 抵押：借钱加杠杆

- 一句话："把东西押给银行，多借一笔钱炒股；赚了翻倍，亏了东西没了。"
- 银行第 2 个月开门。抵押物是有梗的东西：老婆的金镯子、车、房子、爸妈的养老钱，各自借出的钱和每月利息不同，难度越高开放得越多
  （金镯子和车 1 级起，房子 3 级起，养老钱 5 级起；难度每高一级借款 +10%、利息 +10%）。
- 借来的钱加进本金。每月月底先付利息再还月供。利息定得高（每月 6%–10%）：利息低时"借钱交月供"几乎稳赚，抵押就成了最优解；
  抵押应该能放大胜负（高方差），但不是最优解。
- 风控三条线（按账户 ÷ 欠款）：借完至少 1.6 倍才肯借；跌到 1.45 倍银行打电话提醒；跌到 1.25 倍先收走借得最多的那件（扣回借款 + 两成违约金），
  直到回到线上。一年结束，银行收回没还的借款。
- 赎回：手头宽裕时还钱赎回，拿回抵押物（成就"赎身"）。「银行有熟人」减利息，月度主题「银行搞活动」利息减半。
- 群友对重仓、押跌、抵押要有反应台词。

### 6.5 小知识（学习只做彩蛋）

图鉴有一页"小知识"，局中第一次触发某个机制就点亮一张卡并写进档案：买多少自己定、重仓、加仓、减一半、押跌、被轧、借钱炒股、利息、
银行打电话、收走抵押物、赎回来，共 11 张。每张是：一句大白话 + 一句"真实世界里叫……"（例如"押跌，真实世界里叫做空"）。
第一次遇到每个新机制时还有一句提示，三步之内能操作。局末的小故事已经承担"那段时间发生了什么"，不再另做历史课。

## 7. 群聊与情报

群聊是信息系统，也是游戏性的来源：走势是真的，玩家要判断信谁。

- **情报从真实未来推算**：群友的消息和推荐在发出时，读取这段行情接下来 1–3 天的真实走势（消息说几天，权重 8 : 3 : 1），
  按群友这一局的靠谱程度决定说对的概率；说错时改说另外两种方向之一。"说对"指说的方向等于接下来累计涨跌的方向（累计在一条窄带内算"不动"）。
  准确率是参数（`BALANCE.intel`），难度每高一级所有群友 −2 个百分点。
- **群友**（人设和说话风格见 `design-0.7-chat.md`）：

| 群友 | 擅长 | 擅长 / 其他的准确率 | 特点 |
|---|---|---|---|
| 小李（大学生） | AI、游戏传媒 | 0.70 / 0.50 | 冲！起飞！ |
| 老王（退休教师） | 金融、大消费 | 0.85 / 0.55 | 话少，稳 |
| 张姐（宝妈） | 医药、大消费 | 0.75 / 0.50 | 转发妈妈群的消息 |
| 韭菜收割机（群主） | 全部 | 0.30（反指） | 天天喊单卖课，专挑高位出货；说错时 80% 直接反着说 |
| 老赵（老股民） | 低空经济、过山车股 | 0.85 / 0.50 | 懂的都懂 |
| 股市小诸葛（大V） | 当前最火的风口 | 0.55 | 直播口头禅 |
| 内幕哥 / 猪场老板 / 空军老周 | 随机两个风口 / 养猪 / 全部（唱空） | 0.90 / 0.90 / 0.55 | 道具、奖励或押跌许可带来的新群友 |

- **每局状态**：每个群友这一局的准确率在 ±5 个百分点内浮动、说话频率 ±25%（均值不变），玩家得看本局战绩，不能背表。
  头像上显示本局战绩"说对 5/7"，新来的写「新来的」。
- **群友爱在"要变天了"的日子开口**：风口刚启动、见顶、降温的日子，被聊到的概率更高，台词也用拐点的说法，靠谱群友在这时更准，
  所以消息在关键时刻有用。
- **推荐**：每天 3 只，偏向推荐人擅长的风口，但不保证涨；靠谱的群友推荐的股票更可能处在好阶段，群主专挑高位出货和过山车股，整体偏向带头大哥。
- **准确率上限 0.95**：所有加成之后封顶，只有道具指定的才能"必中"（「老王的小本本」）。否则界面显示"必中"、实际也必中，等于剧透当天方向。
- **猫的建议、新闻预告**（"某风口有消息面利好"，每天最多 1 条）、**重磅情报 / 提前看一天**也读真实未来，各有准确率。
- **公平底线**：画面上展示的走势、强弱只能用已发生的数据和开局前历史，不能偷看未来；情报是游戏机制（有概率说错），不是泄露。
  难度"消息失真"会让群里 80% 的消息变成瞎传，推荐不受影响。
- 群友收盘后对结果吐槽或甩锅；"关闭群聊"只给模拟用（消息没有，推荐来自"行情软件"）。

## 8. 月供与突发账单

- **每月要还的钱**逐月上涨，名目越来越离谱：基础 9,000 × 1.105^(月−1)（取整到百元），再乘真实行情的折扣与市况倍数、人设和难度的倍数。
  名目有梗，如房租、健身卡续费、网购分期、车贷、孩子补习班、装修、按摩椅分期、换新手机、学区房首付、请全家旅游、给猫买别墅、还清所有梦想。
  为什么上涨：前期靠账单上涨和突发账单制造紧张，不靠让人早早出局——用连满分玩家都扛不住的大额账单杀人，等于凭运气杀人，违背"高难但公平"。
- **突发账单**：一局 2–3 次，分别落在 2–4 月、5–8 月、9–10 月三个窗口，月初和月供一起公布，金额有大有小、名目有梗
  （猫进了宠物医院、手机掉进马桶、三份份子钱、被拉进"高端理财课"、倒车蹭了邻居的新车、爸妈买了"量子床垫"……）。
  压力因此分散到全年，玩家每个月都要看一眼账单。第 6 级"股灾"那个月另有一笔"表舅爆仓借钱"（常规月供的 25%）。
- 账单（含突发）在月初就公布，不在月底才吓人。
- 月供压力的验收：普通玩家模型的出局月份不集中在某一个月，前两个月基本不出局。

## 9. 节奏：月度主题、目标、高光、连击

让一局"有张有弛"而不是"重复十二个月"，是玩法的一等目标：中间要有反馈，玩家要感觉自己真的在玩。

- **月度主题**：开局按种子、行情段（每月大盘的真实涨跌和最大单日跌幅）和难度抽好，全年不重复。每个主题有：一句介绍、一条规则改动、
  一个小目标、一句群友吐槽和奖励。主题只改规则和信息，不改走势。目标难度每高一级加码 8%。
  - 普通主题 15 个：过山车月、收割机带单月、年终奖到账、银行搞活动、空头来袭、考试月（只能买老实股）、丈母娘查岗、消息满天飞、提前看一天、
    券商送福利（免费多买 1 只）、涨跌停放宽、连胜挑战、鸡蛋别放一个篮子、散户狂欢、逆风翻盘。
  - 中场 boss 4 个，**第 4、8 个月**各抽一个：股灾来袭、年中考核、庄家对决、基金经理挑战；打赢有道具奖励。短局和实盘没有第 8 个月。
  - 抽取偏向有戏的行情：这个月真实大盘大跌就更可能抽到「空头来袭」「股灾来袭」，上涨就更可能抽到「年终奖」「年中考核」。
    需要银行或押跌的主题只在对应机制开着时抽。
- **目标类型**：账户涨 X%、抓到涨停几次、押跌赚钱几次、连续几天赚钱、某天同时拿几个风口、收益比大环境多几个点、
  最多回撤 X%（"撑住"类）、当天买当天赚、单日大赚。月底单独评价，完成给现金（普通月约一个月月供的两成，boss 月五成）、碎片或道具；
  月供照旧每月都要还。
- **月初"看点卡"**：主题 + 目标 + 一句群友吐槽，不超过一屏，长句放悬停里。顶栏始终显示"本月目标 X / Y，还剩 N 天"。
- **每月至少一个高光时刻**：持仓涨停 / 跌停、连续涨停、炸板、妖股异动、单只大涨大跌（≥ 5%）、账户一天大赚大亏（≥ 3%）、连击、目标达成、股灾。
  月末前一天本月还没有高光时，由主题制造一条重磅情报（算一次高光）。
- **连击与小奖励**：连续 3 天收盘赚钱起，每天群里发红包（约月供的 1.5%）；押对跌、抓到涨停给 1 片道具碎片，集满 3 片换一个道具。
  屏幕上能看到，让"小赢"有声音。
- **反馈的画面**：开盘翻牌，大涨大跌有特效、音效和群友刷屏；每天收盘一句结论；快进时账户跳动不打断（第 4.4 节）。
- 验收口径：机器人代玩每天都有可感知的反馈，没有"连续好几天无事可做"；每个月至少一次高光；12 个月的主题不重复。

## 10. 道具、事件、奖励、日历

- **月度奖励三选一**：道具、新群友或一只稀有股票，按稀有度抽（常见 : 稀有 : 传奇 = 6 : 3 : 1；类型权重 道具 7 : 群友 1.5 : 股票 1.5）；可以都不要。
  稀有股票当月一定处于"要火"且不会夭折，可以直接替换进持仓。第 8 级"末日"只给 2 张。没有商店，道具只来自奖励、事件、碎片和人设自带。
- **道具**（共 28 个，id 固定，分打法 / 工具 / 人脉三类；描述从 `BALANCE.fx` 取数，改数值不改文案）：
  - 打法：跟紧大哥、小弟也吃肉、老实人信仰、过山车爱好者、连续涨停梦、抄底大师、跌多了就跑、赚够就跑、大户专座、价值眼光、分散投资、
    空军墨镜、越涨越加；
  - 工具：多开一格、手快、借钱炒股、抽中新股、信用卡、怕错过体质、众筹炒股、押跌许可证；
  - 人脉：付费群（内幕哥入群）、老王的小本本（老王必中）、风口温度计（看到真实阶段）、反着信韭菜收割机、熬夜复盘、小道消息、银行有熟人。
  - 设计约束：每个道具只改规则表的一格；价值落在基线附近（不让任何道具成为必拿或负价值）；五个流派（跟大哥、追涨停、稳中求进、抄底、消息）都有通关局；
    通关局里最常见的三种道具组合合计占比很低。"拿了反而更差"不合直觉，要避免。
- **事件**（共 19 个，月底奖励之后约 40% 概率触发）：全部二选一、后果写在选项里。有表哥荐股、大V直播间、年会抽奖、卖课、买彩票、年终奖、
  房东涨租、老同学借钱、周末摆摊、猫踩键盘、抢红包、软件试用、盲盒、理财经理、加班；以及借钱玩法开着时的银行经理上门、空头大V直播、丈母娘查岗、
  爸妈打电话。带延后结算的（借钱、摆摊、理财、软件续费）在两个月后的月初结算，所以最后两个月不出现。第 8 级末日里事件的花费和损失翻倍。
- **日历**：12 个月都有一个固定、提前可见的效果，相当于 boss 预告：1 月元旦红包（大环境偏强）、2 月春季躁动（风口更容易冒头）、
  3 月开春政策窗口、4 月年报季（过山车股更容易跳水、危险股更容易被警告）、5–6 月偏弱（6 月降温更快）、7 月反弹、8 月中报季（大哥更强小弟更弱）、
  9 月金九和 11 月双十一（大消费、游戏传媒受益）、10 月国庆（只有 3 个交易日、波动缩小，月供照付）、12 月年底排名（波动放大）。
  真实行情下，这些只改群聊与规则，不改走势。

## 11. 人设与难度

### 11.1 人设

数值在 `BALANCE.fx[persona]`。开局自带的道具不算"拿过道具"（成就"裸考"）。

| 人设 | 解锁 | 开局 | 特点 |
|---|---|---|---|
| 职场新人阿韭 | 开局可选 | 10 万 | 标准开局，没有道具 |
| 退休老周 | 开局可选 | 8 万 | 自带老实人信仰；金融、大消费必出；老王更准；月供打折（"退休了，开销小"） |
| 宝妈芳姐 | 开局可选 | 9.4 万 | 自带抽中新股；张姐更准；月供不打折 |
| 程序员小码 | 成就"数据驱动" | 9.7 万 | 自带风口温度计；AI 必出；每天只能买 1 只（拿到"手快"也没用） |
| 炒股大佬 | 成就"涨停敢死队" | 30 万 | 自带过山车爱好者和连续涨停梦；月供 3.25 倍、突发账单 3 倍；韭菜收割机喊单翻倍且更不准；开局能押跌 |

为什么这样定：老周 8 万对头月月供太紧，改成"退休了开销小"保留"本金少"的味道而不加钱；芳姐的新股 + 张姐 + 月供折扣叠加太强，去掉折扣并降本金才和新人持平
（通关率对开局账户很敏感）；大佬 30 万本金下月供不加倍压不住。开局三人设的普通玩家通关率应相差不大，解锁人设可以略难。

### 11.2 难度

通关第 N 级解锁第 N+1 级（每日挑战不解锁）。高等级包含低等级的全部约束。前三级叫**新手 / 普通 / 高手**，面向第一次玩、玩过几局、想挑战；后五级是高手之后的挑战。
真实行情下，部分约束换成了更适合真走势的做法（不人为改走势）：

| 级 | 名字 | 要点 |
|---|---|---|
| 1 | 新手 | 要还的钱最少，没有额外约束 |
| 2 | 普通 | 要还的钱多一点；群里一部分消息是瞎传的（推荐不受影响） |
| 3 | 高手 | 每次买入交手续费；要还的钱再多一点（真走势照真的走，不再人为变差） |
| 4 | 消息失真 | 群里 80% 的消息是瞎传的，靠谱群友在"要变天了"时也不再更准；推荐不受影响 |
| 5 | 强监管 | 所有股票涨停那一头收窄（跌停不变）；危险股更容易被警告 |
| 6 | 股灾 | 随机一个月（4–9、11 月）月初传出"市场传闻"，那个月真的有一次大跌，所有风口一起降温，还多一笔突发账单 |
| 7 | 通胀 | 要还的钱再多 5% |
| 8 | 末日 | 奖励只给 2 张；事件里花的钱和亏的钱翻倍；突发账单再多两成 |

设计原则（来自配平实测）：高难度主要考"信息与判断"，因为月供类压力对满分玩家和会看消息的玩家几乎一样狠，只靠月供把后者压到很低，前者也会被压死。
验收口径：难度梯度严格单调；最高级会看消息的玩家仍有少量通关、知道答案的上限玩家仍有一半以上。具体数字和两种玩家模型的实测见 `design-balance.md`。
改数值必须用 `npm run sim` 跑机器人验证，不凭感觉。

## 12. 成就

成就只在一局结束后判定（`achievementsOf`），可以用隐藏信息（例如买入时的真实阶段）；共 45 个，分铜 / 银 / 金三档。每个成就在 `tests/achievements.test.ts`
里有构造局面的达成测试和"差一点不算"的边界测试。设计约束：

- **必须真的有人做得到。** 每个成就要有机器人实测的达成率；不可能达成的成就改条件，不留空头。
- **价值投资（只买老实股）要撑过 9 月，不要求通关。** 原稿是"只买过老实股并且通关"，实测只买老实股时会看消息的玩家通关 0%、知道答案的也不到 1%
  （老实股涨得慢、推荐里又少，账户基本不长），等于不可能达成。所以条件改成"只买过老实股（奖励、事件进来的也算），还清前 9 个月要还的钱"，
  保留"只买老实股"的玩法。
- **流派成就看带的道具**：跟大哥流、追涨停流、稳中求进流、抄底流、消息流，对应第 10 节的五个流派，带着对应道具通关即得。
- **高难成就看难度档**：老股民（第 5 级以上通关）、股神（第 8 级通关）、裸考（不拿任何道具、第 3 级以上通关）、百万散户（账户到 100 万）；
  允许极少数人做到，不降低标准。
- **解锁人设**：数据驱动（银）→ 程序员小码，涨停敢死队（金）→ 炒股大佬。
- **玩法成就跟新机制走**：一把梭、嘴硬王（押跌一只连续涨停的股票还不认输）、空军司令、东西没了、赎身、房子保卫战等，围绕仓位、押跌、抵押。
- **每日打卡**：打完一局每日挑战（输赢都算），要求种子、人设、难度和当天的 `dailySetup` 一致。
- 档案 `kaipan.profile` 和单局存档互不影响；调试开局不计入；没解锁的人设或难度开的普通局不计入档案；日期晚于本地今天的每日挑战不计入。

## 13. 结局、称号与"这段日子"

- **结局**：通关（还完全部账单，短局还要交首付）或游戏结束（月底还不上）。
- **结局称号**按炒股本身的净赚（不含账单和借款的影响）占本金的比例定：没通关按撑过的月份给"新韭菜（前 3 个月）/ 老韭菜 / 差一点上岸的韭菜（9 个月以后）"；
  通关按炒股净赚给"惊险上岸 / 上岸散户（≥ 0.3 倍）/ 大户新秀（≥ 1.2 倍）/ 百万韭菜王（≥ 3 倍）"。分档按机器人实测的分位数定。
  另有**打法评语**（观望大师、押上全部家当、群聊信徒、涨停收藏家……），按本局统计取第一个对上的，只调侃打法，不调侃人，破产也不挖苦。
- **"这段日子"小故事**：不说是哪段真实行情，不给年份、日期、真实公司名和任何 id，不展示"小人 → 真身"。
  用游戏里的花名（股票小人、风口、群友、本局人设）写一个 4–8 句、有起承转合的幽默小故事：那段时间发生了啥（段内的真实大事转写成情节，按游戏内时间说
  "第二个月月底"，公司换成泛称或本局同风口的小人），结合市况和玩家自己的表现（通关还是爆掉、赚得最多和亏得最多的小人、跟没跟群友），再加一句结局吐槽。
  伤亡、灾害、袭击、停市、选举类事件不进故事。
- **图鉴**：道具、群友、股票小人、成就、小知识、词典（第 2 节）、"见过的行情段"（只显示游戏化标题、市况和这段的故事，可重看，作为收集要素）。

## 14. 其他模式与专题（指路）

- **每日挑战**：由日期决定种子、人设（五个都可能，含未解锁的）和难度（2–5 级），全网同一局；纪录按日期单独存；有榜。
- **好友挑战**：把一局的设置发给朋友同局比拼，见 `design-challenge.md`。
- **实盘**：带筹码打 5 个月，账单打折、资产涨跌放大几倍，结回最多 3 倍，可选杠杆，见 `design-live.md`。
- **分享卡**：见 `design-share.md`；**去文字化的画面规则**见 `design-0.5-visual.md`；**界面美术**见 `art-v3.md`；**手机适配**见 `mobile.md`。
