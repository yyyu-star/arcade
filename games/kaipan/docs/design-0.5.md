# 《开盘》0.5：有节奏、强反馈、真走势

> 2026-10-13 维护者试玩 0.4.0 后的反馈："最大的问题就是一局太长了，而且中间没有反馈，就一直是重复说十二个月，
> 感觉不到我自己真的在玩。一局玩下来好累。"另外，维护者要求核实"是不是真的模拟出来了真实行情"。
> 实测（135 段 × 约 4000 只股票）：大盘逐日相关 0.91、整段方向一致 98%；个股逐日相关只有 0.42、同向 65%、整段方向一致 61%。
> 维护者决定：**个股照搬真实走势**，群聊情报改为从真实未来推算。一局长度先选了"3 关约 10 分钟"，随后改口：
> "不行，我觉得还是得引入这个月份……你可以想办法控制一下节奏。之前那个时间长度是能接受的，就是有点太枯燥、太无趣。"
> 所以**保留 12 个月和原来的时长**，重点改节奏、变化和反馈。

## 0. 对照维护者的约束

| 约束 | 做法 |
|---|---|
| 游戏为主、快乐 | 保留 0.4.0 全部内容（人设、群聊、道具、成就、图鉴、仓位、押跌、抵押、小故事），只改节奏和反馈。 |
| 时长可接受、但不能枯燥 | 保留 12 个月；每个月有不同的"月度主题"和目标，没事的日子自动快进，节奏有张有弛。 |
| 中间要有反馈、要感觉在玩 | 每关有自己的目标；每天开盘翻牌、大涨大跌有特效和群友刷屏；关卡结算给奖励。 |
| 真实涨跌 | 个股逐日涨跌照搬绑定的真实股票（目标逐日相关 ≥ 0.9），涨跌停截断仍是游戏规则。 |
| 不露年份公司 | 不变。 |

## 1. 一局的结构：12 个月，但每个月不一样

- 保留 12 个月和每月约 5 个交易日的长度（0.4.0 的时长维护者能接受）。
- **每个月一个"月度主题"**，从池子里按行情和难度抽，避免重复感，例如：
  - "妖股月"：本月会出过山车股，抓到一次涨停有大奖；
  - "群主带单月"：韭菜收割机天天喊单，信不信由你；
  - "年终奖到账"：本月可以加一笔本金，但月供也涨；
  - "银行搞活动"：抵押利息减半；
  - "空头来袭"：押跌许可证白送，这个月风口容易退潮；
  - "考试月"：本月只能买老实股；
  - "丈母娘查岗"：这个月不能亏超过 X。
  主题决定本月的小目标和奖励，月底结算时单独评价（完成了给额外奖励）。月供仍然每月都要还。
- **节奏控制**：
  - 每月开头一个"本月看点"卡（主题 + 目标 + 一句群友吐槽），不超过一屏；
  - 平淡的日子（没有新推荐、持仓波动小、没有事件）一键快进或自动快进，画面快速翻页；
  - 每个月至少一个"高光时刻"（大涨、大跌、事件、主题触发），没有就由主题制造一个；
  - 第 4、8 个月有"中场"：小 boss 关（例如"股灾来袭""年中考核"），打赢有大奖励；第 12 个月是最终结算。
- 12 个月打完（或中途爆掉）→ "这段日子"小故事 → 局外奖励。
- 行情段长度：12 个月 × 每月天数，与现在一致（不需要重新切段，除非真走势方案需要更长的开局前历史）。

## 2. 真走势 + 有用的情报

- **个股**：当天涨跌 = 绑定真实股票当天的真实涨跌（可乘一个统一的游戏放大系数，所有股票相同，不改方向和相对大小），再按游戏规则做涨跌停截断。
  0.3 的连板惯性、炸板、妖股跳空、ST 消息不再额外改走势；它们改为**从真实走势里识别出来并播报**（连续大涨就是"连板"，大涨后大跌就是"炸板"）。
- **风口**：热度和阶段仍由真实行业相对强弱推出（0.4 已有），保证和个股方向一致。
- **情报从真实未来推算**：群友消息、推荐、"猫的建议"在发出时，读取这段行情接下来 1–3 天的真实走势，
  按群友的靠谱程度决定说对的概率（靠谱的老赵准确率高，韭菜收割机经常反着来）。这就是游戏性的来源：
  走势是真的，玩家要判断信谁。准确率参数化、按难度调。
- 道具和难度改为作用在"信息"和"规则"上（多一条情报、提前看一天、手续费、涨跌停宽窄、月供高低），不再改走势本身。

## 3. 反馈

- **开盘翻牌**：持仓卡一张张翻，显示今天涨跌；大涨（≥ 5%）、涨停、大跌、跌停各有特效、音效和群友刷屏。
- **每天一句话**：收盘一句结论（"重仓的奶茶续命涨停，今天你是群里最靓的仔"），点开看拆解。
- **连击与小奖励**：连续几天赚钱、押对跌、抓到涨停给小奖励（金币、道具碎片、成就进度），屏幕上能看到。
- **关卡进度条**：顶栏始终显示"本关目标 X / Y，还剩 N 天"。
- **快进时**：没事的日子快速翻过，显示账户跳动，不打断。

## 4. 验收

- 实测：个股逐日涨跌与真实相关 ≥ 0.9（除涨跌停截断外），大盘 ≥ 0.9。
- 一局时长与 0.4.0 相当或略短；新手试玩脚本里，每个月都至少有一次"高光时刻"，平淡日可一键快进；12 个月的月度主题不重复。
- 机器人：会看情报、信靠谱群友的策略明显强于乱买；难度梯度成立；牛熊都有通关路径。
- 机器人代玩：每天都有可感知的反馈，没有"连续好几天无事可做"。
