# 画面上的信息怎么放（去文字化与丰满化）

> 现行规范：画面少写字、信息不减，用图标、数字、图表和动画表达。美术风格、材质和关键时刻见 `art-v3.md`，手机尺寸见 `mobile.md`，
> 面向玩家的用词见 `design.md` 第 2、3 节。规则、数值不因为呈现而改。

## 原则

1. **一屏一个焦点。** 交易画面的焦点是「开盘」按钮和持仓卡；弹窗出现时焦点是弹窗里那个大数字或那张卡。
2. **能画就不写。** 图标、数字、颜色、进度条、动画优先，句子最后才用。新图标走 `tools/art/glyphs.ts`（`ui/gl_*.svg`，48×48，Q 版粗描边），画面里用 `addGlyph()`。
3. **信息只增不减。** 删掉的字必须有替代：放回卡面、换成图标数字，或收进悬停提示、详情卡、「怎么玩」、图鉴。手机没有悬停，关键信息要在卡面或可点的详情卡里看得到。
4. **文字是打磨不是删光。** 常驻标签约 6 个字以内，短、准、口语化；内容表给长句配短版字段，画面默认显示短版，长句留在提示和详情里。
   猫的短话不超过 16 个字。标签不带句号；数字和单位之间不加空格（`+5.1%`、`¥1,990`）；分隔用「·」两边各一个空格。
5. **字号三级**（`theme.ts` 的 `TYPE`）：大数字 28 / 标题 18 / 标签 13，大数字和标题加粗，强调靠颜色；手机上的下限见 `mobile.md`。
6. **涨跌一律「颜色 + 箭头 + 数字」**：`↑5.1%` / `↓2.0%`，红绿随配色设置，不写「涨了 x%」。
7. **弹窗按钮**：主按钮橙色在右、次按钮白色在左，最多两个，文字 ≤ 4 个字；电脑上有快捷键角标。
8. **卡牌化**：事件、三选一、看点卡都是「图标 + 名字 + 一个大数字效果 + 一行小字」。
9. **一切可研究**：每只股票、每个风口、每个群友都能点开详情卡（`trade/detail.ts`）：大走势图、近几天涨跌、连涨连跌、风口热度曲线、角色、战绩、和大环境比强弱。
10. **画面一直在动、操作立刻有反馈**：数字滚动、热度条流光、小人待机、天气；买入卡片飞进格位、卖出金币飞回钱包。动画都能点一下跳过，不阻塞结算，
    一天的结算时长不因此变长；「减少动态效果」或关动画时直接画完或不放。
11. **不留大空白**：1280×720 下没有超过约 200×150 的空区域（房间背景装饰除外）。

## 只用已经发生的数据

- `trade/tape.ts`（行情记录仪）每次渲染把公开的近几天（个股涨跌、风口热度、大盘）按交易日并进内存表，最多 20 天，只读公开、已发生的数据。
- 第 1 天就有走势：`src/core/queries.ts` 的 `preHistory(s)` 用行情段开局前的几天（按交易日同样的放大和涨跌停截断）垫底。
  图上开局前那段画浅色、虚线，并画一道开局竖线。`tests/pre-history.test.ts` 保证改掉开局后的行情不影响它。
- 迷你折线、K 柱、热度曲线在 `ui/spark.ts`，支持从左往右画出来。

## 各处放什么（要点）

- **顶栏**：要还的钱、账户（下面一行写人设和级别）、日期、本月目标、道具栏；钱不够时写「差¥x · 会出局」或「差¥x · 信用卡垫」。放不下时的让位顺序见 `mobile.md`。
- **持仓卡**：股票小人、风口签和热度小条、角色图标和名字、近几天走势框、昨天涨跌大数字、持有盈亏色块、连涨连跌角标、跑赢 / 跑输大环境；涨停、大跌换表情并闪色。
- **空格**：纸垫座位，今天能买时发光，买不了时写原因；钱袋写现金。
- **显示器**：大盘近 20 天折线、今天的天气、风口涨跌前几名、昨天账户盈亏，下沿跑马灯；平淡日写「平静日」。
- **推荐卡**：小人、名字、角色、风口签和热度、走势和连涨连跌、≤ 12 字理由（按短句拼，不硬截断）、推荐人头像和战绩。
- **群聊**：消息逐条弹入，一行能放下就整句，放不下的整句在悬停；名字旁写身份；反着信的写「反着听」；
  热闹元素（`trade/chatFluff.ts`：贴纸、@回复、撤回、拍一拍）是纯装饰，按种子和交易日编号确定，只填真消息和推荐卡之后的空白，不加长一天的时长。
- **风口看板**：情绪小脸、「图标 + 两字」状态签（冷清 / 要火 / 正火 / 太火 / 降温）、热度大数字和流光条、近 5 天折线；标题旁写「状态看走向，不看高低」。
- **收盘小结**：每只一个最大原因短签加贡献小条，押跌有小熊；借钱、押跌这类账户层效果写成「图标 + 金额」签。
- **教程**：每步一个指向箭头加一句 ≤ 15 字，有进度点，可跳过。

## 验证

`tests/view-visual.test.ts`（短话、箭头数字）、`tests/view-copy.test.ts`（用词）把关；`npm run shot -- --vis` 截主要画面并统计每个画面可见的汉字数，改版前后对比。
