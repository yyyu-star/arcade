# 0.5 去文字化：美术与交互重设计

> 目标（维护者原话）："文字信息太多……精简一下，美化一下，用游戏思维去设计。" 规则、数值、玩法都不改，只改呈现。
> 基线：`node tools/shot.ts --vis --out <截图目录>/before`（2026-10-13，0.5.0 / 0d6de12），19 个画面可见汉字合计 6917。
> 目标：合计 ≤ 2700（−60% 以上），每个画面单独也要有明显下降。

## 原则

1. 一屏一个焦点。交易画面的焦点是「开盘」按钮和四张持仓卡；弹窗出现时焦点是弹窗里那个大数字或那张卡。
2. 能画就不写：图标、数字、颜色、进度条/环、动画优先，句子最后才用。新图标走 `tools/art/glyphs.ts`（`ui/gl_*.svg`，48×48，Q 版粗描边），画面里用 `addGlyph()`。
3. 常驻文字只留标签，每个约 6 个字以内；说明一律收进悬停/长按提示、可展开详情或「怎么玩」/图鉴。长文案不删，只挪地方。
4. 字号三级（`theme.ts` 的 `TYPE`）：大数字 28 / 标题 18 / 标签 13。大数字和标题加粗，标签常规；强调只靠颜色。
   标点：标签不带句号；数字与单位间不加空格（`+5.1%`、`¥1,990`）；分隔用「·」两边各一个空格。
5. 涨跌一律「颜色 + 箭头 + 数字」：`↑5.1%` 红 / `↓2.0%` 绿（随配色设置），不写「涨了 x%」。
6. 弹窗按钮统一：主按钮橙色在右、次按钮白色在左，最多两个，文字 ≤ 4 个字；快捷键角标保留。
7. 卡牌化：事件、三选一、看点卡都做成「图标 + 名字 + 一个大数字效果 + 一行小字」。

- 内容表给长句加短版字段（如 `short`），画面默认显示短版，长句留在悬停提示、展开详情、图鉴或「怎么玩」里。

# 0.5.1 丰满化：信息只增不减，动起来

> 维护者反馈（2026-10-13）：①"文字也太少了……整个界面看起来好空"；②"我是让你优化文字表达……删了文字就得用其他丰富的方式替代……加点动态效果、更多信息，每个产品最近的趋势"；
> ③"我希望这是一个动态的游戏……有深度"。规则、数值、数据都不改，只改呈现。
> 基线截图：`node tools/shot.ts --vis --out <截图目录>/before`（51efb6c）。上一轮的「≤160 字」目标作废，以信息完整、表达精炼为准。

## 原则（在 0.5 原则上修订）

1. **信息只增不减**：0.5 删掉或挪进悬停的信息逐条找回（对照表见文末），优先用图像、图表、数字、动画呈现，必要时配一句短话。
2. **文字是打磨不是删光**：短、准、有梗、口语化；关键数字和词用字号、颜色、色块突出（三级字号不变，数字可用 28/20 两档）。
3. **一切可研究**：每只股票、每个风口、每个群友都能点开「详情卡」——大走势图、近几天涨跌、连涨连跌、风口热度曲线、角色、战绩、和大环境比强弱。卡面放得下的直接显示，放不下的进详情卡。
4. **画面一直在动、操作立刻有反馈**：跑马灯、热度条流光、小人待机、天气、数字滚动；买入卡片飞入格位、卖出金币飞回钱包、涨跌卡片震动闪色。动画都能点一下跳过，每天总时长不变长。
5. **不留大空白**：1280×720 下没有超过约 200×150 的空区域（房间背景装饰区除外）。

## 共用件

- `src/view/trade/tape.ts`：画面层的「行情记录仪」。每次渲染把 state 里公开的近几天（个股 5 天涨跌、风口 6 天热度、大盘涨跌）按交易日编号并进内存表，同一局里越玩越长（最多 20 天）；真实行情局的大盘用段数据里**已经过去**的日子补满 20 天。只读公开、已发生的数据，不看今天以后的。
- `src/view/ui/spark.ts`：迷你折线 / 迷你 K 柱 / 热度曲线，支持「从左往右画出来」的动画。
- `src/view/trade/detail.ts`：详情卡（股票 / 风口 / 群友），点股票小人、推荐卡、风口行、群友头像打开。
- 新图标（`tools/art/glyphs.ts`）：天气 晴/雨/雷/彩虹、乌云；贴纸 火箭/哭脸/钱袋/韭菜/吃瓜/锤子；情绪脸 火热/开心/平静/发愁/冰冷；放大镜（看详情）。

## 0.5.1 实现备注

- 群聊热闹元素（`src/view/trade/chatFluff.ts`）是纯画面装饰：用 seed + 交易日编号做确定性随机，同一天重绘一样；只填当天真消息和推荐卡之后的空白；intro / afterClose 把原来的总时长均摊给多出来的条目。
- 动画都不阻塞结算：走势线画出、热度条流光、云飘、跑马灯、金币、乌云、小人招手都是旁路补间；「减少动态效果」或关闭动画时直接画完或不放。
