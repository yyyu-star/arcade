# 《开盘》分享卡（社交第一期，接 kit `arcade-kit/share`）

> 规范见仓库根 `docs/social.md` 1.1：游戏只交数据 `{ game, title, big: { value, label }, stats: [{ label, value }] ≤ 3, line, accent, art? }`，画法在 kit。
> 本稿写开盘交什么、为什么。数据全从结束页已有的 `runSummary`（`src/core/queries.ts`）取，规则核心不改。

## 1. 三种结算页各交什么

| | 卡片标题 `title` | 大数字 `big` | 小数据 `stats`（≤ 3 条） |
|---|---|---|---|
| 实盘 | 「实盘小档 · 2,000」 | `×3.40`，「杠杆 ×2 · 结回几倍」（1× 写「结回几倍」）；清零的局 `×0`，「杠杆 ×3 · 跌到清零线」 | 还上几个月（「5/5 个月」）、最赚的一笔（说明写股票名「韭菜芯片」，值写「↑61.5%」） |
| 娱乐 | 「短局 · 5 个月」或「完整一年」 | 资产涨跌 `28.6%`，「这局资产涨了」（跌了写「这局资产跌了」，数字不带负号） | 结果（「通关」或「撑了 3 个月」）、人设和难度（说明写「职场新人阿韭」，值写「普通」）、最赚的一笔 |
| 每日挑战 | 「每日挑战 10/15」 | 同娱乐的资产涨跌 | 今天第几名（读到名次才有，没有就换成「还上 4/12 个月」）、人设和难度、最赚的一笔 |

共用包每格的值约 6 个字宽、说明约 8 个字，所以值只放短的，名字放在说明那一行。名场面 `line` 三种都按第 2 节；`player` 是平台昵称加这局的称号（`sum.title`），单独部署没有昵称就不写。

- **大数字为什么是倍数或涨跌幅，不是钱数**：三个人设的开局本钱不一样（10 万、8 万、9.4 万），钱数比不了；百分比、倍数能直接比。
  实盘用结回倍数是因为结回就是按它算的，和结算页、顶栏同一个数（0.11.0 起已经含杠杆）。
- **资产涨跌** = 最后剩下 ÷ 开局本钱 − 1（`account / startAccount − 1`），一位小数，正数带 `+`。娱乐局输了也照写，不藏。
- **最赚的一笔** 用 `bestTrade`（含没卖的持仓），股票名是游戏里的化名；没赚过（没买、或者全亏）就去掉这一条，写「最赚」却是跌的不对劲。
- `title`：「开盘」；`accent`：主题橙 `COLOR.accent`；`art`：最赚那只股票小人的图（现在海报用的同一张，图集里已有）；没有就用人设头像。
- 链接：游戏地址（`gameLink`，和现在海报一样，不带参数）。每日挑战当天所有人同一局，好友点开首页的「每日挑战」就是这一局；
  不用 URL 里的 `daily=`，它是调试参数，带着开的局不计入档案。直接点开某一局留给第二期的异步挑战（`social.md` 第 2 节）。

## 2. 名场面模板（按顺序取第一条符合的）

| # | 条件 | 模板 |
|---|---|---|
| 1 | 实盘结回 ≥ 3 倍 | 「杠杆 ×{N}，{月数} 个月结回 ×{倍数}」（1× 不写杠杆） |
| 2 | 实盘跌到清零线 | 「杠杆 ×{N}，第 {月} 个月清零」 |
| 3 | 最多连涨 ≥ 3 天（`maxBoards`） | 「连涨 {n} 天，全程坐在车上」 |
| 4 | 最赚的一笔 ≥ +50% | 「{股票}一把赚了 {涨幅}」 |
| 5 | 娱乐通关 | 「{月数} 个月的账全还上了」 |
| 6 | 其他 | 这局的打法评语 `style.line`（结束页称号下面那句，已经是按局面写的大白话） |

- 数字和名字由代码填，模板本身是固定文字，放进 `tests/view-copy.test.ts` 的扫描范围（不出行话、不用 emoji）。
- 模板压在一行放得下（约 16 个字宽）：卡上给名场面加了引号、跟着折行，稍长一点就剩一个引号掉到第二行（`tests/share-card.test.ts` 按字宽锁住）。
- 实盘的几条照实盘结束页的规矩（设计稿 `design-live.md` 第 5 节）：不出现「回本、翻本、再来一把、就差一点、马上、限时」这类催人再赌的话；输了的局不推更高的档位。
- 不写年份、真实公司和行情段的故事（故事里的花名能对上真实年份，分享出去等于剧透这一段）。

## 3. 和以前「晒战绩」海报的关系（0.12.0 已换）

- 0.6.5 起结束页的「晒战绩」是开盘自己画的 1080×1350 海报（`src/view/poster.ts`）。0.12.0 换成「分享」，数据由 `src/view/shareCard.ts` 交给 kit，自己的画法删掉，五个游戏风格一致。
- iOS 只许在点击的那一下里调系统分享：0.12.0 用的 `shareCard` 是点了才画，iOS 上调不起、退到预览层。0.12.1 改用 kit 0.12.3 的 `prepareShare`：结束页一出来就画好，点击里直接 `share()`（前面不 await）；每日挑战读到名次后再画一张带名次的，画好才换上。
- `art`：kit 0.12.0 收 `{ image, crop: { x, y, w, h }, fit }` 或直接一张图片 / canvas，图集里的切片直接交（`image` 是图集、`crop` 是切片框），不用另导出整图。

## 4. 验收

- 实盘（含 2×、3×、清零）、娱乐短局、完整一年、每日挑战各出一张，手机和电脑都能存图、调起系统分享。
- 单测按第 2 节的顺序逐条覆盖模板选择；`npm run shot` 的结束页段点一次「分享」，检查生成了图、控制台零报错。
