# 《开盘》下一阶段规划（0.3 起）

> 2026-10-10。依据：维护者试玩 0.2.0 后的反馈（复杂杂乱、缺少整体体系；太像小丑牌；美术单一；内容、难度、图鉴、成就不足）。
> 状态：待维护者拍板第 9 节的三件事。拍板之后先做 M0 原型，再进入量产。

## 1. 诊断：三个问题是同一个病根

0.2 把 Balatro 的结构逐项翻译了过来：盲注 → 考核，手牌 / 弃牌 → 发牌 / 换一批，小丑 → 策略，
塔罗 / 星球 → 锦囊 / 研报，筹码 × 倍率 → 收益 × 倍率，还有利息。结果有三个：

- **杂乱**：七八个子系统并列，各用各的数字（准确率、加成、倍率、等级、经费、基金规模、目标、天数），
  彼此之间没有一条主线把它们串起来。协同只写在描述里，玩家在画面上看不到。
- **像小丑牌**：骨架是照搬的，所以加多少股市皮肤都像换皮。
- **美术单一**：全是白色线条图标加深色终端，没有角色，也没有会动、有情绪的东西。

所以下一步不是修 0.2，而是换一个从股市本身长出来的核心。原则只有一条：**一个数字、一条主线**。

## 2. 新核心一句话

> 你是刚入市的散户。每天看群聊里的小道消息，挑股票放进持仓，开盘后看它们跟着"题材"涨跌、互相带动；
> 每个月底账户里要留够钱还月供，还不上就爆仓。一年后，看你是韭菜还是股神。

- **一个数字**：账户余额。它同时是分数、本金、还月供的钱、买道具的钱，所有取舍都落在它上面。
- **一条主线**：题材（AI、新能源、白酒、医药、银行……）。股票属于题材，消息谈论题材，道具、日历事件、
  难度都通过题材起作用。玩家要学的核心只有一件事：**题材会轮动：萌芽 → 发酵 → 主升 → 高潮 → 退潮**。

## 3. 核心循环

### 3.1 一天（目标：0–2 次点击，6 秒左右）

1. **盘前**：
   - 群聊里冒出 2–4 条消息，例如"小李：AI 要起飞了🚀""老王：白酒该跑了"。
   - 题材看板上，每个题材有一根热度条。
   - 群友推荐 3 只股票，你可以买下其中一只放进持仓，也可以不买；手里的股票随时可以卖。
2. **开盘**：一键开盘，然后看它自己发生：
   - 题材热度变化（升温冒火，退潮结冰）。
   - 每只持仓股票的小人跟着涨跌做表情。
   - 龙头带动跟风连锁上涨，涨停放烟花，跌停头上下雨。
   - 账户数字滚动。
3. **收盘**：群友吐槽一句，进入下一天。

### 3.2 一个月（5 个交易日）

- 月底还月供：账户扣掉一笔逐月上涨的钱，账单滑入，盖上"已还清"或"逾期"的章。还不上就爆仓，本局结束。
- 还完之后三选一奖励：新的人脉（群友）、工具，或者一只稀有股票。
- 部分月份有**A 股日历事件**，取代 Boss，例如：
  - 春季躁动：题材升温快
  - 年报季：业绩差的股票暴雷
  - 五穷六绝：大盘偏弱
  - 监管月：妖股受限
  - IPO 抽血：大盘被抽血

  日历固定，每局都一样，玩家可以提前布局。这是只有股票游戏才有的"Boss"。

### 3.3 一局

12 个月、60 个交易日，约 15–20 分钟。每局从题材池里随机抽 6 个题材登场，日历事件和群友组合也会变化。

## 4. 统一的体系：少数规则，组合靠题材

| 概念 | 规则（全部只有一两句话） | 产生的取舍 |
|---|---|---|
| 持仓 | 每个格子平分账户，空格子就是现金，不涨不跌 | 集中押一个题材，还是分散 |
| 题材热度 | 每个题材按生命周期涨落，股票的涨跌 ≈ 热度变化 × 角色系数 | 什么时候上车、什么时候下车 |
| 角色 | 龙头（弹性大）、跟风（跟着龙头）、白马（跌得少）、妖股（大起大落）、ST（摘帽或退市） | 进攻和防守怎么配 |
| 龙头效应 | 持有龙头、龙头又涨停时，同题材的其他持仓额外上涨 | 同题材凑一串 |
| 连板 | 连续涨停计数越高，第二天越强，但炸板风险也越大 | 继续拿，还是落袋 |
| 群聊消息 | 消息来自具体的人，每个人有擅长的题材，可信度也不同，有人是反指 | 学会信谁 |
| T+1 | 今天买的明天才能卖；每天只能买入一只 | 提前布局，没法临时抱佛脚 |

道具（人脉和工具）都只改这张表里的某一格，所以协同在画面上看得见。例如：
- "龙头战法"：龙头涨停时，跟风股再多涨一点。
- "低吸大师"：退潮期买入的股票，下一轮更猛。
- "老王的小本本"：银行股消息一定准。
- "付费群"：多一个靠谱的群友。

## 5. 自己的特色：取材来源

| 取自 | 借鉴什么 | 在《开盘》里变成 |
|---|---|---|
| Luck be a Landlord | 每轮自动结算，加三选一的构筑，按期交租 | 开盘自动结算，群友推荐三选一，月供 |
| 炉石酒馆战旗、Super Auto Pets | 种族协同、可爱的角色、触发链 | 题材协同、股票小人、龙头带跟风 |
| 动物森友会的大头菜 | 价格有规律、可以学习 | 题材生命周期，玩家越玩越会看 |
| Reigns | 一句话事件加二选一，角色幽默 | 群聊人物和突发事件（表哥荐股、大V直播） |
| 杀戮尖塔 | 角色开局不同、进阶难度 | 人设（毕业生 / 退休老王 / 宝妈……）、市场环境难度 |
| Stacklands | 极简但有角色感的画风 | 股票小人的画风 |
| A 股本身（独有） | 题材轮动、龙头与跟风、连板与炸板、T+1、ST 摘帽、日历效应、炒股群 | 整个游戏的骨架 |

从 Balatro 保留的只有精神：结算时一层层叠上去的爽感，靠连锁反应和烟花来表现，不再用"筹码 × 倍率"的算式框。

## 6. 美术与动态表现

**方向**：Q 版"股票小人"加温暖的炒股小屋，取代纯白线条图标和冷色终端。

- **股票小人**：每只股票都是有脸的小东西，例如：
  - 韭菜芯片：长着韭菜头发的芯片
  - 躺平银行：躺着的存钱猪
  - 国民辣条：戴墨镜的辣条
  - 永动机能源：仓鼠跑轮

  每个小人有 5–6 个表情：平静、开心、涨停戴墨镜、担心、跌停哭、退市变灰。
  做法是部件化的程序生成 SVG（身体 × 配色 × 五官 × 配饰）。有名字的股票按配方手定，杂股自动组合。
- **动起来**：
  - 小人：待机时呼吸和眨眼；涨跌时弹跳或发抖。
  - 题材热度：火苗和冰晶粒子；退潮时潮水漫过整个题材。
  - 结算：龙头带动时有连线光效；涨停放烟花，跌停飘雨云。
  - 账单与日夜：月底账单动画；日夜和天气随大盘情绪变化（牛市晴天，股灾雷雨）。
- **贴图**：
  - 小屋场景分层背景：窗外天色、书桌、显示器的光、睡觉的猫。
  - 手机群聊界面，配群友头像。
  - 纸张和玻璃质感；图标改为彩色填充。
- **仍然全部自己生成**，不引入外部素材，版权干净。Steam 主视觉之类的宣传图，以后再决定要不要外包。

## 7. 内容、难度、图鉴、成就

- **内容**（M1 → M3 逐步扩充）：

  | 内容 | M1 | M3 |
  |---|---|---|
  | 题材 | 8 | 14 |
  | 股票小人 | 40 | 90 |
  | 群友 | 8 | 16 |
  | 道具 | 24 | 50 |
  | 日历事件 | 10 | 16 |
  | 突发事件 | 15 | 40 |
  | 人设 | 3 | 7 |

- **难度**：用"市场环境" 8 级，从慢牛到股灾，通关一级解锁下一级。每级加一条约束，例如：
  - 退潮更快
  - 消息更不准
  - 月供更高
  - 监管更频繁
  - 黑天鹅
  - 道具会过期

  第 8 级要难到高手通关率也很低。
- **图鉴**：股票小人、群友、题材、道具、事件，见过就点亮。股票小人图鉴本身就是收集动力。
- **成就**：40 个起，要有梗，并且多数会解锁新内容，让输掉的局也有进展。例如：
  - "站岗专业户"：在高潮买入，一直拿到退潮
  - "连板狂魔"：拿到一只五连板
  - "价值投资"：只靠白马股通关
- **纪录**：沿用 0.2 的本地纪录，再加上每日挑战（固定种子），以后可以接排行榜。

## 8. 复用与重写

- **直接复用**（约六成工程量）：
  - 确定性规则框架、回放和快照存档
  - 机器人与模拟验收框架
  - 设置、纪录、错误兜底
  - 音频引擎（新增音效，音乐跟着大盘情绪走）
  - UI 组件、高分屏和触屏适配
  - 截图冒烟和浸泡测试
  - 0.2 的幽默文案和股票名
- **重写**：
  - 规则核心：行情、持仓、群聊、日历、道具、事件
  - 交易场景和商店（改成三选一奖励）
  - 教程（改为逐局解锁、逐步露出）
- **废弃**：发牌、换一批、方向选择、锦囊 / 研报、收益 × 倍率的算式、利息。0.2 留在 git 里可以随时找回。

## 9. 需要拍板的三件事

1. **核心概念**：按第 2–4 节改为"持仓 + 题材轮动 + 群聊消息 + 月供"（推荐）。
   如果更想保留"每天亲手判断涨跌"的手感，备选是在 0.2 上做减法：去掉锦囊、研报和算式，换成题材和群聊。
   代价是骨架仍然像小丑牌。
2. **主角**：散户还月供（推荐，更有梗也更好代入），或者沿用基金经理加季度考核。
3. **美术**：自己用程序生成的 Q 版小人和场景（推荐，可控、版权干净、能动起来）；或者找外包或用 AI 出图
   （需要预算和版权确认，风格一致性也要另外管理）。

## 10. 里程碑

| 里程碑 | 内容 | 验收 / 检查点 |
|---|---|---|
| **M0 原型**（先做，不量产） | 设计稿 v0.3；规则核心 + 机器人模拟；美术样张（6 只股票小人 × 5 表情、1 张小屋场景、群聊界面、热度动效）；5173 上粗糙但能完整走完一局的原型 | 模拟：技能曲线拉得开；题材择时和集中 / 分散都有意义；没有必胜构筑。**你试玩原型并认可方向后，才进入 M1** |
| **M1 → 0.3** | 完整核心循环、首批内容（见第 7 节）、新画面和动效、逐步露出的教程 | 冒烟、浸泡、模拟验收全部通过；部署到 4173 |
| **M2 → 0.4** | 8 级难度、图鉴、成就、解锁、人设、每日挑战 | 第 8 级高手通关率低于 15%；成就全部可以达成 |
| **M3 → 0.5** | 内容扩充到第 7 节的 M3 列；表现打磨（转场、天气、音乐随行情变化） | 构筑多样性和策略价值的模拟验收；试玩反馈 |
| **M4 → 0.6** | 英文本地化、Tauri 桌面包、Steam 商店页与试玩版、可选的匿名统计 | 桌面包在 Windows 上实测通过 |

过程上的改进：这次先给你一个能玩的粗原型，确认手感之后再画细节，避免像 0.2 那样做完一整版才发现方向不对。
