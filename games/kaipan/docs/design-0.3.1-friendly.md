# 《开盘》0.3.1：看得懂、说人话

> 2026-10-10。依据：维护者试玩 0.3.0 后的反馈——
> - 不知道今天为什么赚、为什么亏；
> - 金融术语小白看不懂；
> - 内容感觉单调；
> - 希望更友好、更清晰、更容易上手，文字更人性化。
>
> 规则和数值不变（只改名字和文案，不改效果），id 不变。

## 1. 诊断

1. **因果看不见**。一只股票当天的涨跌，由下面几部分叠加而成：
   - 风口热度的变化；
   - 角色放大；
   - 带头大哥带动；
   - 道具；
   - 过山车跳空；
   - 涨跌停截断。

   画面上却只有一个"今日 +14.4%"，外加一闪而过的"跟风大法 +2.0%"，玩家无从知道钱是怎么来的。
2. **满屏术语**：题材、发酵、退潮、龙头、跟风、白马、妖股、ST、低吸、拐点、连板、炸板、T+1、换仓、"横"、"说中 5/7"、
   两融、打新……小白看到第二个词就放弃了。
3. **没有一句话的玩法**。"风口会轮流火，开始火的时候上车，太火了下车"这条核心规律，游戏里从来没有直说。
4. **单调**：每天都是同样的点击，题材涨跌没有"故事"，股票小人也不说话。

## 2. 词表（画面和文案一律用左边的说法；A 股原词只作括注，出现在提示和词典里）

| 新说法 | 原来的词 | 一句话解释（提示里用） |
|---|---|---|
| 风口 | 题材 | 大家正在炒的话题，比如 AI、新能源。同一个风口的股票一起涨跌。 |
| 热度 | 热度 | 这个风口有多火，0–100。热度涨，它的股票就涨；热度跌，股票就跌。 |
| 没人理 / 开始火 / 正火 / 太火了 / 在降温 | 冷门 / 萌芽·升温 / 发酵·主升 / 过热·高潮 / 退潮 | 看板上的公开状态（按公开信息算，不是隐藏的真实阶段）。 |
| 带头大哥 | 龙头 | 风口里最猛的那只，涨得多也跌得多；它涨停时会带着小弟一起涨。 |
| 小弟 | 跟风 | 跟着大哥走，大哥涨停它也沾光。 |
| 老实股 | 白马 | 涨得慢、跌得也少，适合压舱。 |
| 过山车 | 妖股 | 经常突然暴涨或暴跌，刺激但危险。 |
| 危险股 | ST | 公司出了问题，可能摘帽翻身，也可能退市归零。 |
| 涨停 / 跌停 | 同 | 一天最多涨 10%（跌 10%），涨满就叫涨停。 |
| 连续涨停 N 天 | N 连板 | 越连越猛，但随时可能"没封住"。 |
| 涨停没封住 | 炸板 | 本来涨停，收盘前被砸下来了。 |
| 大哥带小弟 | 龙头带动 | 带头大哥涨停时，同风口的小弟额外涨一点。 |
| 今天买，明天才能卖 | T+1 | 不出现"T+1"字样。 |
| 换掉一只 | 换仓 | |
| 准 5/7 | 说中 5/7 | 这个群友这局说了 7 次，说对 5 次。 |
| 要变天了 | 拐点 | 群友觉得风口要转向了（变好或变坏）。 |
| 不动 | 横 | |
| 买入以来 +37% | 持有 +37% | |
| 今天大环境：好 / 一般 / 差 | 大盘 晴 / 阴 / 雨 | 天气只是图，文字要直说。 |
| 这个月要还 | 月供 | 首次提示："每个月底要从账户里还一笔钱，名目越来越离谱。还不上就爆仓（游戏结束）。" |
| 借钱炒股 | 两融 | 道具名和描述都改成大白话。 |
| 抽中新股 | 打新中签 | 同上。 |

其他原则：
- 道具、事件、日历、人设、成就、难度这些内容的名字可以保留有梗的说法，但描述一律写成"什么时候 → 发生什么"的大白话，不出现未解释的术语。
- 数字要说明意思：写"赚了 ¥5,890"，不写"+5.9%"；百分比只作补充。

## 3. 文案风格

- 像群里一个靠谱的朋友在说话：短句，一句只说一件事，先说结论再说原因。
- 幽默来自人物和处境（群主卖课、表舅爆仓、猫比我有钱），而不是来自术语。
- 不说教，不用"注意""请"开头的命令句；提示用"可以……""小心……"。
- 每个新词第一次出现时，要么能悬停或点开看到解释，要么旁边直接带半句解释。
- 中文全角标点；数字和单位之间不加空格（¥5,890、+10%）；不使用 emoji。

## 4. 新功能

### F1 收盘小结：每天都讲清楚赚亏从哪来

- **规则层**：`DayReport` 给每只持仓提供结构化的归因，单位是 pp，各项加起来等于当天涨跌：
  - 风口热度变化（附风口 id 和 ΔH）
  - 角色放大
  - 大哥带动
  - 道具（按道具列出）
  - 过山车跳空
  - 个股消息（摘帽、警告）
  - 涨跌停截断
  - 随机波动（余项）

  再给出每只持仓的盈亏金额（元）。只用当天已经揭晓的信息，不泄露阶段。
- **画面**：
  - 结算动画结束后弹出一张"收盘小结"卡，第一句是总账，例如："今天赚了 ¥5,890，主要靠 AI 风口（+¥4,200）"。
  - 下面每只持仓一行大白话，例如："韭菜芯片 +10%（涨停）：AI 风口热度 +15，它是带头大哥，涨得比别人猛"。
  - 亏钱的同样直说原因。
  - 点任意持仓卡，都能看到当天的拆解条。
  - 小结卡可以点掉，也可以在设置里改成只显示总账一句。

### F2 收盘新闻：风口为什么动

- 收盘后，对当天热度变化最大的 1–2 个风口，配一条虚构的新闻标题，在群聊里以"今日新闻"的形式出现。例如：
  - "某 AI 公司发布会现场演示翻车，观众却更兴奋了"→ AI 热度 +15；
  - "猪肉价格连跌三周，养殖户集体沉默"→ 养猪热度 −8。
- 新闻是在结果揭晓后，按方向和幅度从文案池里抽的，只解释已经发生的事，不预告。
- 文案池：每个风口 × 涨 / 跌 × 至少 5 条；另有"全场大涨"、"全场大跌"等通用条目。全部虚构，不涉及真实公司、人物、机构、政治、军事和真实社会事件。

### F3 一张图看懂 + 小白词典

- **说明书面板**：标题页和顶栏都有"怎么玩"入口，3 页图文：
  1. 风口会轮流火：没人理 → 开始火 → 正火 → 太火了 → 在降温。
  2. 在风口开始火的时候，买它的股票，热度涨，股票就涨。
  3. 太火了就该卖，降温会跌。另外每个月底要还钱，还不上就游戏结束。
- **词典**：图鉴里新增一个页签，列出第 2 节词表里的每一个词，说明对应的 A 股原词，并配一句笑话式的例子。

### F4 新手提示（可关）

- 开盘前，猫（或者新手阿韭的内心独白）根据公开信息说一句建议。例如：
  - "AI 热度连涨三天，正在火，可以考虑上车"；
  - "你的螺旋桨精工所在的低空经济在降温，要不要先卖了？"
- 规则：
  - 只用公开查询，不泄露隐藏信息；建议不保证对，文案里也要承认这一点（"我也是猜的"）。
  - 前 3 局默认开启，之后默认关闭；设置里可以切换。

### F5 让画面说话

- 股票小人在涨停、跌停、连续涨停、退市、被买入、被卖出时冒一句台词。
  - 每只至少 4 条，有角色感，例如韭菜芯片涨停时说"今天谁也别想割我"。
  - 台词是内容数据，放在规则层，按 id 存，抽取用独立的随机流。
- 收盘后群友对你今天的结果吐一句槽（规则层已有 comments，扩充文案池），赚大钱、亏大钱、踩空各有说法。

## 5. 验收

- **规则不变**：同一种子、同一操作序列下，账户结果与 0.3.0 逐位相同（新内容的随机抽取用独立的流）。用 replay 做对比测试，覆盖 5 个人设和 1、4、8 三档难度。
- **归因自洽**：每只持仓的归因项之和等于当天涨跌（误差 ≤ 0.01pp），金额之和等于账户当天的变化。测试覆盖涨跌停、两融、止损自动卖出等边界。
- **隐藏信息不泄露**：归因、新闻、新手提示都只用当天已揭晓的信息或公开信息。
- **文案检查**：
  - 新增测试，扫描面向玩家的所有文案，第 2 节左列之外的术语不得出现（"T+1"、"龙头"、"跟风"、"白马"、"妖股"、"题材"、"拐点"、"炸板"、"连板"、"换仓"、"两融"等），提示和词典里的括注除外。
  - 不得出现 emoji。
- **小白试读**：另派一个审阅者扮演从没炒过股的玩家，只看截图和文案，列出所有看不懂的地方，全部处理完才算通过。
- typecheck、test、shot、--meta、--playtest 全部通过，正式构建浸泡无报错。

## 7. 实现决定（规则层，2026-10-10）

- **规则不变的证据**：`tests/replay-030.test.ts` 用 0.3.0（git 20f199f）的代码和机器人跑出的 30 局作基准（5 个人设 × 第 1、4、8 级 × normal / smart，存在 `tests/fixtures/replay-030.ts`），
  在 0.3.1 里按同样的操作序列重放，每次开盘后的账户轨迹和终局局面（账户、持仓、道具、群友战绩、风口热度、统计、账单）的指纹全部一致。
- **F1 归因**：`moveStocks` 只在旁边记下每一项（不改原来的算式，所以逐位不变），引擎再把道具的变化一项一项记下来；各项取两位小数，零头并进"随机波动"。
  除了第 4 节列的几项，另外单列了"今天大环境"（`market`）和"连续涨停的惯性"（`momentum`），因为它们也是涨跌的一部分，并到"随机波动"里反而说不清。
  金额：每格 = 账户开盘前 × 当天收益 × 权重，借钱炒股的放大、分散投资单列为账户层效果，分到分，零头并进金额最大的一格。
- **F2 新闻**：热度变化最大的风口一定有一条；第二条要求热度变化至少 5；大环境涨跌超过 1.2pp 时加一条全场新闻。数在 `BALANCE.news`，只影响文案。
- **F5 台词**：每只股票 4 句自己的（涨停、跌停、被买入、被卖出；危险股多一句退市），再加上每个角色每个时机的通用台词，抽的时候合在一起抽。
  收盘时每只持仓最多一句（退市 > 连续涨停 > 涨停 > 跌停 > 被自动卖出）。
- **吐槽**：第一条按大赚（≥ 4%）> 大亏（≤ −4%）> 涨停 > 跌停 > 踩空（某个风口热度涨了 12 以上而你一只都没有）挑；数在 `BALANCE.talk`。
- **改名**：道具名里带术语的都换成了新说法（如"龙头战法"→"跟紧大哥"、"两融账户"→"借钱炒股"、"情绪指标"→"风口温度计"），完整对照见 docs/core-api-0.3.md 第 15.6 节。
  人设"游资大佬"改成"炒股大佬"；流派成就和人设说明里的道具名直接从道具表取，以后改名不会漏。
- **真实阶段的叫法**：看板公开的状态用"没人理 / 开始火 / 正火 / 太火了 / 在降温"；"风口温度计""熬夜复盘"能看到的真实状态多一档，
  "火起来了"（原来的发酵）和"正火"（原来的主升）分开，否则这两个道具给的信息会变少。
- 突发账单"花呗"是真实产品名，改成"网购分期"。
