# 《开盘》美术与界面打磨 v3（方案，待审）

> 起因：游戏「界面粗糙、背景单调、排版没对齐，不像一个好玩的游戏」，要求所有游戏先精心准备、再动手。
> 本稿只是方案：现状审计、对标、美术方向、进入流程、对局画面、电脑和手机布局、拆分计划。审过之后按第 7 节分 PR 做，每个 PR 附改前改后截图。
> 改前截图（0.13.3）：开发机的 QA 目录 `art-v3/before/`，尺寸 `d1280`（1280×720）、`d1920`（1920×1080）、`d1920w`（1920×960，1920 宽浏览器去掉工具栏后的实际可见区）、
> `d1440`（1440×900，16:10 笔记本）、`phone`（844×390 横屏，2 倍）；21 个画面，清单在 `before/INDEX.md`。下文用「d1920w/07」这样的写法指具体截图。

## 0. 先说结论

开盘不是"一张背景图加按钮"：交易画面已经有分层的小屋（天空随牛熊变、城市、墙、桌、猫、台灯、雨和闪电），角色和图标是统一的 Q 版粗描边。
粗糙感主要来自六处，按玩家最先看到的顺序排：

1. **电脑上不铺满**：画布固定 1280×720 等比放大，浏览器可见区不是 16:9 时两边或上下留米色空条（d1920w：左右各约 106 像素；d1440：上下各约 45 像素）。一打开就显得「小、旧」。
2. **开始菜单是一排排按钮，不是游戏主页**：3 个大按钮 + 6 个小按钮 + 4 个进度格挤在中间（d1920w/01），没有「继续上局」的内容（哪个人设、第几月、多少钱），没有今日挑战、实盘余额这些「今天能干什么」的卡片；主视觉是一整张图，只有 Logo 在呼吸。
3. **所有面板同一种奶油纸**：弹窗、卡片、看板、持仓区都是同一块米色加同一圈描边，层次只靠阴影，一屏里看不出主次（d1920/07、d1920/13）。背后精心画的小屋几乎全被盖住。
4. **几处排版真的歪了**：每日挑战面板的说明气泡盖住人设立绘、右半边空着（d1920/04）；顶栏「账户」「目标」小字和图标不在一条线上，手机上房租字被截断（phone/07）；月底账单的「本月目标没达成」是窗户里一行极小的字（d1920/09）；结束页左下大白框里只有一只股票，右边「收获」空着（d1920/13）；手机结束页的「大厅」按钮插在标题行中间（phone/13）。
5. **关键时刻不够「爽」**：开盘翻牌、收盘出钱、月底还账、通关这几下是这个游戏的高潮，现在只有一张卡翻过来、一行字变一下；没有数字滚动、没有盖章那一下、没有越赚越响的音效层次。
6. **字体只有系统黑体**：大数字、标题、按钮都是同一个系统字体加粗，缺少一个有性格的「游戏字」。

规则核心不动；数值、文案（除排版需要的缩短）不动。

## 2. 对标（只学风格和结构，不拿任何图）

**Balatro**（肉鸽卡牌）——最该学的是「一局的高潮怎么做爽」：
- 计分是一个逐步累加的过程：每张牌依次弹起、数字往上跳、音调一下比一下高，最后总分砸下来。开盘的「收盘出钱」「月底还账」可以照这个节奏：每只股票依次跳出赚亏、总账滚动、到账那一下有重音。
- 局内信息固定在一侧栏（目标、剩余次数、钱），中间留给「正在发生的事」。开盘的左看板、右群聊已经是这个结构，但中间的持仓区太空、太平。
- 背景是一层缓慢流动的色彩，随当前局面变色；开盘的天空已经随牛熊变，可以把这个做得更明显（整屏的光色跟着市况走）。
- 主页极简：大 Logo、动态背景、少数几个大按钮；收藏和设置放边上。

**Luck be a Landlord**（每隔几轮交一次房租的肉鸽）——和开盘「每月还账」几乎同一个循环：
- 房租倒计时一直挂在最显眼的位置，交租是一次单独的「事件」：画面停下来，房东出场、数字结算、过了才继续。开盘的月底账单应该有同样的舞台感，而不是在原画面上盖一个半透明章。

**Slay the Spire**（局外结构）：
- 主页是一张有视差和细微动静的主视觉（云在动、火光在闪），菜单是左侧一列；「继续」直接显示上一局的角色和进度。
- 每局结束后的分数是一行一行加出来的（每项一个名字、一个数），读起来像清单但有节奏。开盘的结束页和「这段日子」可以学这个出场方式。

## 3. 美术方向

**一句话定调：温暖热闹的「散户小屋」，白天看盘、晚上算账；纸做的信息、木做的框、屏幕上跳数字。**

- **保留**现有 Q 版粗描边（描边 `#3a2634`）、右下暗部月牙、纸张颗粒；所有新素材仍是 `tools/art/` 程序生成的 SVG，不引外部图片，来源照旧写进 `public/assets/art/README.md`（本模块的素材说明）。
- **色板（7 色，已在 `theme.ts`，只是用法收紧）**：
  - 纸 `#fff6e6`（信息卡、弹窗）
  - 墙 `#f3e2c7`（底色）
  - 墨 `#3a2634`（描边、正文）
  - 橙 `#ff7a33`（唯一的主按钮色、强调）
  - 金 `#f6c02f`（奖励、稀有、通关）
  - 夜蓝 `#22303f`（屏幕、月底夜晚的底）
  - 涨跌红绿 `#d8342c` / `#137a42`（只给数字和箭头）
- **三种材质，各管一类东西**（解决「所有面板同一种奶油纸」）：
  - **纸**：会变的信息（持仓卡、群聊气泡、事件卡、弹窗正文）。
  - **木**：不会变的框架（顶栏、左看板外框、底部开盘台、主页按钮托盘），木纹程序生成、九宫格。
  - **屏幕**（夜蓝玻璃 + 微弱扫描光）：行情数字、开盘翻牌、收盘总账。现在显示器那一条已经是这个样子，扩到所有「数字在跳」的地方。
- **字体层级**：
  - 现在 `TYPE` 只有 28/18/13 三级，加一级展示：**主页 Logo 和结算大数字 48–64**、标题 22、正文 15、标签 13，行高都对 4 的倍数。
  - 数字用一款有性格的圆体数字字体，只取数字、¥、%、+、-、.、,、万、亿（几 KB）；候选是 SIL OFL 许可的开源字体，许可证随字体文件放进模块，动手前列给你选。中文正文继续用系统字体，不加大字体包。
  - 这一条要加一个字体文件，单独列成可选项，不同意就只做字号层级。
- **光**：小屋一天四个时段，各自一套整屏色调和灯光层：
  - 盘前：清晨暖白；
  - 开盘：日光，市况决定天空；
  - 收盘：傍晚橙；
  - 月底算账：夜里，台灯和显示器发光。
  
  这一条同时解决「背景单调」和「关键时刻没舞台」。

## 4. 进入流程：从「一排按钮」改成「游戏主页」

```
主页（小屋外景） ──快速开始/继续──▶ 小屋（对局）
   ├─ 每日挑战卡 ──▶ 今日题面（人设、难度、我的名次）──▶ 小屋
   ├─ 实盘卡 ──▶ 选档带入 ──▶ 小屋
   ├─ 新一局 ──▶ 选人设、难度、局长 ──▶ 小屋
   └─ 角落：图鉴 · 成就 · 怎么玩 · 设置 · 大厅
```

- **主视觉分层**（远到近 5 层）：
  1. 天空渐变（随时段）；
  2. 远处城市剪影，慢速视差；
  3. 小屋，窗里显示器在闪 K 线；
  4. 草地和股票小人，每个小人有待机动作：眨眼、上下轻晃、偶尔举牌；
  5. 前景飘动的光点或金币粒子。
  
  鼠标移动或手机陀螺仪带一点视差（几个像素），省内存模式全关。
- **左上**：「大厅」，保持现在的位置和样子。**Logo** 放在上方居中，下面一句玩法「看群聊、追风口、每月还上账」。
- **主按钮区（居中偏下）**：一张大「继续」卡，显示人设头像、第几月、账户金额和小小的涨跌线；没有上局时换成「开始第一局」（新玩家），或「快速开始」加上次的人设和难度。
- **三张模式卡（横排，木托盘上）**：
  - **每日挑战**：今天的人设和难度图标、「新题」或「第 n 名」。
  - **实盘**：钱包余额；没登录时写「登录后可用」，不只是灰掉。
  - **新一局**：人设剪影和「8 档难度」。
- **角落小图标**：图鉴、成就、怎么玩、设置，带进度角标（现在的 4 个进度格挪进这里）。
- **新玩家**：「开始第一局」最大，旁边一个「怎么玩」；模式卡里没解锁的先半透明。

## 5. 对局画面（小屋）

- **背景铺满**：电脑上画面四边延伸到窗口边（详见第 6 节），左右露出的墙面、书架、窗帘就是这块延伸出来的地方；UI 仍在中间的 1280×720 安全区里。
- **时段光**：
  - 盘前、开盘、收盘、月底四套整屏色调，加窗外天空随市况变；
  - 台灯、显示器各一层加色光；
  - 切时段时 0.5 秒渐变；
  - 「减少动态效果」和省内存模式下只换色、不渐变、不加光层。
- **网格**：全部按 8 像素对齐，间距从 `SPACE` 取。
  - 顶栏改成木条：五组「图标 + 大数字 + 下方小标签」，同一条基线、等间距；
  - 「账户 · 人设 · Lv」并成一个人设小头像。
- **持仓区**：
  - 四个空格画成桌上的四个「位子」（纸垫），持仓卡放上去有落下的动作；
  - 钱袋缩小移到左侧；
  - 「今天还能买 1 只」改成位子上的发光。
- **关键时刻动效（都要配音效）**：
  - **开盘**：灯光一亮；每张持仓卡依次翻牌，涨跌数字往上滚，大涨时火苗、大跌时冰晶（素材现成）；音调随涨幅升。
  - **收盘**：显示器变成屏幕材质的总账，每只股票一行依次跳出，最后总数砸下，入账时金币飞进钱包。
  - **月底算账**：
    1. 天黑、台灯亮，屏幕切到一张单独的账单舞台：账单纸从桌面滑上来；
    2. 房租、补习班等逐行加；
    3. 「还上了」或「没还上」的大印章砸下（带屏幕震动，「减少动态效果」时不震）；
    4. 目标达成与否写在账单上，不再是窗户里的小字。
  - **通关、清零**：结束页出场前一段 1–2 秒的过场（通关放烟花、彩带，失败下雨），可跳过。

## 6. 电脑和手机各自的布局

- **电脑（铺满）**：
  - 缩放模式从「等比放进 1280×720」改成「等比放进、多出来的边由背景延伸填满」（Phaser 的 EXPAND 一类模式，动手前先在 Phaser 4 上实测）；
  - 所有 UI 仍按 1280×720 的安全区摆，背景层画宽一些（左右各多 25%、上下各多 15%），保证 16:9 到 21:9、16:10 都没有空条；
  - 1920 宽以上不再放大 UI 字号（目前 1920×1080 时整体放大 1.5 倍，字已经够大）。
- **手机（横屏）**：
  - 继续用现有 960×444 的单独布局；顶栏按手机重排（房租和道具不打架）；
  - 主页改成左右两栏：左边主视觉和继续卡，右边三张模式卡纵排；
  - 结束页的「大厅」回左上角。
- **手机竖屏**：维持「请横过来」提示层，背景换成主页同款（做①时顺手看一眼现在的样子再定）。
- **性能**：
  - 省内存设备渲染倍数封顶 2，背景大图按 1 倍光栅化（现规矩不变）；
  - 视差、粒子、光层在省内存模式和「减少动态效果」下全关；
  - 新增素材都进图集，每个 PR 量一次显存估算（`--lowmem` 冒烟里有），不超过现在的 +15%。

## 7. 拆分计划（每个 PR 单独能上线、附改前改后 1280 / 1920 宽 / 手机截图、冒烟零报错）

## 8. 拍板的结论（审过，按第 7 节五个 PR 做）

1. **背景先只延伸**，UI 仍按 1280×720 安全区摆；两栏往外挪等 ③ 上线后看 1920 宽截图再说。② 先在 Phaser 4 上实测 EXPAND，测不通就用「等比放进 + 外面单独画一层背景」代替。
2. **数字字体可以加**：一款 OFL 的，只截数字和几个符号，≤ 10 KB，许可证文件放进模块，素材说明里写来源。跟 ③ 的顶栏木条一起上。
3. **月底账单舞台可以做**，但每月自动停的时间不超过 2 秒：点一下就跳过，设置里能关；实盘和每日挑战也一样能点掉。一局 12 个月加起来不能多出半分钟以上，④ 的 PR 说明里写一局多了多少秒。

## 9. 做了什么

### ① 主页（0.14.0）

- **全局改成 EXPAND**（原定 ② 做，提前到 ①，因为主页要铺满）：Phaser 4.2.1 有这个模式，实测可用。`viewport.ts` 的 `cameraFor` 按画布实际尺寸把 1280×720（手机 960×444）的世界居中；
  窗口缩放后各场景重摆相机；全屏遮罩、点击挡板按 `coverOf`（安全区的三倍大）画，窗口怎么变都盖得住。别的场景的背景还没加宽，延伸出来的部分是和以前空条同色的底色，② 再补。
- **主视觉拆层**（`tools/art/keyart.ts`）：远处城市、山坡（含后排小人）、小屋、六个群聊气泡、一朵云各一张图，城市和山坡左右各加宽 25%；天空在画面里直接画（渐变、慢慢摆的光带、柔光）。
  拼好的一整张 `title_keyart.svg` 仍然生成，只给 README 配图和平台大厅封面用，游戏不加载。
- **主页布局**：Logo 和一句玩法；大卡「继续」（人设立绘、第几月、账户）/「快速开始」/「开始第一局」；三张模式卡（每日挑战带今天的人设和难度、「新题」或名次贴纸；实盘不能点时写原因；新一局带档案进度，
  有存档时里面放「快速开始」小按钮）；右上角一排小入口，图鉴和成就带进度。手机上左边大卡、右边模式卡竖排。
- **动起来**：前排小人用 StockGuy（眨眼、轮流跳），气泡依次弹出再轻轻浮，云慢慢飘，偶尔冒星星，电脑上随鼠标有一点视差；「减少动态效果」、关动画、省内存设备上都不做。
- 顺手修了审计里「每日挑战面板被说明气泡盖住」：点开弹窗时按钮的悬停说明没收起，现在弹窗一开就收起。

### ② 铺满与小屋光（0.15.0）

- **小屋延伸**（`tools/art/scene.ts` 的 `room_left` / `room_right` / `room_top` / `room_bottom`）：按房间坐标接着画墙纸、护墙板、顶角线和桌子，接缝处花纹对得上；两侧各 320、上下各 108，
  覆盖 16:9 到 21:9 和 16:10。两侧各放几件摆设（左：相框、存钱罐、桌头外的落地绿植；右：软木板便利贴、废纸篓），1920×960 时只露出约 80，更宽的屏幕看得更多。四张图进对局时才加载（结束页也补加载）。
- **天气压暗改成矩形**：阴天、雷雨的室内压暗原来是两张 1280×720 的纯色图，盖不到延伸出来的那圈；改成游戏里画的矩形，删掉了 `ambient_flat`、`ambient_bear` 两张图。
- **四个时段**（`Room.setTime`）：清晨（暖白，台灯暗）、白天（不加色）、傍晚（橙，台灯半亮）、夜里（深蓝压暗，台灯全亮）；整屏色调盖在房间上、台灯和显示器光下面，切换时 0.5 秒交叉淡化。
  盘前是清晨，开盘是白天，出收盘结果时是傍晚，月底账单前入夜，第二天盘前回到清晨；快进时停在清晨（一天一两秒，来回换会闪），只有月底入夜。结束页通关是傍晚、出局是夜里。
  「减少动态效果」、关动画时直接换；省内存设备只换色调，台灯不动。
- **主页气泡**：气泡弹出的补间从 0 弹到 `scaleX || 1`，读到的是已经清零的缩放，结果弹到纹理原始尺寸——渲染倍数大于 1（高分屏、1920 宽）时气泡被放大，压到「新一局」卡片上。
  改成先记下显示缩放再弹；宽屏时两侧气泡贴着看得见的边往外挪（最多 160）。

### ③ 对局排版（0.16.0）

- **数字字体**：Kaipan Num（`public/assets/fonts/`，2.6 KB），由 SIL OFL 的 Fredoka 2.001 改出：固定 wght 600，只留数字和 `¥%+-−.,:/×~`，原字体数字是比例宽度，把 0–9 的步进统一成最宽的那个（等宽，滚动不抖），改名（改过的版本不用原名）。
  `FONT_NUM` 排第一，万、亿、箭头逐字回退；启动时用 FontFace 先等它最多 2 秒（画布上的字不会自己重画）。来源和改法写在字体目录的 README，许可证 `OFL.txt` 随字体放。
- **顶栏木条**（`addWood`，程序画，不占素材）：深木框 + 浅枫木面 + 几道木纹；面板色对 muted 小字对比度约 4.6:1，原来的字直接放上来。
  每组「图标 + 大数字」一行、小字一行，小字中线对齐（电脑 48、手机 38）；「账户 · 人设 · Lv」从数字上面挪到下面。和方案的差别：没有把人设并成小头像（顶栏横向放不下头像和五组数字），等 ⑤ 再看。
- **8 像素网格**：这一版只落到顶栏（电脑顶栏挪到 y 8，各组的行位置按 8 对齐）和新画的位子、每日挑战面板；左看板、群聊手机的外框尺寸没动（里面的排版跟着宽度算，改了风险大于收益）。
- **持仓区四个位子**：空格一块一块画成纸垫（虚线座位），不再并成一大块「现金」；钱袋缩到 34 放第一块左上角，旁边是现金数；今天还能买时纸垫外圈发金光、轻轻呼吸（以前是「还能买 N 只」大字），买不了时写原因。别的推荐小人一块纸垫放一只。
- **手机顶栏**：月度目标那一行右边只剩七八十宽，房租只写金额（名目、差多少的后果在悬停里），再按宽度收。
- **每日挑战面板**：右边改成三块整宽小卡（人设、难度、今日最好），没打过写「今天还没打」；**结束页**手机上「大厅」回到纸卡左上角，头像那一行右移让位。

### ④ 关键时刻（0.17.0）

- **月底账单舞台**（`monthEnd.ts` 的 `playBill`，节拍在 `billTiming.ts`）：入夜（② 的时段光）→ 账单纸从画面底下（桌面）滑上来 320 → 各行依次出现、一行一声音调上升（一共 ≤ 350）→ 剩下的钱从还前账户滚到结果 300、落下时砸一下 → 盖章 240（带震屏，减少动态效果时不震）→ 停 700。
  每个月自动停 ≤ 1.91 秒，`tests/bill-timing.test.ts` 锁住 ≤ 2 秒；点一下跳过整段（实盘、每日挑战一样）。设置里「月底账单：完整 / 简短」，简短时账单和章直接出来，停 0.9 秒。
  本月目标达成没有写在账单最下面（靶心图标 + 「本月目标「名字」达成 / 没达成」）；月底那天才出结果的，不再另外在屏幕中间飘一行字、多停 0.9 秒。
- **开盘**：翻牌、火苗冰晶、数字滚动、音效原来就有；加了屋里灯一亮（`Room.flashLights`，0.3 秒，不占节拍）。
- **收盘**：显示器上的总账砸一下，赚了的话金币从显示器飞进顶栏钱包（不占节拍）。顺手修了金币飞的终点：以前写死 (312, 36)，手机上和新顶栏都对不上，改成顶栏给的钱包位置。
  和方案的差别：没有把显示器换成「每只股票一行」的总账，每只的涨跌收盘小结卡里已经有，再在显示器上逐行跳一遍每天都要多停，和「一局不能变长」冲突。
- **通关 / 出局过场**（`EndScene.cutscene`）：结束页出来前 1.2 秒，通关放三朵烟花、出局三朵雨云，一行大字；盖一层挡板免得误点，点一下跳过；关动画、减少动态效果时不放。
- **一局多了几秒**（1 倍速）：月底账单 2.21 → 1.91 秒（每月 −0.3 秒），结束过场 +1.2 秒（一局一次），开盘灯光、收盘金币不占节拍。
  完整一年 12 个月：−3.6 + 1.2 = **−2.4 秒**；短局 5 个月：−1.5 + 1.2 = **−0.3 秒**；月底那天出目标结果的月份每次再省 0.9 秒。设置成「简短」时每月 0.9 秒。


### ⑤ 面板材质与次要画面（0.18.0）

- **三种材质**：纸（弹窗、看板，原来就是 `addPaper`）、木（顶栏之外，左边风口看板外面垫一圈木框，「开盘」按钮下面一块木托，都用 `addWood`）、屏幕（结束页的月份条改成一条深色显示屏）。
- **结束页**：一排月份小格换成显示屏，每格下面一根柱子是这个月账户的涨跌（`stats.monthRets`，悬停看数字），还上的绿边、没还上的红边、没走到的暗格；电脑上收获栏多一行「最亏」那只（跌超过 5% 才写，和最赚那只不是同一只）。
  分享按钮没挪进按钮行：电脑上那一行已经放了三个按钮，再加一个要缩字号。
- **这段日子**：右上角一张心情图（天气 + 一张脸：牛市太阳、泡沫火箭、横盘多云、熊市下雨、崩盘雷雨），手机放在市况签后面。
- **好友挑战卡**：打开链接、还没打过时，左边这局的人设立绘，右边发起人（平台不给头像，画一个写名字头一个字的圆）、难度徽记、他的成绩。
- **图鉴锁卡**：深紫底换成浅一号的纸色、淡点、淡描边，问号也淡下来；一排里一半没解锁时不再压得很重。知识卡的锁卡同样处理。
- **顶栏人设小头像，再看了一次，还是不做**：头像位子只有 24（手机）/ 28（电脑）像素，立绘是 480×600 的全身像，缩到这么小只剩一团颜色；而且立绘在 meta 图集里，对局不加载，为一个小图标多拉两张图集页不划算。账户下面的小字已经写了人设和级别。
- **设置**：没有改，和别的弹窗是同一张纸。
