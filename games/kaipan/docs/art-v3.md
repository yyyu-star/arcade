# 《开盘》美术与界面（v3）

> 现行的美术和界面规范。各版改了什么见 `CHANGELOG.md`（0.14.0–0.18.0 是这一轮）；手机和平板的尺寸、字号见 `mobile.md`。
> 规则核心、数值不因为画面改动而动。

## 1. 方向

温暖热闹的「散户小屋」：白天看盘、晚上算账；纸做的信息、木做的框、屏幕上跳数字。

- Q 版粗描边（描边 `#3a2634`）、右下暗部月牙、纸张颗粒。所有素材是 `tools/art/` 程序生成的 SVG，不引外部图片，来源写进 `public/assets/art/README.md`。
- 色板（`theme.ts`）：纸 `#fff6e6`（信息卡、弹窗）、墙 `#f3e2c7`（底色）、墨 `#3a2634`（描边、正文）、橙 `#ff7a33`（唯一的主按钮色、强调）、
  金 `#f6c02f`（奖励、稀有、通关）、夜蓝 `#22303f`（屏幕、夜里）、涨跌红绿 `#d8342c` / `#137a42`（只给数字和箭头，可在设置里对调）。
- 三种材质，各管一类东西：
  - **纸**（`addPaper`）：会变的信息，持仓卡、群聊气泡、事件卡、弹窗正文、看板；
  - **木**（`addWood`，程序画，不占素材）：不会变的框架，顶栏、风口看板外框、「开盘」按钮下的木托；
  - **屏幕**（夜蓝小屏）：数字在跳的地方，显示器、结束页的月份条。
- 字：中文用系统字体。数字用 Kaipan Num（`public/assets/fonts/`，约 2.6 KB）：由 SIL OFL 的 Fredoka 改出，固定字重、只留数字和 `¥%+-−.,:/×~`、
  0–9 等宽（滚动不抖），万、亿、箭头逐字回退；启动时最多等它 2 秒（画布上的字不会自己重画）。来源和改法见字体目录的 README。
- 字号、间距、圆角从 `theme.ts` 的 `TYPE`、`SPACE`、`RADIUS` 取；新画的东西按 8 像素网格对齐。

## 2. 光：小屋的一天

`Room.setTime` 四个时段，整屏色调盖在房间上、台灯和显示器光下面，切换时 0.5 秒交叉淡化：

- 清晨（暖白，台灯暗）：盘前；
- 白天（不加色，窗外天空随市况变）：开盘；
- 傍晚（橙，台灯半亮）：出收盘结果时；
- 夜里（深蓝压暗，台灯全亮）：月底账单前，第二天盘前回到清晨。

快进时停在清晨（一天一两秒，来回换会闪），只有月底入夜。结束页通关是傍晚、出局是夜里。阴天、雷雨的室内压暗是游戏里画的矩形，盖得到铺满出来的那圈。
「减少动态效果」、关动画时直接换；省内存设备只换色调，台灯不动。

## 3. 主页（`scenes/TitleScene.ts`）

- 主视觉分层（`tools/art/keyart.ts`）：天空在画面里画（渐变、慢慢摆的光带）；远处城市、山坡（含后排小人）、小屋、六个群聊气泡、一朵云各一张图，城市和山坡左右加宽 25% 用来铺满。
  拼好的整张 `title_keyart.svg` 只给 README 和平台大厅封面用，游戏不加载。
- 动起来：前排股票小人眨眼、轮流跳，气泡依次弹出再轻轻浮，云慢慢飘，偶尔冒星星，电脑上随鼠标有一点视差；「减少动态效果」、关动画、省内存设备上都不做。
- 布局：Logo 和一句玩法；一张大卡（继续上局：人设立绘、第几月、账户 / 快速开始 / 开始第一局）；三张模式卡（每日挑战带今天的人设和难度、「新题」或名次贴纸；
  实盘不能点时写原因；新一局带档案进度）；右上角一排小入口（怎么玩、图鉴、成就、设置、关于），图鉴和成就带进度；左上角「大厅」。
  电脑上大卡居中、模式卡一排；手机上见 `mobile.md`。

## 4. 对局画面

- 顶栏是木条：每组「图标 + 大数字」一行、小字一行，小字中线对齐（电脑 48、手机 38）；「账户 · 人设 · Lv」写在账户数字下面。
  不放人设小头像：位子只有 24–28 像素，全身立绘缩到这么小只剩一团颜色，而且立绘在 meta 图集里，对局不加载。
- 持仓区：每个空格是一块纸垫（虚线座位）；钱袋放第一块左上角，旁边是现金；今天还能买时纸垫外圈发金光、轻轻呼吸，买不了时写原因。推荐的小人一块纸垫放一只。
- 每日挑战面板：右边三块整宽小卡（人设、难度、今日最好）。
- 「这段日子」：右上角一张心情图（牛市太阳、泡沫火箭、横盘多云、熊市下雨、崩盘雷雨）。
- 结束页：月份条是一块显示屏，每格一根柱子是这个月账户的涨跌（悬停看数字），还上的绿边、没还上的红边、没走到的暗格；电脑上收获栏有最赚、最亏两只。
- 好友挑战卡：左边这局的人设立绘，右边发起人（平台不给头像，画一个写名字头一个字的圆）、难度徽记、他的成绩。
- 图鉴、知识卡的锁卡用浅一号的纸色、淡点、淡描边、淡问号。

## 5. 关键时刻

- **开盘**：持仓卡依次翻牌，涨跌数字往上滚，大涨冒火、大跌结冰，音调随涨幅升；屋里灯一亮（`Room.flashLights`，0.3 秒，不占节拍）。
- **收盘**：显示器上的总账砸一下，赚了的话金币从显示器飞进顶栏钱包（终点用顶栏给的钱包位置，不占节拍）。每只的涨跌在收盘小结卡里，不在显示器上逐行再跳一遍（每天都会多停）。
- **月底账单**（`trade/monthEnd.ts` 的 `playBill`，节拍在 `billTiming.ts`）：入夜 → 账单纸从桌面滑上来 → 各行依次出现、一行一声音调上升 → 剩下的钱从还前账户滚到结果、落下时砸一下 →
  盖章（带震屏，减少动态效果时不震）→ 停一下。本月目标达成没有写在账单最下面。
  每个月自动停不超过 2 秒（`tests/bill-timing.test.ts` 锁住），点一下跳过整段（实盘、每日挑战一样）；设置里「月底账单：简短」时账单和章直接出来，停 0.9 秒。
- **通关 / 出局过场**（`EndScene` 的 `cutscene`）：结束页出来前 1.2 秒，通关放烟花、出局下雨，一行大字；点一下跳过，关动画、减少动态效果时不放。

底线：这些动效加起来不能让一局明显变长（一局 12 个月多出的时间不超过半分钟）。

## 6. 铺满

- 全部场景用 Phaser 的 EXPAND：UI 按安全区摆（电脑 1280×720，手机按 `phoneWorld`），`viewport.ts` 的 `cameraFor` 按画布实际尺寸把世界居中；
  窗口缩放后各场景重摆相机；全屏遮罩、点击挡板按 `coverOf`（安全区的三倍大）画，窗口怎么变都盖得住。
- 小屋延伸（`tools/art/scene.ts` 的 `room_left` / `room_right` / `room_top` / `room_bottom`）：两侧各 320、上下各 108，接着画墙纸、护墙板、顶角线和桌子，
  覆盖 16:9 到 21:9 和 16:10；两侧有摆设（相框、存钱罐、绿植；便利贴、废纸篓）。四张图进对局时才加载。
- 1920 宽以上 UI 跟着整体放大，不另加字号。

## 7. 素材和性能

- 素材进图集（`public/assets/art/v3/atlas/`，`node tools/art/bake.ts` 2 倍烘焙），缺失时回退单张 SVG。
- 省内存设备渲染倍数封顶 2、整屏背景按 1 倍光栅化；视差、粒子、光层在省内存模式和「减少动态效果」下关掉。新增素材后跑 `--lowmem` 冒烟看显存估算。
