# 《开盘》0.2 设计稿：参考 Balatro 的核心循环

> 状态：方向已定；阶段 A（规则核心）已完成，数值按第 12 节的模拟验收调过（2026-10-10），
> 第 4、6、8 节写的是调整后的值，第 14 节是实现时补充的规则细节。
> 依据：2026-10-09 的数值分析与首局体验评审（原始数据是临时文件，没有进仓库），
> 以及维护者定下的方向。

## 0. 设计支柱（维护者定）

1. 简单易上手：每天只做两件事——选一只股票、选方向。
2. 模拟炒股的代入感：选股、看消息、看走势、追涨杀跌、关灯吃面。
3. 轻松幽默：股票、策略、Boss、消息标题、称号都玩散户梗。全部虚构，不出现真实公司、真人、真实机构或政治内容。
4. 机制简单、搭配丰富：复杂度放进策略、锦囊、行业等级的组合里，不放进基础操作里。
5. 高难度真的难：基础难度友好；0.3 的难度等级逐级加约束。

## 1. 0.1 的问题与对应改法

| 0.1 的问题（模拟数据） | 0.2 的改法 |
|---|---|
| 提前交卷是陷阱：过线就交卷通关率 3%，不交卷 29% | 改成本期收益目标，达标立即收工，剩余天数自动换经费（同 Balatro） |
| 仓位、杠杆是假选择：满仓 + 最大杠杆永远最好 | 去掉仓位和杠杆。风险改由选哪只股票（波动大小）表达；杠杆类效果放进策略和锦囊 |
| 净值累计，开局安全垫决定生死，玩家觉得全凭运气 | 每期独立计分，亏损不滚雪球；"换一批"让玩家能对抗坏运气 |
| 网格交易是必选，五个策略是负价值，几乎没有协同 | 策略按流派重做，每张都用开局价值测试验收 |
| 后期经费过剩、没有出口 | 商店加锦囊和行业研报；刷新涨价 |
| 第一个 Boss 是断崖，没有应对提示 | 季度开始就公布 Boss 和一句应对提示；第一季度只抽温和的 Boss |
| 单一指数，选择维度少 | 股票池 + 每天发牌：行业是"花色"，风格是"波动档位" |

## 3. 一局的流程

- 开局：基金规模 ¥100 万（只是分数），经费 ◆4，股票池 15 只，没有策略和锦囊，各行业 Lv1。
- 一局共 8 个季度 × 3 场考核 = 24 场。每个季度开始时公布本季 Boss 和应对提示。
- 每场考核：
  - 目标 T（本期累计收益率，单位为百分点）。
  - 最多 3 个交易日、2 次换一批。
- 每个交易日：
  1. 发牌：从股票池随机发 3 张互不相同的股票卡。
  2. 玩家可以使用锦囊（部分锦囊要先选一张卡），也可以花 1 次"换一批"把 3 张卡全部换掉。
  3. 玩家选 1 张卡和方向（做多 / 做空 / 高抛低吸），然后开盘。没有"空仓"选项：每天都要交易，和 Balatro 每回合都要出牌一样。
  4. 日内走势 48 个 tick，止损类策略在盘中生效。
  5. 结算：当日收益率 r 经策略、行业等级修正得到最终收益 f（见第 5 节）。本期进度 += f；基金规模 ×= (1 + f)。
  6. 进度 ≥ 目标时立即过关：经费 = 基础奖励 + 剩余交易日 × 1 + 利息，然后进入商店。3 天用完仍未达标，本局结束（风控官等策略可以救一次）。
- 过关后进入商店，离开商店后开始下一场考核。打完 24 场即通关。

## 4. 股票与行情

### 4.1 行业（花色）与风格（波动档位）

| 风格 | 整日漂移（牛/熊） | 波动 | 消息准确率 | 说明 |
|---|---|---|---|---|
| 蓝筹 blue | ±0.6% | 0.3% | 90% | 稳，赚得少 |
| 成长 growth | ±1.2% | 0.6% | 80% | 中间档 |
| 妖股 meme | ±3.0% | 1.5%，有跳空 | 65% | 大起大落，消息最不靠谱 |

- 所有股票涨跌停 ±10%。
- 震荡市按风格放大波动并均值回复，利于高抛低吸。
- 暴雷（panic）是大跌加跳空。
- 高抛低吸的反手带宽按风格的波动缩放。
- 行业：科技 tech、消费 consumer、医药 pharma、金融 finance、能源 energy。

### 4.2 状态与消息

- 每只股票各有一条马尔可夫状态链（bull 利好 / bear 利空 / range 震荡 / panic 暴雷），转移矩阵沿用 0.1，可以调。
- 开局前先生成 5 天历史。股票卡上画最近 5 天的迷你日 K，体现状态的延续性，也是推理素材。
- 每只股票每天的状态、日内走势只由 (种子, 股票, 日) 决定，和发了哪些牌、换了几次无关。换一批只是让你看到更多股票，不会改变它们的命运。锦囊能改今天的状态（利好公告等），改动属于操作序列，回放仍然确定。
- 消息：每张卡显示一条倾向（利好 / 利空 / 震荡 / 暴雷）和准确率。错的时候随机指向另外三种之一。
- 每张卡另配一条幽默标题，从对应倾向的标题池里按种子抽。标题只是装饰，不带额外信息。

## 5. 计分

- 方向收益 r（百分比）：
  - 做多：收盘 / 开盘 − 1
  - 做空：取负
  - 高抛低吸：沿用 0.1 的反手逻辑
  - 止损等提前平仓按平仓价计算
- 盈利日（r > 0）：f = r × (1 + 加成) × 倍率 + 固定
- 亏损日（r ≤ 0）：f = r × 亏损系数 + 固定
- 行业等级：交易 Lv n 行业的股票且盈利时，加成 +0.5 × (n − 1)。初值可调。
- 展示用百分点，例如"+1.8% ×（1 + 0.6）× 2 = +5.8%"。进度条按目标显示。

## 6. 目标曲线（初版）

- 季度基础目标 B（百分点）：Q1 0.55、Q2 1.2、Q3 2.15、Q4 3.5、Q5 5.3、Q6 7.5、Q7 9.8、Q8 12.5。
- 小考 ×1，大考 ×1.2，Boss ×1.3，再乘该 Boss 自己的目标系数（0.38–1，规则越狠目标越低，见 8.3）。
  所以 Boss 考的目标可能比同季度小考还低，界面要写明"目标已按 Boss 规则下调"。
- 实测（normal 通关局）：后期盈利日的总倍率中位数约 ×9–11，单日最终收益中位数约 +67%，
  通关时基金规模中位数约 ¥2,576 万（q90 约 ¥1.5 亿）。一天翻倍的爽感有了；"涨到万亿"
  和技能曲线冲突，不追求。
- 目标曲线集中放在 balance.ts，按第 12 节验收。

## 7. 经济

- 开局经费 4。
- 过关奖励：小考 3、大考 4、Boss 5；剩余交易日每天 +1；利息每 5 经费 +1，最多 +5。
- 商店：2 张策略 + 2 张锦囊或行业研报。刷新 ◆5，同一商店内每次 +1。
- 价格：
  - 策略：普通 4–5，稀有 6–7，传奇 8–10。
  - 锦囊和研报：3。
  - 卖出回收一半，向下取整，至少 1。
- 槽位：策略 5 个，锦囊 2 个。

### 8.1 策略（26）

**普通：**
- `stop_loss` 止损纪律：日内浮亏达 2% 自动平仓。
- `long_faith` 多头信仰：做多盈利时加成 +0.6。
- `short_army` 空军司令：做空盈利时倍率 ×1.5。
- `grid` 网格交易：高抛低吸每反手一次，固定 +0.3 个百分点。
- `dividend` 红利策略：每个盈利日 +1 经费。
- `trend` 趋势跟随：当日涨跌幅超过 3% 且方向做对时，加成 +1。
- `hedge` 对冲组合：亏损系数 ×0.5。
- `guru` 股吧大神：每个亏损日 +2 经费（割肉安慰奖）。
- 行业信仰（交易该行业股票盈利时加成 +1）：
  - `faith_tech` 科技信仰
  - `faith_consumer` 消费信仰
  - `faith_pharma` 医药信仰
  - `faith_finance` 金融信仰
  - `faith_energy` 能源信仰

**稀有：**
- `analyst` 消息灵通：消息准确率 +15%。
- `compound` 复利信徒：连续盈利每多 1 天，加成 +0.2；亏损清零。
- `bottom_fisher` 抄底王：前一天亏损时，今天盈利倍率 ×2。
- `value_investor` 价值投资：交易蓝筹盈利时倍率 ×2。
- `meme_hunter` 妖股猎人：交易妖股盈利时倍率 ×1.5；亏损系数 ×0.8。
- `extra_card` 多看一只：每天多发 1 张股票卡。
- `turnover` 高换手：每期换一批 +1。
- `lights_off` 关灯吃面：暴雷股做空盈利时倍率 ×4。

**传奇：**
- `quant` 量化模型：每通过一场考核，倍率永久 +0.04（从 ×1 起累积）。
- `insider` 内幕人脉：每天发牌后揭示一张卡的真实状态。
- `risk_officer` 风控官：某期未达标但进度 ≥ 目标的 50% 时视为通过，之后离职。
- `all_in` 满仓干：当日收益 ×1.7，亏损也 ×1.7。
- `contrarian` 反向指标：逆着消息方向操作并盈利时，倍率 ×4。

- 价值投资 + 消息灵通
- 反向指标 + 妖股（消息最不准）
- 满仓干 + 对冲
- 空军司令 + 关灯吃面
- 复利信徒 + 止损纪律
- 多看一只 + 高换手 + 内幕人脉
- 股吧大神 + 满仓干

## 11. 教程（画面阶段做）

10 步左右，用固定种子：
1. 看卡：行业、风格、消息、迷你日 K
2. 选一张利好的成长股做多
3. 看结算公式
4. 演示换一批
5. 第 3 天前达标收工，剩余天数换经费
6. 在商店买一张行业信仰和一张对应的行业研报
7. 讲 Boss 预告

## 12. 验收（模拟，每组 ≥ 2000 局，写出达标与否和数据）

机器人全部按新规则重写：
- random：随机选卡、随机方向。
- follower：选消息准确率最高的卡，照消息做。
- normal：模拟普通玩家。看消息和近 5 日走势，三张都差时用换一批，商店按朴素规则买。
- smart：后验 × 期望值决定选卡、方向和是否换一批，商店策略合理。
- oracle：知道真实状态。

| # | 项目 | 标准 |
|---|---|---|
| 1 | 技能曲线 | normal 通关率 35–50%；smart ≥ normal + 10pp；follower ≤ normal − 10pp；random ≤ 3%；oracle ≥ 95% |
| 2 | 难度曲线 | normal 在第一季度出局 ≤ 10%；任一 Boss 的条件失败率 ≤ 非 Boss 均值 × 2 |
| 3 | 策略价值 | 用"开局持有"测，每个策略的价值落在基线 ±10pp 以内 |
| 4 | 构筑多样性 | normal / smart 通关局里，最常见的 3 种策略组合合计占比 < 30% |
| 5 | 换一批有用 | smart 平均每期用 ≥ 0.8 次；禁用后 smart 通关率至少降 5pp |
| 6 | 选卡有意义 | smart 选中的三种风格各占 ≥ 15% |
| 7 | 经济 | Q6 起进店时平均经费 ≤ 25；平均每次进店至少买 0.7 件 |
| 8 | 时长 | normal 通关局的交易日数在 35–55 天（原定 45–65；实测 37.7 天，约 15 分钟一局，符合"简单易上手"，不为凑天数加难度） |

达不到的项要写明原因和建议，不要为了达标牺牲第 0 节的设计支柱。
