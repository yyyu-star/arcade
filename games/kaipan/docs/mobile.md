# 手机和平板

电脑按 1280×720 的世界布局。手机和触屏平板换一套「手机世界」，字号、点击区按渲染到屏幕上的实际像素定。
验收标准：正文 ≥ 12 像素、数字 ≥ 14、可点的 ≥ 44（都是屏幕上的 CSS 像素）。

## 什么时候用手机布局（`theme.ts` 的 `pickPhoneLayout`）

- 短边不超过 500 的横屏，或短边不超过 500 的触屏竖屏（微信里点开链接默认竖屏，先看到转屏提示，转过来铺满的是手机版）；
- 触屏平板：电脑布局缩到这块屏上 11 号字到不了 12 像素（1024×768、1180×820 都是这样），也用手机布局，不看方向；
- URL 参数 `layout=phone` / `layout=desktop` 强制。

开局时定一次，中途改窗口、转屏都不换布局（转屏只是同一块画布换方向铺满）。

## 世界尺寸和最小字号

- 世界高固定 404，宽 = 404 × 屏幕长边 ÷ 短边，取偶数，限制在 718–960（`phoneWorld`）。iPhone SE（667×375）是 718×404（0.93 倍），
  844×390 是 874×404（0.97 倍）；更长的屏宽封顶 960，更方的屏宽取 718，多出来的部分由 EXPAND 补背景。
- `PHONE_SCALE` 是手机世界铺到屏幕上的倍数（平板在 1.4 以上）。比 SE 还矮的屏（640×360、780×360 约 0.89，568×320 约 0.79）按它抬下限：
  正文最小 `max(13, ⌈12 ÷ 倍数⌉)`（`ui/text.ts` 的 `MIN_TEXT_SIZE`），数字最小 `max(16, ⌈14 ÷ 倍数⌉)`（`MIN_NUM_SIZE_PHONE`，
  只有数字的文字没标 `num` 也按数字算），点击区最小 `max(50, ⌈44 ÷ 倍数⌉)`（`ui/button.ts` 的 `HIT_MIN`）。
- 场景声明 `phoneReady` 才按手机世界布局（`viewport.ts`）；没声明的（只有启动页）按电脑布局整体缩小放进来。

## 竖着拿（`src/platform/orientation.ts`）

触屏设备（`(orientation: portrait) and (pointer: coarse)`）竖着拿时盖一层 DOM 提示「把屏幕横过来」，手机和平板都提示；
提示层左上角也有「大厅」，一局进行中先问一次。不支持竖屏里玩。

## 主页（`meta/homeGeo.ts` 的 `phoneHome`）

- 要点的都在下半屏一排（高 112）：右下是大卡（继续 / 快速开始，宽 = 世界宽 × 0.42，300–404），左边是模式卡（每日挑战、实盘、新一局，单独部署没有实盘）；
  有没打完的局时大卡是「继续」，快速开始挪到大卡正上方。上半屏是 Logo、一句玩法和主视觉（按 0.62 缩，小人的脚踩在卡片上沿）。
- 版本号在右上角小入口下面。

## 弹窗和结束页

- 整屏弹窗统一按 `ui/dialog.ts` 的 `phonePanel`：宽 = min(940, 世界宽 − 16)，高 = min(430, 世界高 − 12)，SE 上 702×392。
- 结束页纸卡也是这个大小；右栏战绩格一格不到 140 宽时竖排（`meta/bits.ts` 的 `statTile` 的 `stacked`），金额用短写法，月份轨道一格的间距按宽度算。
- 实盘开局的档位卡在手机上排三行，一万以上的筹码写成「万」，不截断。

## 交易页（`trade/layout.ts` 的 `mobileLayout`）

- 右边群聊 / 风口一块宽 = 世界宽 × 0.355（256–338），左边是持仓（高 214），下面是小结和开盘键（开盘键宽 140）。
- 顶栏（`trade/topBarGeo.ts`）：设置、怎么玩、银行贴右边；中间按「要还的钱 → 账户 → 日期」的顺序让宽度，还不够就收道具栏（放不下的进「+N」）。
- 持仓卡在 SE 上约 104 宽：小人、走势框收窄，「跑赢 / 跑输」挪进悬停，累计那条放不下就只写数字，热度和连涨签放不下就只留连涨签。
- 小结一枚至少 96 宽，放不下的几只点「详情」看；更窄时不放头像。
- 推荐在「推荐」页签里，按数字键买的时候自动切过去。

## 省内存设备

iOS 和触屏设备渲染倍数封顶 2，整屏背景按 1 倍光栅化（`theme.ts` 的 `LOW_MEMORY`，原因见仓库根 `AGENTS.md` 第 4 节）。
`node tools/mem-probe.ts` 按几种视口和 DPR 估算显存；冒烟 `npm run shot -- --lowmem` 模拟一次。

## 怎么验

`npm run shot -- --phone`（改开局面板时加 `--live`）。多尺寸检查按手机横屏 568×320 到 932×430、手机竖屏（只看转屏提示）、平板竖横、
电脑 1280×720 / 1366×768 / 1920×1080 一组跑：不出屏、不互相压、字和点击区到下限、控制台零报错。
