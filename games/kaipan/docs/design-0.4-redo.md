# 《开盘》0.4 重做：0.3 的游戏 + 真实历史行情驱动涨跌

> 2026-10-12。维护者试玩 0.4.0-alpha.1 后否定了"真实炒股软件"方向：
> "咋这么复杂，这么严肃，我看不懂，之前 0.3 的故事，情报，游戏，成就，图鉴，闯关，难度，肉鸽，道具，咋都没了……
> 不要分为三年……每次自己找点行情，随机一个游戏出来，可以是任意年份，可以是任意行情，我让你接入行情的目的是模拟真实涨跌，
> 不是让你变为真实的炒股，我要保持趣味性。这是一个游戏！！！"
> 维护者决定：不回退线上，重构完成全部内容后重新发布 0.4。

## 0. 对照维护者的约束

| 约束 | 本稿做法 |
|---|---|
| 这是游戏，要趣味 | 以 0.3.1 的完整游戏为骨架：故事、群聊情报、闯关（月供）、难度、肉鸽三选一、道具、人设、成就、图鉴、每日挑战全部恢复，大白话界面保留。 |
| 真实涨跌 | 只把"涨跌从哪来"换成真实历史：每只股票小人背后挂一只真实股票的一段真实走势，题材热度、大盘情绪由真实行业和大盘走势推出。 |
| 不分年份，随机行情 | 每局从 1996–2018 全部历史里随机抽一段（可能是牛市、熊市、泡沫、崩盘、横盘），玩的时候不告诉你是哪年。 |
| 看得懂、不严肃 | 不出现 Reg T、维持保证金、SEC 费这些；画面沿用 0.3.1 的大白话。真实感只体现在走势本身和局末"这段日子"的小故事。 |
| 有依据 | 依据只在图鉴"行情段"页留一句"涨跌取自真实历史行情（公有领域数据），公司和时间都隐去了"，不打扰游戏过程。 |

## 1. 一局的样子（与 0.3.1 相同，只列变化）

- 开局：选人设、难度，照旧。后台随机抽一段真实行情（"行情段"），不显示年份。
- 每天：看群聊情报、挑股票进持仓、推进一天；月底付月供、三选一奖励，照旧。
- 局末"这段日子"（维护者 2026-10-12 改定，代替原来的揭晓页）：不说是哪段真实行情，不给年份、日期、真实公司名和任何 id，也不展示"小人 → 真身"。用游戏里的花名（股票小人、风口、群友、本局人设）写一个 4–8 句、有起承转合的幽默小故事：那段时间发生了啥（段内真实大事转写成情节，按游戏内时间说"第二个月月底"，公司换成泛称或本局同风口的小人），结合市况和玩家自己的表现（通关还是爆掉、赚得最多和亏得最多的小人、跟没跟群友），再加一句结局吐槽。图鉴"行情段"页只显示游戏化标题、市况和这段的故事（可重看）。
- 图鉴新增"见过的行情段"：收集过哪些年份、哪些大事件（科网泡沫、金融危机、牛市……），作为收集要素。

## 2. 行情：真实走势驱动 0.3 的模型

0.3 的行情是"题材热度生命周期 + 大盘 + 个股性格（beta、噪声、涨跌停）"。重做后：

- **大盘**：用行情段里真实的合成大盘逐日涨跌，决定 0.3 的大盘情绪（牛/平/熊）和大盘涨跌。
- **题材（风口）**：每个题材对应一个真实行业（互联网、半导体、银行、能源……）。题材热度由该行业在行情段里的真实相对强弱推出（例如 10 日相对大盘的超额收益映射到热度），所以风口轮动是真实轮动，不再纯随机。
- **个股**：每只股票小人绑定该行业里一只真实股票，当天涨跌 = 那只真实股票当天的真实涨跌，再套 0.3 的游戏规则：
  - 涨跌停按 0.3 的规则截断（这是游戏规则，不是美股规则）；
  - 性格（带头大哥、小弟、老实股、过山车、危险股）按真实股票在行情段里的波动和与行业的相关性来分配，而不是反过来改走势。
- **事件、道具、难度**：仍按 0.3 的机制作用（例如道具改变能买几只、难度加崩盘月）。会改变涨跌的事件（崩盘、利好）尽量对齐真实：行情段里真实的大跌日就是"崩盘"事件出现的日子。
- **价格**：可以按开局价重新标定（例如统一换算到 0.3 的价格区间），不显示真实价格，避免玩家用真实价格反查年份。
- **确定性**：同一个"行情段 id + 种子 + 操作"一定得到同一个结果；每日挑战大家抽到同一段。

## 3. 数据

- 来源仍是 WIKI Prices（公有领域）。Nasdaq Data Link 的 key 放到 `~/.config/nasdaq/nasdaq.env` 后，下载 1996–2018 全量到 `~/data/wiki-prices/`（不进 git）。
- 预先切好"行情段库"：长度等于一局的交易日数（按 0.3 的月数和每月天数），覆盖 1996–2018 各种市况，目标 150–300 段，每段一个小文件（只放这一局用到的约 20–40 只股票、几个行业和大盘），开局只下载抽中的那一段。
- 每段带标签：市况（牛、熊、泡沫、崩盘、横盘）、游戏化标题、大事件（数据里还有年份区间和化名，只供生成和测试，画面不显示）。故事页和图鉴用。
- 0.4.0-alpha.1 已有的管线（tools/data）、化名表、核对报告继续复用。

## 4. 从 0.4.0-alpha.1 里保留什么

- 保留：数据管线和化名、剧情稿里的真实大事和群友设定（作为情报和局末小故事的素材）、"为什么赚、为什么亏"的拆解思路（0.3.1 已有）。
- 收起：美股交易引擎（融资、追保、Reg T、费用表、条件单）、按年份开局、K 线终端式界面、数据与依据弹窗。代码保留在仓库里（`src/core/us/`、`src/view/us/` 之类），不进游戏。
- 仓位和杠杆（0.4 早期就提过）：用游戏化的方式加，比如"重仓"按钮（这只股票买双份）和"借钱"道具（杠杆，涨跌翻倍、亏到底就爆仓），不引入保证金术语。
