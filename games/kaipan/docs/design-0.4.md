# 《开盘》0.4 设计稿：美股真实历史、仓位与杠杆、真实事件剧情

> 2026-10-11 第三版。方向变更记录：
> 1. 先定为真实 A 股历史回放，因数据授权放弃；
> 2. 改为 A 股规则加模拟行情；
> 3. 维护者最终定为**美股真实历史回放**。
>
> 维护者的要求：
> - 故事性最重要，游戏性也很重要。
> - 玩家要能决定每只股票投多少钱、用不用杠杆、怎么管理仓位。
> - 体现真实市场，目标用户是炒股的人。
> - 任何机制和奖励都要有真实的科学依据。
> - 游戏性丰富但不要太复杂。
> - 行情、事件和每天群友说的话，都要和历史上真实发生过的事对得上；写法搞笑、幽默，组成一个真实、完整、充分的故事。
>
> 已拍板：
> - 美股真实历史；
> - 公司用"化名，但一眼能认出"；
> - 术语用真实说法，加大白话注释；
> - 人设各有一年的剧情，多个结局。

## 0. 对照维护者的约束

| 约束 | 本稿怎么满足 |
|---|---|
| 故事性第一，真实且完整 | 一局就是真实的某一年。新闻、事件、群友话题都锚定当年当天真实发生的事（第 5 节）。群友是虚构的，但他们的反应和当年市场的真实情绪一致。 |
| 有仓位和杠杆可选 | 第 3 节：按金额或股数买卖，自己定仓位；融资按真实规则，可能被追加保证金或强平；有止损单和止盈单。 |
| 真实市场 | 第 2 节：价格是真实日线回放（公有领域数据），交易规则和费用按当年的真实情况。 |
| 一切有依据 | 每条机制、奖励、事件都附来源（法规、论文或史实出处），汇总在图鉴的"依据"页（第 7 节）。 |
| 丰富但不复杂 | 交易动作只有四种：买、卖、开或关融资、挂止损和止盈。丰富度放在剧情、事件和群聊上。 |
| 化名一眼能认出 | 第 2.3 节的命名规则。 |

## 1. 一局的样子

- 开局选人设，再随机抽一个真实年份（1996–2018）。年份可以在开局时公开，例如"这一年是 1999 年"，也可以隐藏。让真实历史的戏剧性成为卖点。
- 一年约 252 个交易日。每天开盘前可以：
  - 看行情和群聊，以及昨夜的新闻；
  - 买卖、调仓位、开或关融资、挂条件单；
  - 推进一天，或者快进到下一个"有事的日子"。

  一局控制在 20–30 分钟。
- 主角是熬夜炒美股的中国散户。美股的交易时间是北京时间深夜，"熬夜"本身就是剧情和梗的来源。
- 每个自然月月底还剧情账单，还不上就爆仓出局。账单金额按所抽年份的大盘表现校准，熊市年也有活路。
- 年底按目标完成情况和这一年的操作风格判定结局，并给出复盘。

## 2. 行情：美股真实历史日线

### 2.1 数据来源

- **WIKI Prices**（Quandl 社区整理，现由 Nasdaq Data Link 托管）。官方页面写明："curated by the Quandl community and released into the public domain"。
- 覆盖 3000 多只美股的日线，包括开高低收、成交量、分红、拆股，历史从 1996 年起，2018 年 4 月停止更新。
- 官方提醒这是社区维护的数据，可能有错误，所以数据管线要做清洗和异常检测。
- 访问需要自己的免费 API key，以环境变量 `NASDAQ_DATA_LINK_API_KEY` 提供，存放方式和其他凭证一样。
- **大盘**：用成分股自己合成一个"大盘指数"，按市值或等权加权。不使用标普、道琼斯等受版权保护的指数数据。
- **幸存者偏差**：先查清 WIKI 是否包含已退市的公司（安然、雷曼这类）。没有的话，相关事件只能作为新闻和背景出现，不能交易；在依据页如实说明。

### 2.2 股票池与年份

- **股票池**：每年 150–250 只，按真实行业分组，例如互联网、电信、半导体、能源、银行、地产、零售、医药、汽车。每个行业里挑当年有故事的公司：龙头、明星股、泡沫股、暴雷股。
- **数据打包**：每个年份一个压缩数据文件，开局时只下载被抽中的那一年。产物里是真实价格，按公有领域再分发；附数据来源说明。

### 2.3 化名规则（一眼能认出，但不是真名）

- 用谐音、意译或调侃的方式起名，配原创的 Q 版小人。不用真实的商标、标志或配色。股票代码也改写成相近的形式。
- 要能认出来，但不能混淆成官方产品。具体名字由剧情组提出，我来审核。
- 新闻和事件里也用化名。公众人物（央行官员、企业高管等）同样用化名或职务来指代。官方公开讲话可以按原意转述，同时注明出处。

### 2.4 依据页公开的事实

- 数据来源及其公有领域声明。
- 这一年的真实大盘涨跌和最大回撤。
- 游戏对数据做了哪些处理：复权方式、剔除了哪些异常、化名。

## 3. 交易系统（按美股当年的真实规则；具体数值实现前逐条核对来源）

| 机制 | 规则 | 依据（待逐条核对） |
|---|---|---|
| 交易单位 | 按股买卖，买入时选仓位：1/4、1/2、满仓或者指定金额 | 美股交易惯例 |
| 当天买卖 | 允许当天买入、当天卖出 | 美股规则 |
| 成交价 | 以开盘价成交，或者挂限价单；条件单按当天最高价和最低价判断是否触发 | 真实撮合的简化，规则写进依据页 |
| 费用 | 按年代收每笔固定佣金，例如 90 年代较高，2010 年代降到几美元。具体数值按史料定 | 史料中的券商收费 |
| 融资 | 初始保证金 50%，维持保证金 25%（券商通常更高）；跌破维持线先追加保证金，追不上就强平 | Reg T；FINRA Rule 4210 |
| 停市和熔断 | 真实发生过的全市场停市和熔断照常发生 | 史实 |
| 分红和拆股 | 按数据处理 | 数据 |
| 做空 | 原型阶段不做，保持简单 | — |

## 4. 奖励与成长：只给现实中真实存在的优势

做法同前一版：不用"凭空加成"。奖励都是现实中真实存在的东西，例如：
- 更便宜的券商；
- 条件单功能；
- 仓位计算器（Kelly 1956）；
- 资产配置课（Markowitz 1952）；
- 融资资格；
- 付费财经资讯。

每一项都附依据，对应的偏差研究见第 5.1 节。

## 5. 故事：真实的一年 + 虚构的群友 + 多结局

### 5.1 群友：每人代表一种被研究证实的投资者偏差

沿用剧情设定稿 docs/story-0.4.md 里与市场无关的部分：偏差、成长线、介入节点、结局判定指标、复盘模板。几位群友：
- 小李：过度自信、频繁交易；
- 老王：处置效应；
- 张姐：从众；
- 群主"韭菜收割机"：荐股骗局；
- 老赵：长期投资者。

他们在真实的年份里会自然撞上历史的教训。例如 1999 年小李满仓网络股，2000 年泡沫破裂。

### 5.2 真实事件时间线（新增，剧情的骨架）

每个年份整理一份"真实事件时间线"，作为新闻、事件和群聊的唯一事实来源。每条包括：
- 日期；
- 事件：用化名事实描述，不抄新闻原文；
- 影响的行业或股票；
- 当时的市场情绪；
- 来源链接。

群聊消息和事件按时间线生成：
- **新闻**：在真实日期播报。
- **群友反应**：按各自的偏差来，例如小李追涨、老王死扛、群主借机卖课。
- **剧情事件**：按真实背景设计，例如 1999 年同事都在辞职炒网络股，2008 年房贷断供。

### 5.3 笑点的边界

- 笑点在人物和炒股心态上：贪婪、侥幸、马后炮、群里互相吹牛。
- 涉及人员伤亡的真实事件（恐怖袭击、天灾等）不拿来搞笑。只严肃、如实地呈现它对市场的影响，例如停市 4 天；群友这时候也不说俏皮话。
- 不嘲弄真实的个人。写到公司时只写有据可查的事实。

### 5.4 人设、结局、复盘

结构与上一版相同。人设剧情改成和美股、熬夜、真实年份相契合：
- 阿韭：在互联网公司上班，熬夜炒美股；
- 老周：退休后被侄子拉进美股群；
- 芳姐：给孩子攒留学钱。

复盘用当年的真实数据算出反事实，例如"如果你那天按止损线卖出，就能躲过之后 40% 的下跌"。

## 6. 术语

用真实的美股和券商说法，例如盘前、盘后、融资、追加保证金、强平、止损、拆股、分红、熔断，第一次出现时附一句大白话。0.3.1 的赚亏归因、收盘小结、说明书保留。归因改为拆成：大盘、行业、个股、杠杆、费用。

## 7. 依据页

依据页分四类：
- 数据来源和公有领域声明；
- 交易规则（Reg T、FINRA 4210 等）；
- 研究文献（偏差、仓位、组合）；
- 每个真实事件的史实来源。

所有引用在写入游戏前逐条核对原文。

## 8. 架构改动

- **core**：
  - 新增 `MarketSource` 接口，按交易日给出开高低收、成交量、分红、拆股和合成大盘；
  - 新增交易撮合和账户（现金、持仓、融资）；
  - 新增事件时间线引擎；
  - 保持确定性：同一个"年份数据 + 种子 + 操作序列"一定得到同一个结果。
- **数据管线**（`tools/data/`，只在本机运行）：
  - 下载 WIKI 数据 → 清洗和异常检测 → 选股票池 → 化名映射 → 每年打包成一个文件；
  - 原始数据不进 git；打包产物进入游戏的静态资源。
- **view**：
  - K 线小图、仓位面板、融资面板、条件单、快进；
  - 新闻和事件、剧情对话；
  - 结局和复盘页。
- **机器人**：
  - 买入持有、动量规则、频繁交易、激进杠杆、知道未来行情的上限；
  - 验收要求：有章法的策略在多数年份明显跑赢频繁交易；杠杆会放大方差和爆仓率；熊市年有生存路径。

## 11. 实现决定（规则层，2026-10-11）

- 方向调整后（美股真实历史回放 + 美股规则），三层因子模拟行情、涨跌停、连板、炸板和 A 股专属的典型事实参数**没有开工**，按要求停下；行情层只定义接口 `MarketSource`，现在用确定性的假数据源跑通链路。
- 0.3 的规则层原样移到 `src/core/legacy/`（测试移到 `tests/legacy/`），0.4 引擎接管 `src/core/index.ts`。
- 交易规则全部参数化（`src/core/rules.ts`）：美股（目标）和 A 股（备选）两套，每个数字带年代、打算核对的来源和状态，目前没有"已核对"的项。
- 所有挂单都在下一次开盘按开盘价成交；条件单按当天最高、最低价判断，触发价成交（跳空按开盘价）。现金为负即融资负债；保证金一律用"权益 / 市值"表示。
- 月底账单只能用现金或融资余地付（付完要满足初始保证金），不够就按收盘价卖股票凑。
- 归因按隔夜和盘中两段算大盘、行业、个股，账户层再把持仓盈亏分成自有资金和融资（杠杆）两部分，加上费用、利息、账单，各项之和等于权益变化。
- 接口详见 docs/core-api-0.4.md。
