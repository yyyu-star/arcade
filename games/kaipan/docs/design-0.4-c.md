# 《开盘》0.4 里程碑 C：仓位、做空、抵押——都做成游戏

> 2026-10-12 维护者："总之这是游戏为主，娱乐为主，学习历史、学习行情优先级很低，让人感觉快乐。
> 但是你也不要丢掉我之前给 0.4 的任务，例如持仓、做空、学习、娱乐、抵押，等等。"
> 0.4 早期的原始要求："我能选择什么杠杆啊，包括我每只股票投多少钱啊，仓位管理啊……不是选一个就放那。"

## 0. 原则（排序）

1. 快乐、好玩、一看就懂；
2. 玩法有选择、有取舍（仓位、方向、借不借钱）；
3. 顺手学到一点：只用一句大白话和图鉴里的"小知识"，不讲规则条文。

每个新机制都要能用一句话说清楚，否则砍掉。术语一律大白话，真实说法最多出现在图鉴小知识里。

## 1. 仓位：每只买多少自己定

- 买入时选"试一口 / 半仓 / 重仓"，分别是可用现金的约 1/4、1/2、全部（数值实现时按 0.3 的平衡定）；已有持仓可以"加仓""减一半""清仓"。
- 0.3 的"格子"保留，但每格的金额不再固定，画面上用卡片厚度或筹码堆高度表现仓位大小。
- 收盘小结照旧讲"赚亏主要来自哪只"，重仓的那只自然会被点名。

## 2. 做空：押它跌

- 一句话：**"押跌"——它跌你赚，它涨你亏。** 卡片翻成反面颜色，小人戴墨镜或者倒着站。
- 一开始不开放，通过月底三选一的"做空许可"卡或者人设、难度解锁，做成 0.3 肉鸽体系里的一项奖励。
- 规则简单：押跌的仓位也占格子；当天涨停时亏得最狠（游戏化的"轧空"）；群友里有人专门唱空，可能对也可能是坑。
- 风口退潮、崩盘事件时，押跌是翻身的机会。

## 3. 抵押：借钱加杠杆（月供主题自然延伸）

- 一句话：**"把房子押给银行，多借一笔钱炒股；赚了翻倍，亏了房子没了。"**
- 抵押物做成道具或事件：房子、车、老婆的金镯子、爸妈的养老钱（幽默但不低俗），每样借出的钱、每月利息不同。
- 借来的钱加进本金（相当于杠杆），每个月底除了月供还要付利息；账户跌破"警戒线"时银行打电话（游戏化的追保），再跌就"收房"（强平），东西被收走，图鉴里记一笔。
- 赎回：手头宽裕时可以还钱赎回，拿回抵押物还有小奖励（成就）。
- 难度越高，可抵押的东西越多、利息越高，诱惑和风险一起上来。

## 4. 学习：只做彩蛋

- 图鉴新增"小知识"：每解锁一个机制（第一次重仓、第一次押跌、第一次被收房……）就点亮一张卡，一句大白话 + 一句真实世界里叫什么（例如"押跌，真实世界叫做空"）+ 可选的一句依据。
- 局末的小故事已经承担"那段时间发生了什么"，不再另做历史课。

## 5. 娱乐增量

- 新事件、新道具、新成就围绕上面三项来做，例如"嘴硬王：押跌一只连续涨停的股票还不认输""赎身：把抵押的房子赎回来"。
- 群友对重仓、押跌、抵押要有反应台词。

## 6. 验收

- 机器人：新增"重仓派""押跌派""抵押赌徒"，难度梯度仍然成立；抵押能放大胜负（高方差），但不是最优解。
- 新手试玩脚本：第一次遇到每个新机制都有一句提示，三步之内能操作。
- 文案扫描：画面上不出现"保证金、维持线、Reg T"这类词。

## 7. 实现决定（2026-10-12，里程碑 C）

- 开关：新机制只在 `createRun(seed, setup, { ext: true })` 的局里出现（正式游戏都开）；不开时（0.3 存档、replay-030）规则、奖励池、事件池都和 0.3.1 一样。
- 仓位："份"＝账户的 1/4，总份数＝格子数；试一口 1 份、半仓 2 份、重仓＝剩下的全部；加仓 +1 份（算一次买入），减一半按半份取整。
  账户涨跌按份数加权（0.3 的一格就是 1 份）。机器人显示"一次全压上"明显好过 0.3 的慢慢买，所以加了冲击成本：一次买超过 1 份，
  多出来的每份让这一笔多花 1.2%（重仓 4 份约多花账户的 3.6%）。
- 押跌：只能押推荐里的股票（空军老周的推荐默认建议押跌）；押跌不吃"买涨"的道具，只走自动卖出；每天手续费 0.3%，涨停被轧再多亏一半（墨镜减半）；大环境最近在涨押跌逆风、在跌押跌顺风（真实行情看前 20 个交易日大盘，合成行情看天气，每天最多 ±3%），
  否则押跌只吃风口轮动、和牛熊无关（机器人：牛市段押跌赚得和崩盘段一样多）。
  难度不送押跌：第 6 级起送会让 smart / oracle 在第 6 级比第 5 级还好打（梯度倒挂），改为押跌许可证、空头大V体验卡（两个月）、炒股大佬人设。
- 抵押：银行第 2 个月开门；借完账户至少是欠款的 1.6 倍才肯借；1.45 倍打电话，1.25 倍先收走借得最多的那件（扣回借款 + 两成违约金），
  直到回到线上；月底先付利息再还月供；一年结束银行收回没还的借款。利息定得高（每月 6%–10%，难度每级 +10%），
  机器人显示低了时"借钱交月供"几乎稳赚，抵押就成了最优解。
- 小知识 11 张（仓位、重仓、加仓、减一半、押跌、被轧、借钱、利息、银行打电话、收走、赎回），局中第一次触发就点亮并写进档案。
- 文案：画面不出现"保证金、维持、Reg T、融资融券"；"仓位、满仓、杠杆、做空"这类真实说法只出现在小知识的"真实世界里叫……"一行。
