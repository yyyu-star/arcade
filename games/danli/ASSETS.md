# 素材说明

本模块没有外部素材、第三方图片、字体和音频文件，全部由本模块的代码运行时画出来、合成出来；美术代理交付的画法和数据改写成 TS 放在模块里，不引用模块外的文件：

| 素材 | 来源 |
|---|---|
| 6 张地图的形状、出生点、材质、远景主题、卡片文案 | 美术代理 2026-10-21 交付的程序数据，改写成 TS：`src/core/mapData.ts`（形状、坑、井、出生点、材质码）、`src/view/mapArt.ts`（材质颜色和纹理、主题、卡片） |
| 0.4.0 新加的 5 张地图（生日蛋糕城、火锅沸腾谷、披萨火山、寿司长台、下午茶花园）的形状、出生点、25 种新材质的颜色和 13 种纹理、5 个远景主题、卡片文案、焦痕底色 | 美术代理 2026-10-23 交付的程序生成的数据和画法，照原样改写成 TS：`src/core/mapData2.ts`（形状、坑、出生点、材质码 26–50）、`src/view/mapArt2.ts`（材质、纹理、远景、卡片、焦痕底色）；和老图共用的小画法抽到 `src/view/paintKit.ts` |
| 地形（25 种材质的渐变、纹理、地表皮、炸焦的坑边、材质间细线、深褐墨线）和碎屑颜色 | 美术代理交付的画法，改写成 TS：`src/view/terrainPaint.ts`；`src/view/terrainArt.ts` 按 marching squares 描轮廓、Canvas 2D 分块烘焙 |
| 8 把武器的坑形（包子圆、西瓜宽椭圆、球拍网格方块、萝卜窄深竖坑、烟花六角星、拖鞋鞋底印、飞盘扁槽、奶茶圆坑带流痕） | 美术代理 2026-10-22 交付的程序生成的坑形函数（整数运算），照原样改写成 TS：`src/core/craters.ts`（规则的一部分） |
| 8 把武器坑边的焦痕（包子焦糖色烫痕和蒸汽、西瓜红汁和籽、球拍网格压痕、萝卜刨花、烟花黑灰和火星、拖鞋鞋纹、飞盘彩色擦痕、奶茶茶渍和珍珠） | 美术代理 2026-10-22 交付的程序生成的画法，照原样改写成 TS：`src/view/scorchPaint.ts`（Canvas 2D，按位置散列，不用 Math.random、滤镜、渐变）；`src/view/terrainArt.ts` 按地形块分层烘焙 |
| 远景（厨房、冰淇淋店、雪夜、野餐布、夜市、早餐桌，往下淡成的雾）、纸边和书桌 | 美术代理交付的画法，改写成 TS：`src/view/backdrops.ts`；`src/view/backdrop.ts` 开局烘焙一张，纸边的毛边用写死种子的随机数 |
| 角色（柴柴、橘子、团团、企企、兔兔、鼠鼠）的全身和圆形头像 | 美术代理交付的画法，改写成 TS：`src/view/charArt.ts`（Canvas 2D，不用滤镜、阴影、渐变） |
| 队标、名牌、图钉、画面外小牌、"出局"章 | `src/view/chars.ts`：Canvas 2D 程序画的 |
| 8 把武器的图标和炮弹、界面小图标（房子、喇叭、规则书、骰子、铅笔、勾） | 美术代理交付的画法，改写成 TS：`src/view/weaponArt.ts`（Canvas 2D） |
| 标题字"弹里个弹" | 美术代理交付的 SVG，改写成 TS：`src/view/title.ts`（SVG 文字和路径，没有滤镜，用系统字体） |
| 首页、准备房间、结算页的版式和配色 | 照美术代理的设计稿（v2 pages）写的 `src/view/pages.css`；首页的面团舞台、结算的蒸笼领奖台和彩纸是 `src/view/lobby.ts`、`src/view/result.ts` 里程序画的 |
| 地图缩略图 | `src/view/thumb.ts`：照美术的画法，远景缩小画，地形一格一个像素 |
| 纸飞机、面粉团、角度盘（三岔时两边的虚线） | `src/view/scene.ts` |
| 音效（蓄力、嗖、噗、命中、掉出画本、爬、道具、轮到你、胜负、按钮） | `src/view/sound.ts`：WebAudio 现场合成（振荡器和滤过的白噪声），不用音频文件 |
| 道具图标（连发 +1、连发 +2、三岔、加力 10% / 20% / 50%、纸飞机、锅盖，各有正常、压暗、去色三套颜色）和按钮上的勾、小锁、爪印 | 程序画的 SVG：`src/view/itemIcons.ts`，照美术 2026-10-21 定稿的源码改写，手写路径，不用滤镜、渐变和 id；按钮的边框和四种状态是 `src/view/style.css` |
| 对局顶栏的图标（小房子、全图、喇叭、风向袋、叶子、爪印、爬的箭头） | `src/view/hud.ts` 里手写的 SVG |
| 网页图标 | `index.html` 里手写的 SVG（一只包子） |

美术代理交付的都是程序画法和数据（Canvas 2D、SVG、整数坐标），没有图片文件；改写进模块时只加了类型，画法照原样。

文字用系统字体。名字、角色、武器、地图、规则文字都是原创的。
