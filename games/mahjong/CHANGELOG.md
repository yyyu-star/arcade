# 雀馆（games/mahjong）更新日志

## 0.7.0（2026-10-16）

界面改版①：主题、按钮、对齐（DESIGN.md 第 7 节）。不加素材，规则和电脑不动。
- 一套主题刻度：颜色、间距（4 的倍数）、字号、圆角、阴影、动效时长都写成 CSS 变量，组件不再到处写死数字。
- 一套按钮：悬停、按下、禁用、键盘焦点、加载中（单机开打、开房间、叫朋友发请求时转圈，转着再点不会发第二次）；主按钮金色、次按钮浅色玻璃、轻按钮分明。
- 手机上点按区域都到 44 像素（按钮外观不变，四周撑开一圈看不见的点按区）：改前手机选桌页有 19 个按钮不够，现在 0 个。
- 对齐：筹码、剩几张、倒计时、房间号用等宽数字；长昵称截断；房间号字距居中；弹窗里单独的按钮居中；输入框有焦点金边。

## 0.6.3（2026-10-16）

强电脑更强：豪华场、大档原来普通玩家几乎打平，现在亏得明显；新手场不变（DESIGN.md 4.1、第 5 节"功力"）。
- 电脑多一个"功力"：火锅婆婆最高（盖碗儿一点），大档、豪华档每个电脑这一场再加"手紧"（少打错、读牌准、功力高）。
- 功力高的：听牌挑值钱的那张（按番加权）、定缺按牌型、防守按模拟量出来的"像不像听牌"估，只对读得出大牌的人收紧。
- 单机豪华普通玩家每场 −0.018 → −0.109 份、大档 −0.007 → −0.075；娱乐、小档、中档在误差上下；好友房实盘两个普通真人每人每场 −0.08 到 −0.10（原来 −0.01 到 −0.03）。
- 只用看得见的信息，平行世界测试照样 0 不一致；决策耗时 p99 不变（约 1.2 毫秒）。

## 0.4.0（2026-10-16）

电脑再训练：按场地分强弱，性格更鲜明，每一场都不一样。
- 按场地分强弱：单机娱乐、小档的电脑偏弱偏宽容（偶尔打错、少防守、少碰少杠，真人打出来的小胡偶尔放过），新手也不亏、普通玩家小赚；
  中档大约打平，大档、豪华档越来越难，豪华档每桌都有火锅婆婆。好友房娱乐热闹为主，好友房实盘照旧一律最强。
- 性格拉开：幺妹儿胡得快；熊猫哥做清一色、对对胡，番最大；盖碗儿守门清、少碰少杠；兔头哥最爱杠；火锅婆婆胡得最多、点炮最少；板凳儿常打错。
- 每一场的状态不一样：同一个性格这一场可能更贪、下一场更稳；局面也会变：落后会追、领先会稳、快输光了保命，点了炮输一大把的会上头。
- 单机里电脑出手的快慢跟性格走（幺妹儿快、盖碗儿慢），台词按性格的口吻，同一个人不连着说同一句。
- 电脑照旧只看自己能看到的牌，不看互动；同一局面同一决定。模拟表和性格指标写在 DESIGN.md 4.1、第 5 节。
- 部署那一刻正在打的好友房和没打完的单机存档：电脑按原来的性格打完，只是没有这一场的状态浮动。
