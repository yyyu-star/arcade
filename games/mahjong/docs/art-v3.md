# 雀馆 美术与界面 v3 方案（第一步：只出方案，不改代码）

> 2026-10-17 晚。起因：所有者说各游戏界面粗糙、一进去就是选玩法、背景单调一张图、排版没对齐，"不是一个好玩的游戏"。
> 本文是麻将模块的方案，主线审过后按第 7 节拆 PR 动手。现状以 main 上的 0.16.1 为准（手感 0.16.2 #219 未合，涉及它的地方单独注明）。
> 截图都在本机 `.local/qa/mahjong/art-v3/before/`（不进仓库），文件名 `<尺寸>-<编号>-<界面>.png`：
> `land` = 1280×720，`desk` = 1920×911（1920 宽的浏览器去掉标签栏地址栏），`port` = 390×844 手机竖屏（2 倍）。
> 分享、好友房沿用冒烟留下的图（`smoke-*`、`room-a`）。横屏 1280 的结算没截到（截图脚本在我坐庄的第一手没有"摸到的那张"，卡住了），结算看 1920 和手机两张。

## 1. 现状审计

雀馆现在只有两个"页"：**选桌页**（游戏名、单机开打、开房间、房间号、娱乐三档、实盘四档、规则设置折叠）和**牌桌**；
结算、规则、新手引导、声音、分享都是弹层。没有"游戏主页"，所以审计按界面列，选玩法 / 选档 = 选桌页（川麻是唯一玩法，选桌页没有玩法这一步）。

### 1.5 共性

- **没有统一网格**：间距有 6、10、12、14、18 各种值；`style.css` 里的 `--r-*`、`--fs-*` 是有的，但版面没按网格摆。
- **两套材质打架**：选桌页木头 + 竹帘，牌桌绿呢子，弹窗绿窗棂，三处互不呼应。
- **主视觉缺位**：游戏名"雀馆"的雀（幺鸡那只鸟）是现成的吉祥物，只在一条牌面上出现。

## 2. 对标（只学风格和结构，不拿任何图）

**雀魂**
- 主页是"人物 + 场景"的分层主视觉，人物有待机动作，右边竖排几个大入口（段位场、友人场、活动），入口少而大。学：**主页先给氛围和两三个大入口，档位放到下一层**。
- 牌桌：桌面有中心光斑和桌沿厚度，中控盘显示四家风位、当前出牌方亮起、剩余张数。学：**中控盘做成"罗盘"，用灯光指出该谁打**。
- 牌有侧面厚度（牌身 + 一层彩色底），手牌比牌河大一档，牌河 6 张一行整齐排。学：**牌的厚度和规整的牌河**。
- 碰杠胡有全屏级的字和光效，配专门的音效；结算是逐项"翻出来"的番型列表，分数滚动。学：**关键时刻给足仪式感，结算分步出**。

**欢乐麻将（腾讯）**
- 主页一屏铺满：顶部头像钱包，中间大块"快速开始"，下面按玩法分的场次卡（底分、入场门槛一眼看清）。学：**"快速开始"是最大的按钮；场次卡只写两三个关键数**。
- 桌面是暖色调，四家头像在四角，信息（分、缺门、托管）统一贴在头像旁的同一位置。学：**座位信息统一组件、统一网格**。
- 操作按钮按紧急程度分色：胡（红金、最大）、杠、碰（次之）、过（灰、最小）。学：**碰杠胡过分级**。
- 结算一屏放下，不滚动：四家一行，输赢用大号数字和金币图标，底部"继续"固定。学：**结算不滚动，按钮固定在底**。

不学：两家都有的商城、抽卡、体力、广告位、红点轰炸（项目不碰真钱，也不做留存陷阱）；雀魂的二次元立绘（风格不合，也没有可商用的来源）。

## 3. 美术方向

**一句话定调：成都老茶馆的夜场。** 推开竹帘进门，暖黄的灯，红灯笼，盖碗冒着热气，木格窗外是夜色和远处的灯火；
牌桌是墨绿呢子配深色木框，牌是象牙白、有厚度的老牌。热闹但不吵，像跟熟人打一下午牌。吉祥物是幺鸡那只小麻雀（"雀馆"的雀）。

**色板（7 色，写成 CSS 变量，现有的 `--felt`、`--gold` 等并进来）**

| 名字 | 色值 | 用在哪 |
|---|---|---|
| 茶馆木 | `#3b2318`（暗 `#24150e`） | 主页、选档的底，桌框，弹窗边 |
| 呢子绿 | `#0f5a41`（暗 `#0a3d2c`） | 桌面、牌背 |
| 灯笼红 | `#c8372d` | 胡、点炮、庄、警示；只在小面积用 |
| 暖金 | `#f3c86b` | 主按钮、当前轮到谁、高亮 |
| 象牙 | `#f6efdc` | 牌面、正文字 |
| 竹青 | `#8db37a` | 次要按钮、赢分（替换现在偏荧光的 `#4cc38a`） |
| 夜蓝 | `#1a2232` | 远景窗外、遮罩（替代纯黑遮罩） |

**字体层级（8px 网格，字号取 4 的倍数）**：展示 48（游戏名、结算总分）/ 标题 24 / 小标题 20 / 正文 16 / 次要 14 / 注 12（只给版本号、法律说明）。
正文继续用系统中文字体。游戏名和"胡""自摸""杠"这几个大字用**思源宋体 Heavy**（SIL OFL 1.1，可商用），只子集化需要的十几个字（约 15–25KB，woff2 放模块里），来源写进 ASSETS.md；
CSP 现在 `default-src 'self'`，自带字体不用改 CSP。

**材质**
- 桌面：呢子（现有的程序纹理）+ 中心一圈暖光（radial-gradient）+ 四角压暗；桌框做成有倒角的深色木，内沿一道金线。
- 木头：主页和选档用横向的木板墙 + 木格窗，不再是一整张竖条木纹。
- 纸：规则、引导用宣纸色卡片（象牙底、茶色字），和牌桌的绿区分开，看规则像翻一本小册子。
- 金属：只用在档位图标和"胡"字描边，铜金色，不做大面积金属。

**主视觉怎么画**：全部程序生成（SVG + CSS），和现在的 `art.ts` 一样，不引外部图片。分三层：
1. 远景：夜蓝底，木格窗框里几点远处灯火（小圆点模糊发光，慢慢明暗）；
2. 中景：茶馆墙、挂着的两三只红灯笼（轻轻摆）、竹帘；
3. 近景：一张桌角，盖碗（蒸汽上升）、一手摊开的牌，幺鸡那张牌上的小麻雀偶尔跳一下、飞出画面再飞回来。
省内存设备和"减少动态效果"时只画静态的三层（沿用 `art.ts` 的 `data-lite` 判断），不跑动画。

## 4. 进入流程

**现在**：进来 = 选桌页（档位 + 按钮一起）→ 牌桌。
**改成**：游戏主页 → 选档 → 牌桌。

**游戏主页**（新）
- 上：左上"大厅"（不变），右上钱包、声音、规则。
- 主视觉占上半屏（第 3 节三层），游戏名"雀馆"压在主视觉上，下面一句话：**"血战到底：胡了不下桌，打到只剩一家。"**
- 主按钮一个最大：**快速开始**（按上次选的档位和规则直接开；第一次玩 = 娱乐·新手）。有没打完的单机局时它变成**继续上局**，旁边小字"娱乐·新手 · 第 3/8 局"。
- 三张模式卡一排：**娱乐**（不算筹码，三个难度）、**实盘**（用钱包，四档；钱包连不上时灰掉并写原因）、**好友房**（开房 / 输房间号进房）。点卡进选档。
- 一张小卡：**我的战绩**（今天打了几场、连胜 / 连败、最大番，连胜连败来自已有的本地 `mahjong.streak`，场数和最大番要在它旁边加一个本地计数，键同样 `mahjong.` 前缀）。雀馆目前没有每日挑战榜，先不做挑战卡；以后平台登记 `daily` 再加。
- 好友动态留在平台大厅（雀馆 0.14.0 只往里写"名场面"），主页不重复放。

**选档**（现在的选桌页瘦身）：左上返回主页；只放当前模式的档位卡（娱乐三张 / 实盘四张 / 好友房两个按钮 + 娱乐实盘切换），卡上只写星级、最多输赢；
"规则设置"保留折叠；一个"开打"按钮固定在底部。

**单独部署**（没有平台）：主页没有实盘卡和钱包，好友房卡上多昵称框（沿用 `detectPlatform()`）。

## 5. 牌桌

- **背景分层**：远景（茶馆墙 + 窗，只在牌桌外的空边露出来，1920 上那两条 210px 的边就是用来露它的）/ 桌面（呢子 + 中心暖光 + 四角压暗）/ 灯光（一层很淡的顶灯光斑，随轮到谁往那一家偏一点）。去掉印在呢子上的半透明灯笼盖碗。
- **桌框**：12px 厚的深木框，内沿金线，外沿投影；牌桌整体像放在茶馆里的一张桌子。
- **中控盘**：改成方形"罗盘"：四边写东南西北（按座位转），当前出牌方那一边亮暖金并有一道往外的光；中间剩余张数 + 第几局；换三张、定缺的提示不再压在盘上，改到盘和我手牌之间的提示条。
- **网格**：8px 基准。四个座位牌子同一个组件（头像 48、名字 16、分 14、缺门章 12），离桌框内沿都是 16；牌河离中控盘 16，每行 6 张；手牌离桌底 8。
- **牌的质感**：现有象牙牌面保留，加 3px 的侧面厚度（呢子绿底层，同雀魂思路）和一层柔和投影；手牌 > 副露 > 牌河三档尺寸；对手的牌背做成竖立的牌（能看出张数），不再是小绿条。
- **按钮分级**：胡 = 灯笼红底金字、最大；杠、碰 = 暖金；过 = 半透明灰、最小。定缺三个按钮用茶馆木底，跟碰杠胡区分。
- **关键时刻动效**（都在 300ms 内，不挡操作；省内存模式只保留位移、去掉粒子）：
  - 开局：四家牌墙从中心推出 → 4-4-4-1 发到手里，约 1.2 秒，可点跳过；
  - 换三张：三张牌朝换的方向滑走，换来的三张从对应方向滑进；
  - 定缺：缺门章"盖"在头像上（缩放 + 一下震动）；
  - 碰杠：被碰的牌从牌河飞到副露，大字"碰 / 杠"从出牌的人那边冲出来；
  - 胡 / 自摸：胡的那张牌放大停一下，金光圈 + 粒子，头像上盖"胡"章（现有 `celebrate` 加强）；
  - 结算：分数从 0 滚到最终值，赢的钱币从输家飞向赢家。
- **音效**：现有 WebAudio 合成音（`sound.ts` 的 `Sfx`）一一对上：发牌 `deal`、换三张 `swap`、定缺 `que`、碰 `pon`、杠 `kan`、胡 `hu` / `zimo`、结算 `chips` + `win` / `lose`。新加两个：茶馆底噪（很轻的人声和盖碗声，默认音量 20%，可在声音面板单独关）、发牌洗牌声。

## 6. 电脑版和手机版

## 7. 拆分计划（每个都能单独上线，规则核心 `src/core/`、`src/ai/` 一律不动）

1. **主页 + 主视觉**（所有者最先看到的）：新的游戏主页、三层程序画主视觉（静态 + 轻动效，省内存关动效）、快速开始 / 继续上局、模式卡、战绩卡；选桌页先原样保留做"选档"。约 0.17.0。
2. **牌桌背景和桌框**：远景空边、呢子中心光、桌框厚度、去掉印在桌上的摆件、中控盘改罗盘。约 0.17.1。
3. **结算一屏放下 + 选档瘦身**：先修 1920 上结算要滚动、"下一局"被切的问题；结算分数滚动、钱币飞；选档页只放当前模式的卡、开打按钮固定。约 0.17.2。
4. **牌的质感和按钮分级**：牌侧面厚度、三档尺寸、对手竖立牌背、碰杠胡过分级配色、8px 网格对齐座位牌子。约 0.17.3。
5. **关键时刻动效 + 音效 + 规则小册子**：发牌、换三张、定缺、碰杠胡的过场，茶馆底噪，规则改宣纸卡片分节、番型带牌例，引导加示意图。同时升 kit 到 ^0.16.0，用 `arcade-kit/theme` 的 `applyTheme` 把分享预览、叫朋友、互动面板换成第 3 节的色板和字体（这个 PR 改 package.json 和 lockfile，要维护者本人审）。约 0.17.4。

每个 PR 附改前改后 1280 / 1920 / 手机截图，冒烟零报错，`scripts/capture.ts` 的"压住了"报告为空；省内存模式（`--lowmem`）渲染倍数封顶 2、背景动效关；
