# 卡通风格配色（0.22.0，所有者 10-19 各游戏统一）

规则写在 `src/view/art.css` 末尾"卡通风格"一段：平涂、2–3px 深色描边、圆角 12–16、按钮 4px 实色下沿（按下沉 3px）。

| 变量 | 色值 | 用在哪 |
|---|---|---|
| `--c-ink` | `#2b1d14` | 描边、实影、奶油底上的字 |
| `--c-paper` | `#ffeec4` | 主页、选桌、等人页、牌桌两边的底（加淡圆点） |
| `--c-cream` | `#fff6e0` | 顶栏、卡片、次按钮、"互动"按钮 |
| `--c-teal` | `#17a37f` | 主色：呢子、标题、选中的档位 |
| `--c-panel` | `#14584a` | 名牌、弹窗（深底浅字，结算配色照旧） |
| `--c-sun` | `#ffc53d` | 主按钮（开打、快速开始）、轮到谁的光圈 |
| `--c-orange` | `#c4570b` | 钱包数、星级 |
| 木框 | `#c9763a` | 牌桌一圈 |
