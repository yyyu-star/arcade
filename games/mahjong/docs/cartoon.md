# 卡通风格配色（0.22.0 统一描边、圆角、下沿；0.22.1 补回质感，所有者 10-19）

规则写在 `src/view/art.css` 末尾"卡通风格"一段：2–3px 深棕描边、圆角 12–16、按钮实色下沿（按下沉 3px）；表面上亮下暗的轻渐变 + 顶边高光 + 柔和投影。
茶馆的板壁、木框、呢子（织纹、绒点、暗角、顶灯暖光）用原来的程序生成纹理，不平涂。

| 变量 | 色值 | 用在哪 |
|---|---|---|
| `--c-ink` | `#2b1d14` | 描边、实色下沿 |
| `--c-cream` | `#fff6e0`（渐变到 `#f3e3c0`） | 次按钮、档位卡、模式卡、座位卡、"互动"按钮 |
| `--c-panel` | `#14584a`（`#1f7462` → `#0d3d33`） | 名牌、弹窗：深底浅字，结算配色照旧 |
| `--c-teal` | `#17a37f`，标题 `#2fc89c` | 主色：选中档位的外圈、标题、大厅图标 |
| `--c-sun` | `#ffc53d`（`#ffe07a` → `#f0a52a`） | 只给主按钮、钱包数、轮到谁的光圈、选中的规则选项 |
| `--c-orange` | `#c4570b` | 星级 |
| 底色 | 板壁深木 `#3a1a0c`、呢子 `#0f5a41` | 大面积沉稳的底，原 0.21 的纹理 |
