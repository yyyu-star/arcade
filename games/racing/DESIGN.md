## 1. 术语

| 本游戏 | 意思 |
|---|---|
| 速度牌 | 牌面 1–4，打出去加到这回合的速度 |
| 改装牌 | 开局带的特殊牌：速度 0、速度 5、多一张热量 |
| 热量 | 打不出去、弃不掉的废牌；过弯超速、跳两挡、冲刺都要付 |
| 引擎 | 放热量的地方，公开；付热量 = 从引擎挪一张到弃牌堆 |
| 手抖牌 | 打出去时从牌堆往下翻，翻到速度牌为止，点数看运气 |
| 冲刺 | 付 1 热量，翻一张速度牌加到速度上，每回合一次 |
| 散热 | 把手里的热量放回引擎 |
| 拼劲 | 落在最后的车：多走 1 格（算进速度）和 / 或多散热 1 张 |
| 尾流 | 停在别的车旁边或正后方一格，可以再往前 2 格（不算速度） |
| 打滑 | 过弯超速又付不起热量：退回弯前、掉回 1 挡、拿手抖牌 |
| 熄火 | 手里能打的牌不够这一挡：车不动、掉回 1 挡 |
| 格 / 内线 / 外线 | 赛道一格有两个车位，靠赛车线的叫内线 |
| 弯道线、限速 | 弯道入口的线和它标的速度上限 |
| 一回合 | 大家同时选挡出牌，然后从最前面的车起依次走完 |
| 一场 | 发车到所有车冲线 |

## 2. 规则（`src/core/rules.ts`）

### 2.1 每辆车的牌和开局

- 牌堆：12 张速度牌（1、2、3、4 各 3 张）+ 3 张改装牌（速度 0、速度 5、多一张热量）+ 若干手抖牌，洗匀。
- 引擎：若干热量，公开。手抖牌、热量的张数由赛道定（3.2）。
- 1 挡起步，起手 7 张。发车格随机排（开局的随机数），也就定了第一回合的先后。
- 每辆车的牌是"这辆车里的编号"，编号对应的种类只在状态里；手牌、操作都用编号。
- 随机：`arcade-kit/rng`（ChaCha20），`stream(key, 'grid')` 发车格，`stream(key, 'deck', 座位 × 1000 + 第几次洗)` 每辆车每次洗牌，
  `stream(key, 'persona')` 挑电脑性格，`stream(key, 'form')` 每个座位这一场的状态（5.4）。同一密钥同一串操作结果完全相同（`test/rules.test.ts` 检查）。

### 2.2 一回合

1. **选挡、出牌（大家同时，暗选）**：挡位可以不变或升降 1 挡，免费；升降 2 挡要付 1 热量（引擎空了不能跳挡）。挂几挡就出几张（1–4）。热量不能打；手抖牌能打。
   回合开始时按位置从前往后排好这一回合的顺序（同一格内线在前）。
2. **亮牌、移动**（从最前面的车起，每辆车做完第 2–8 步才轮到下一辆）：这时才付跳挡的热量、亮出挡位和牌（亮牌前别人看到的挡位、引擎都是上一回合的）。
   速度 = 牌面之和；打出的手抖牌从牌堆往下翻，不是 1–4 的速度牌进弃牌堆，翻到为止算它的点数。
   正好走这么多格。路过别的车不受阻；停的那一格内线空着就停内线，否则外线；两个车位都满了，就往后找第一个有空位的格。
3. **散热**：1 挡 3 张、2 挡 1 张，有拼劲再加 1 张；手里的热量放回引擎（永远划算，自动做满）。
4. **冲刺**（可选）：任何挡位都能，付 1 热量，翻一张速度牌加到速度上，每回合一次；照样找车位。
5. **拼劲**（可选）：这回合最后走的车（开局 5 辆车以上时是最后两辆）可以多走 1 格（速度也 +1）。按开局的车数算，冲线离场的不减。
6. **尾流**（可选）：停在别的车旁边（同一格）或正后方一格，可以再往前 2 格，每回合一次，照样找车位。不算速度。不能靠尾流冲线，冲线以后也不能用。
7. **过弯**：这回合跨过的每一条弯道线（从回合开始的位置到现在的位置，含尾流带过去的），按先后比一比速度（含冲刺、拼劲，不含尾流）和限速：
   不超没事；超了几格就付几张热量；付不起就把引擎里剩下的全付掉，然后**打滑**——车退回这条弯道线前第一个有空位的格；1、2 挡拿 1 张手抖牌、3、4 挡拿 2 张进手里；挂回 1 挡；后面的弯不再查。
8. **弃牌**（可选）：手里的牌任选几张进弃牌堆，热量和手抖牌不能弃。弃牌堆只有最上面一张公开。
9. **补牌**：打在桌上的进弃牌堆，补到 7 张。牌堆空了把弃牌堆洗成新牌堆；回合中途（手抖、冲刺翻牌时）洗的，这一回合打在桌上的不洗进去。

冲刺放在拼劲前面问：先看冲刺翻出几点，再决定要不要多走那 1 格（这样给的信息最多）。

### 2.3 熄火

手里能打的牌（速度牌、改装牌、手抖牌）少于这一挡要出的张数：能打的全打，不够的用热量顶上（顶上的热量也进弃牌堆）；这回合车不动，挂回 1 挡，直接补牌。

### 2.4 改装牌

速度 0、速度 5 当普通速度牌打；被手抖、冲刺翻到时**不算**，进弃牌堆接着翻。多一张热量开局洗在牌堆里，抽到手里就是一张热量。
牌堆和弃牌堆里一张 1–4 都没有时，手抖、冲刺翻出来算 0 点（不会死循环）。

### 2.5 冲线和名次

- 跑完圈数先冲线的赢。同一回合几辆车冲线：越过线越远的在前；同一格内线在前。每回合结束把冲线的车按名次移出赛道。冲线以后的弯不管。
- **真人都冲线了（或都离座交给电脑了），剩下的电脑按位置直接排名次**，不再陪跑；全电脑的一场（模拟器）跑到全部冲线。

### 2.6 公开和隐藏（`src/core/view.ts`）

| 公开（所有人看得见） | 只有自己看得见 | 谁也看不见（只在服务端） |
|---|---|---|
| 每辆车的位置、挡位和引擎（亮牌以后的）、手里几张、牌堆几张、弃牌堆最上面一张、这回合打出和翻出来的、交没交计划、这回合谁有拼劲、每辆车的统计 | 自己的手牌；自己这回合交的计划；自己牌堆加弃牌堆里每种牌各剩几张（不给顺序）；自己的整个弃牌堆（驾驶台点弃牌区翻看：自己打过、弃过的牌本来就记得住） | 牌堆的顺序；随机数密钥；牌编号对应的种类 |

交了计划的车会从"还在选"的名单里拿掉，别人看得出"谁选好了"、看不出选了什么，和实体桌一样，接受。

### 2.7 预设（省等待）

亮牌以后是一辆一辆来的，每辆车都停下来问会很拖。所以交计划时顺手带上预设，轮到自己时服务端直接照办：

| 问题 | 预设 | 默认 |
|---|---|---|
| 冲刺 | 问我 / 不冲 | 问我 |
| 拼劲多走 1 格 | 问我 / 要 / 不要（这回合有拼劲才显示） | 问我 |
| 尾流 | 问我 / 能吸就吸 / 不吸 | 问我 |
| 弃牌 | 出牌时标好要弃的牌 / 轮到时问 | 出牌时标 |

只有一个选择的步骤一律跳过（没热量不问冲刺、没车可吸不问尾流、手里没能弃的不问弃牌）。预设存在 `racing.prefs`，下回合沿用。

### 2.8 一场的选项（开房就定，进房的人都看得到；单机在选桌页选）

| 选项 | 取值 | 默认 |
|---|---|---|
| 赛道 | 固定赛道 id（以后加随机赛道的种子码） | 环湖 |
| 圈数 | 1–3 | 赛道标的数（都是 2） |
| 几辆车 | 2–6（人不够电脑补位） | 6 |
| 电脑强弱 | 新手 / 普通 / 老手 / 混着来（只影响挑哪些性格，5.3） | 混着来 |

让子（给某个座位少放热量）、"第一名冲线后再跑 N 回合"这类收场方式没做，放到第 10 节以后再说。

## 3. 赛道

### 3.1 规则层只认一条"一维"的赛道（`src/track/types.ts`）

```ts
interface Track {
  id: string; name: string; blurb: string;
  spaces: number;                              // 一圈多少格
  laps: number;                                // 默认圈数
  corners: { at: number; limit: number }[];    // 弯道线在第 at - 1 格和第 at 格之间、限速
  heat: number;                                // 每辆车引擎里的热量
  stress: number;                              // 每辆车牌堆里的手抖牌
}
```

位置是"从起终点线往前数第几格"的绝对格数：线后第一格是 0，发车格在线前（-1、-2、-3），跑完就是 `pos ≥ laps × spaces`。

画法单独在 `src/track/shape.ts`：一圈控制点，按向心 Catmull-Rom 连成平滑闭合曲线，按弧长均匀分成 `spaces` 格，每格内线在行进方向左边。
只有画面层和 `scripts/track.ts` 用，规则核心不 import（`test/arch.test.ts` 检查）。

### 3.2 固定赛道（全部自己设计，地名是虚构的；`src/track/fixed.ts`）

| id | 名字 | 一圈 | 弯道线（格：限速） | 热量 / 手抖 | 设计意图 |
|---|---|---|---|---|---|
| `lakeside` | 环湖 | 60 格 | 9:5、19:6、30:3、36:4、49:6 | 6 / 3 | 绕湖一圈，湖边一个急折弯（3）接一个中速弯，其余是快弯，热量不紧 |
| `hillcity` | 山城 | 56 格 | 5:3、11:2、19:4、33:4、38:3、43:3 | 6 / 4 | 连续的发夹弯和 S 弯，考验降挡和散热，手抖牌多一张 |
| `harbor` | 海港 | 64 格 | 8:3、19:2、28:3、46:6、54:5 | 5 / 3 | 码头边一段三连急弯（最急 2），另一边是长直道接两个快弯，冲刺和尾流的大场面；热量少一张 |

- 弯道线和形状是一起定的：`node scripts/track.ts --png` 按控制点算每一格转了多少度、找出弯，弯道线放在每个弯的入口；
  限速按弯的大小和急缓定（180° 的发夹弯 2–3，90° 的快弯 5–6）。`test/track.test.ts` 查每条弯道线后面 5 格真的转了 45° 以上、发车格在直道上。
- 新增固定赛道：在 `fixed.ts` 加数据、`shape.ts` 加控制点，不改别的代码。

### 3.3 随机赛道（第二阶段，未做）

要求：同一个种子码在任何设备、任何浏览器上生成**一模一样**的赛道（单机、好友房、以后的每日挑战都靠它），而且生成出来的赛道一定能跑、好跑。

做法：**规则用的赛道全用整数算，平滑的曲线只在画面层画**。

1. **长一块不带洞的格子形状**：在一张粗格子图（比如 9×6）上，从中间一块起，用 `stream(key, 'track', 0)` 的随机数一块一块往外长，每次只加"加了以后还是连成一片、不出现洞"的格子。
   这块形状的外轮廓天然是一条**不自交的闭合线**，用不着做相交检测。
2. **轮廓 → 直道和弯**：轮廓上每个拐点是 90° 弯；离得近的拐点合成一个弯（同向两个 = 发夹弯 180°，反向两个 = S 弯）。每条轮廓边按整数折成若干格。
3. **限速按弯的形状查表**（整数，不用三角函数）：单个 90° 弯 5–6、S 弯 4、发夹弯 2–3，再按弯前直道的长短 ±1。
4. **起终点线**放在最长的直道上，后面留够发车格和到第一个弯的距离。
5. **验收**，不合格就换下一个子流（`stream(key, 'track', n)`）重来：一圈格数、弯的数量、最长直道、相邻两弯的最短间距、整圈"难度分"都在固定赛道的范围里。
6. 画面层把轮廓用圆角和样条画成平滑的赛道，再按格数沿曲线均匀分格（这里用浮点没关系，不影响规则）。

- 种子码 6 位，大写字母和数字去掉容易认错的（0/O、1/I），比如 `R7KM2Q`；赛道 id 是 `gen:<种子码>`，`track/index.ts` 的 `getTrack` 按种子现生成，规则核心不用改。
- 生成器 `src/track/gen.ts` 是纯函数，和规则核心守同样的规矩。
- 测试：1 万个种子全部生成成功、全部通过验收、同种子两次逐字节相同；挑 200 个种子让电脑对跑，一场的回合数、打滑率落在固定赛道的范围里。

- 动作：`{ t: 'plan', gear, cards, boost, adren, slip, discard }`（`discard` 是 `'ask'` 或要弃的牌编号）、`{ t: 'boost' | 'adren' | 'slip', yes }`、`{ t: 'discard', cards }`。
- `apply` 先复制一份状态再改，不改传进来的；错误码只用固定的短码（`bad_gear`、`no_heat`、`bad_cards`、`bad_discard`、`planned`、`not_plan`、`not_your_turn`、`not_asked`、`not_racing`、`race_over`），不带牌面。
- 状态里的 `stage` 记着当前这辆车走到第 2.2 节的第几步；`advance` 一直往下走，直到要问人、回到交计划、或者整场跑完。

## 5. 电脑（`src/ai/`）

### 5.1 只看自己能看到的

电脑拿的是自己座位的视图，和真人一样：看不到别人的手牌和任何人的牌堆顺序；自己牌堆加弃牌堆的成分视图里有（记性好的真人也知道）。

### 5.2 怎么决定

- **选挡出牌**：列出能挂的挡 × 手里能打的组合（按牌面去重，最多几十种），每种按速度的分布（手抖按自己牌堆里 1–4 的成分）算期望得分：
  走了几格 − 过弯要付的热量 × 一张热量值几格 − 打滑的代价 − 下回合刹不住的风险 + 散热 + 打掉手抖牌清手 + 挡位留着下回合能快。
  - 一张热量值几格：引擎越空越值钱，离终点越近越不值钱（跑完了还剩着就是白留）；
  - 下回合刹不住：停下来以后，下回合最慢能挂的挡、打手里最小的几张，要是还会冲进下个弯，按超出的格数算。
- **冲刺、拼劲、尾流**：比较做和不做两种结果的得分，过了性格的门槛就做。
- **弃牌**：离低速弯近（10 格内、限速 ≤ 4）弃 4 和 5，直道上弃 0 和 1。
- **失误**：性格的 `slop` 越大，越常挑到不是最好的选择。抖动按"这场的抖动种子 + 步数 + 座位 + 选项编号"算，确定、每场不一样，不用 `Math.random`。
- **CPU**：一次决定几百种组合。`test/ai.test.ts` 量了最费的局面（7 张各不相同、带两张手抖、能挂 1–4 挡）：单次 p99 < 5 毫秒，六台电脑加起来 < 20 毫秒；整场所有决定的 p99 < 2 毫秒。

### 5.3 性格和强弱（`personas.ts`）

按场地分强弱：每档至少两个性格，新手场、普通场、老手场**只从本档挑**（不拿别档凑数），"混着来"三档都有。

| 性格 | 档 | 打法 |
|---|---|---|
| 嘟嘟 | 新手 | 常挑错，看不远 |
| 慢半拍 | 新手 | 胆小：热量看得极重，弯前早早刹死，也常挑错 |
| 冲冲 | 普通 | 热量看得轻、爱冲刺，偶尔失误 |
| 跟屁虫 | 普通 | 有尾流就吸，偶尔失误 |
| 刹车王 | 普通 | 热量看得重、怕打滑，弯前早降挡 |
| 弯道王 | 老手 | 参数是网格搜索出来的最好的一组（`scripts/tune.ts`：热量 1.1、能吸就吸），不失误 |

### 5.4 每场的状态

开局用 `stream(key, 'form')` 给每个座位抽一份状态，存在 `State.form`，只下发给自己（视图的 `me.form`，真人的页面用不到）：

- **冲劲**（−100 到 100）：+100 时这场热量的估值低 25%、打滑的代价低 20%、冲刺和尾流的门槛低 0.5；−100 反过来，这场稳着开；
- **手感**（−100 到 100）：−100 时多 0.8 的失误，+100 时少 0.4（不低于 0）；
- **抖动种子**：失误的抖动每场不一样。

所以同一个电脑这场冲、下场稳，同一个局面两场的选法可以不一样（`test/ai.test.ts` 检查）。

## 6. 联机（好友房）

- 用 `packages/arcade-kit`：房间类继承 `GameRoom`（`worker/room.ts`），Worker 路由只接 `acceptCreate` / `acceptJoin`，浏览器用 `RoomClient`。遵守 `platform-backend.md` 第 4 节：
  只用 `ctx.acceptWebSocket`、一个闹钟、每步 ≤ 2 行写入、电脑批量出手、绝不下发别人的手牌和牌堆、密钥只在状态里。
- `src/room/rules.ts` 把规则包成 `RoomGame`：
  - 交计划阶段 `actors` 返回所有没交的车（组 `plan-<回合>`，45 秒）；亮牌以后一次一辆车（组 `act-<回合>-<第几辆>-<第几步>`，15 秒）；
  - 超时：交计划由电脑替他选，冲刺、拼劲、尾流按"不"，弃牌按"不弃"；
  - 开房就定选项（2.8），`seatCount` = 几辆车；开打后掉线由 kit 托管，回来交还；离座交给电脑（`seated`），可以接管没绑人的电脑座位；
  - **再来一场**：跑完不马上关，房间停 3 分钟（kit 的 `pause`）；桌上的真人点"再来一场"，用同样的选项开个新房间，把房间号发回来（`{ t: 'next', code }`，不轮流的操作），
    别人的结算上写"某某开了新房间"，5 秒后跟过去（坐回相对一样的位置）；3 分钟没人点，房间打完。
- 叫朋友来：分享 `/games/racing/?room=123456`；没登录的人经登录闸门登录完原样回来。
- 交流的编号：0–15 短语、16–27 表情、28–35 道具（`src/game/emotes.ts`），怎么用见 6.2。

### 6.1 写入和请求估算

- 每回合：交计划每个真人 1 行；亮牌后每个真人平均约 1–2 次回答（有预设时更少）；电脑一批算一步。6 个真人约 15 行 / 回合。
- 一场按 2 圈约 20 回合算，6 个真人约 **300 行**，加开房 4 行；1 个真人 + 5 电脑约 60 行。
- 入站：一场最坏约 300 条操作 + 短语表情；房间一生入站 3,000（默认），寿命 3 小时（默认）。
- 全账户每天 10 万行，现在分出去的 `stopWrites` 合计 9 万（掼蛋 6 万、德州 2 万、麻将 1 万）。赛车配的是 **`busyWrites` 3,000 / `stopWrites` 4,000**（约 13 场满员），
  从余下的 1 万里出，**要维护者同意**（`wrangler.jsonc`）。
- 快照：6 辆车的公开信息 + 自己的手牌 + 这一步的事件，`test/room.test.ts` 断言 < 8 KB。
- 交流（真人的和电脑的）不写存储、不改 seq，只占 kit 的令牌桶和入站额度。

### 6.2 互动（单机和好友房都有）

- **"聊"面板**（`src/view/comms.ts`）：说一句（16 句，只说比赛不说人；先挑"对谁说"，默认大家，点名的气泡带"@名字"、被点的那一行晃一下）、
  kit 的表情包、冲某辆车扔道具（`arcade-kit/fun`）。"头像"是名次栏里那一行。
  气泡和表情不压车手名（0.1.4）：横屏冒在那一行左边（赛道上；气泡挂在 `.race` 上，原来挂在行里被名次栏的 overflow 裁掉了）；竖屏名次栏是两列、左右没地方，短语冒在名次栏上沿（赛道底边，带那辆车的小棋子，左列的靠左、右列的靠右），
  表情冒在那一行右头（挡位、热量那几格上，压一两秒没关系）、和这一行一样高、不出这一行：kit 的表情至少 44 像素，比手机上的一行高得多，
  所以竖屏自己用 kit 的 `stickerSvg` 画一个（`comms.ts` 的 `rowSticker`）；横屏照旧用 kit 的 `showSticker`，冒在那一行左边的赛道上（按它的偏移反过来算一个框给它）。道具照旧砸在那一行的小棋子上。设置里：
  - 总开关（存 `racing.comms`）：关了别人的话、表情、道具都不显示，自己也发不了，单机也算；
  - 看不看别人的（存 `racing.mute`）；按人屏蔽（真人、电脑都行，这一场有效）。
- **电脑会互动**（`src/game/banter.ts`，单机和好友房同一份）：
  - 只看公开快照（每辆车的位置、名次、公开的统计），对比前后两次认出：打滑、吸了谁的尾流、超了谁、冲线、熄火、一口气付了好多热量；
  - 按性格的脾气（`TEMPER`：话多少，冲 / 怂 / 稳 / 傲）挑一句短语、一个表情或冲人扔东西：比如冲冲打滑喊"刹不住了！"、嘟嘟哭，
    被吸尾流的喊"别吸我尾流！"，被超的弯道王回"哼，下个弯见"，冲线第一的弯道王戴墨镜；
  - 被点名、被扔东西按脾气回：冲的扔回番茄，傲的狗头，稳的冒汗，怂的哭；被夸回比心或干杯；对大家说的话不回；
  - 一件事最多一个电脑接话，一步最多两句；同一个电脑 6 秒内只说一次；"随机"按种子哈希算，可以复现。
- **单机**：页面每一步放完动画后按快照让电脑说；我冲电脑发的，等一会儿它回；我出牌想了 15 秒还没出，话最多的电脑催一句"快点出牌呀"
  （每回合一次，只有画面和声音，单机本来不限时）。
- **好友房**（kit 0.10 的 `onStep` + `botEmote`、0.10.1 的 `onEmote`，`worker/room.ts`）：
  - `onStep` 每一步拿公开视图和上一次的比（电脑连着出手时 kit 一批推好几步，按统计的变化认就不会漏），让电脑座位发；
  - `onEmote` 只让被冲着的电脑回一句；快照和冷却只在房间的内存里，不写存储；
  - 好友房有倒计时，电脑不催人；
  - 页面把电脑的表情排在这一批走车动画放完以后再显示（`online.ts`），免得车还没过弯就先得意上了。
- **公平底线**：电脑开车（`src/ai`）和规则（`src/core`）不 import 交流的代码（`test/arch.test.ts`），读不到任何短语；电脑说什么只看公开的事，不读隐藏的牌，也不把真人的短语记下来。
  互动免费、人人一样、不停计时、不盖按钮。

### 6.3 两种部署（共用包 0.10 的平台模式和独立模式）

- `wrangler.jsonc` 是独立配置（docs/new-game.md 第 4、7 节）：不写平台绑定和 `GATE`，`workers_dev: true`，站点根 `/` 也先过 Worker。

- **单独部署**（Deploy to Cloudflare 按钮、`npm run deploy`）：没有 `ARCADE`，kit 发游客 cookie，任何人打开就能玩，单机和好友房都有；
  Worker 入口先 `standaloneRoot` 把 `/` 转到 `/games/racing/`；游客昵称不许和电脑重名（`guest.reserved`）。
- **页面**：开局 `detectPlatform()`：有平台照常（名字用平台账号的）；没有平台时"大厅"改成回游戏首页，选桌页多一个昵称框（存 `racing.name`），开房、进房用 `withNickname` 带上；
  平台一时连不上（unknown）按有平台处理。
- 共用包从 npm 装（`"arcade-kit": "npm:@yyyu-star/arcade-kit@^0.10.1"`），目录拿走就能部署。

## 8. 画面

- **渲染：DOM + SVG**（同麻将、德州），不用 Phaser。
- **桌游风格**（素材见 `ASSETS.md`）：整局像摆在木桌上的一盒实体桌游。赛道是一块印刷的地图板，车是塑料棋子，卡牌是印刷卡，驾驶台是一张玩家板。
  只有棋子、卡牌这些"实物"带投影，印在板上的东西都是平的。木桌、卡纸、纸纹、斑驳是 `scripts/art.ts` 程序生成的平铺纹理（`public/art/*.webp`），别的都是运行时画的 SVG。
  - **规矩**（`view/mapkit.ts`）：一套限定色板，明暗从深到浅分几档（赛道最深，地面、水是中间调，沙滩、缓冲区、纸最亮）；墨线只有三档粗细（主体、次要、装饰）；
    文字用系统字体，避免不同手机落到不同的字体。
  - **地图板**（`view/mapart.ts`）：深色边框（环湖深绿、山城深棕、海港深蓝），上边框印着赛道名、"一圈几格 · 几个弯 · 热量几"和指北针，里面一圈棋盘格边，地图四周留白。
    往上依次是：地面 → 场景 → 弯外缓冲区（慢弯是淡红斜纹，快弯是砂石点加轮胎墙）→ 维修区（主直道内侧：通道进出口、维修墙、每队一个车位、一排车库）
    → 林子 → 主直道外侧的大看台 → 赛道。赛道是一块干净的深色路面，格线淡，每 5 格一道白线（数格子用）；红白路肩只在弯里，弯道线是红线白边，起终点黑白格，发车框。
  - **场景**（`view/scenes.ts`）：
    - 环湖：内场两片水连成的大湖，自然的岸线（从中心往四周伸，碰到赛道、弯道牌子就收住，再抹平）；湖心岛上一座六角亭，九曲桥通到岸边，水道上一座石桥，荷叶，小船；
    - 山城：几座山（等高线和越高越暖的分层设色），最高的山顶一座三层檐的塔，坡上有梯坎石阶；一格格的街坊；两座山连得上（不压着弯道牌子）就拉一条索道；
    - 海港：上沿是海，岸线跟着赛道走；靠岸的集装箱船和两台岸桥，防波堤尽头的灯塔；油罐区、仓库，集装箱对齐成排，码头铺装的接缝。
    林子是一棵棵树冠并成的一片，外缘是一条起伏的墨线；赛道外一圈最密，越远越稀，再按低频的起伏分出林间空地。摆放的随机数写死种子，同一条赛道每次一样。
    场景摆放要成千上万次地问"这里离赛道多远"，先算一张距离场（每 6 个单位一格）查表，三条赛道各几十毫秒。
  - **标注**（单独一层，跟着缩放重画）：每个弯的限速是一块**路边的限速牌**：牌杆从路边沿着弯道线的方向垂直伸出去，杆头一块白底红圈黑字的圆牌——
    弯道线顺着杆子指到牌子，不会对错弯，路面上也不压东西（原来是弯外一块盾牌，两个弯挨得近时被挤开，看不出哪个数字是哪个弯）。
    牌子默认立在弯外，弯外挨着别的赛道就立到弯里；挨得近的两个弯牌子叠上了，后一个先换到路的另一侧，再不行把杆子加长（每档缩放各算一次）。
    放大以后，弯道线外端旁边多一块小名牌写"T 几 + 弯名"（柳岸弯、梯坎发夹、灯塔发夹……，不写数字），被挤远了有一条短虚线连回弯道线；
    名牌在横屏、竖屏（转 90°）各算一套位置，不压赛道、不叠在一起（`test/mapart.test.ts` 检查）。路边每 5 格一个格号；
    弯道线前三格的**制动牌**写着 3、2、1，是"停在这格再跑几格就过弯道线"，不用自己数格子；**下一个弯**（自己的车前面最近的弯道线）的限速牌描一圈金边。
  - **分层显示**：手机全图时一个格子才十几像素，细节会糊成一片。所以缩放低于 0.7（屏幕上 1 个单位不到 0.7 像素）时只显示大件：
    赛道、限速牌（放大到屏幕上约 24 像素，杆子跟着加长）、棋子、起终点；放大以后才出现格号、制动牌、弯名。
  - **棋子**（`view/piece.ts`）：塑料小车，车身按座位配色（红、蓝、黄、绿、紫、橙），一块高光，车顶一个白圆牌写着座位号（红绿分不清的玩家看号码，号码不跟着车转），车下一片投影；
    自己的车外面一圈金边。名次栏里也是这枚棋子。
  - **竖屏转 90°**：三条赛道都是横的，竖屏舞台又高又窄，不转只占四成高。舞台高比宽多 15% 以上时整张图顺时针转 90°（`board.ts` 的 `layout`），
    限速牌、弯名牌、格号、制动牌、飘字转回正向，板子上边框不印标题（转到画面外了，顶栏有赛道名）；转屏时重画、重新烘焙。
  - **性能**：地图板开局在浏览器里烘焙成一张位图（透明底，桌面是页面背景；纹理先内联成 data URL），镜头平移缩放只挪这张图；标注、棋子、虚影、飘字照旧是矢量（约 200 个元素）。
    手机按 2 倍、电脑按 3 倍画（AGENTS.md"渲染倍数封顶 2"），画好前、失败时用矢量的。纸纹、斑驳用平铺纹理而不是实时的噪声滤镜：滤镜在手机上烘焙要多卡半秒多。
    实测（手机横屏、像素比 3、CPU 降速 4 倍）跟车拖动时一帧约 17 毫秒。
- **动画**：车沿格子一格一格走；冲刺带尾焰、吸尾流带风线、打滑转一圈退回；车上方飘字（速度、冲刺 +几、热量 −几、散热、打滑、名次）。
  系统"减少动态效果"时只做位移。单机顶栏"快 / 慢"调动画速度。
- **镜头**（`board.ts`）：方向固定，只平移缩放，不跟着车转（发夹弯里整张图转来转去会晕，也记不住在哪一段；实体桌游的板子也是不动的）。
  - 两种看法："跟车"（屏幕上 1 个单位约 1 像素，一格约 40 像素，车在画面偏后，往前多看几格）和"全图"。手机默认跟车，电脑默认全图；
  - 跟车时出牌：落点和路上要过的弯放不进画面就平滑缩小，框住我的车、落点和这些弯的限速牌；落点变近时等 0.7 秒再放大回去，不来回抖；
  - 亮牌移动：轮到我的车时镜头跟着走，别人的车在画面里就看得到，不追着跑；
  - 画面外的车在屏幕边上、它所在的方向显示一个小牌：颜色、号码、比我前后几格；
  - 拖动平移、双指或滚轮缩放以后不再自动动，下一回合恢复；镜头不跑出板子；系统"减少动态效果"时直接跳到位。
- **驾驶台**（`view/dash.ts`）：照一回合的顺序排，玩家一眼看出现在该做哪一步。
  - 最上面一条**步骤条**：1 挂挡 → 2 出牌 → 3 亮牌移动 → 4 冲刺·拼劲 → 5 尾流 → 6 过弯 → 7 弃牌·补牌。亮着的是现在这一步，轮到自己做的那一步是红的、一闪一闪；好友房右上角有倒计时。
  - 驾驶台是一张纸质的**玩家板**。左边印着半圆的**挡位盘**（现在的挡上放一枚红色塑料标记；能挂的挡描金圈，1、2 挡标着散热几张，跳两挡标"火苗 −1"）和**引擎热量**（一个火苗 × 张数，用光了火苗变灰）。
  - **热量一律用火焰表示**（`cards.ts` 的 `flameSvg`）：热量牌、引擎热量、名次栏、跳挡、过弯付热量的预览、赛道上付热量的飘字。
  - 中间是**出牌区和手牌**：挂几挡出牌区就有几个空位；点手牌放进出牌区，点出牌区的牌拿回手里；交了以后出牌区的牌盖着，亮牌以后翻开、标上这回合的速度。
    同一排右边是**牌堆区**（盖着的一摞，标着还剩几张）和**弃牌区**（翻开最上面一张，标着几张）：点弃牌区弹出这一场用过的牌（按种类统计 + 新的在前一张张列出来），点牌堆弹出还剩哪些牌（只有种类和张数）。
  - 右边只放**这一步要做的事**：
    - 1 挂挡：说这挡出几张、用手里的牌能跑几格、散热几张、跳挡付不付热量，挂好了点"挂好了，出牌 →"，手牌这时只看不能点；
    - 2 出牌：放满了就预览速度（有手抖时是范围）、过哪几个弯、要付几张热量、会不会打滑，赛道上画一辆虚影车（白 = 没事、黄 = 要付热量、红 = 会打滑）；
      下面是"后面几步"的预设（冲刺、拼劲、尾流、弃牌，2.7），"← 换挡"回到第 1 步；
    - 4–7：轮到自己回答时换成那一步的问题（冲刺？多走 1 格？吸尾流？弃哪几张？），别人在决定时写"等 某某 决定……"。
- **名次栏**（`view/side.ts`）：第几回合、领先的第几圈；每辆车的名次、颜色、名字、第几圈、挡位、引擎热量、这回合的速度或状态（✓ 选好了、… 在想、熄火、打滑、拼）。
  交计划是大家同时出牌：出完牌的那一行边框变绿（`row.ready`），还在想的不变，一眼看出还在等谁。单机里电脑交完计划也先刷新一次画面再等你。
  电脑的台词在这一行冒气泡。
- **卡面**（`view/cards.ts`）：印刷卡，卡纸纹理、墨线描边。速度牌顶上一条按点数配色的色带（点数越大越热），中间速度表（指针指着点数），下面大号数字；改装牌色带上写"改装"、卡边一圈金线；
  热量牌是红底上一台线描的引擎（红色气门室盖、空滤、皮带轮、排气管），火从缸体上面窜出来；手抖是紫底上两道轮胎拖痕加问号；牌背深绿底，细线框和"飞驰"。
- **页面**（`view/style.css`）：舞台是木桌面；顶栏深绿；选桌页、等人页、弹窗是一张摊在桌上的纸；名次栏是一列纸签（自己那行淡黄，出完牌的变绿）；
  主按钮是印刷的红色，硬边投影，按下去沉一下。
- 横屏为主（赛道左上、名次栏右上、驾驶台在下）；竖屏赛道在上、名次两列、驾驶台在下。
- iOS 那几条照 `AGENTS.md` 第 4 节做（高度按 `visualViewport`、双指放大时不重排、safe-area 兜底）；没有画布，"渲染倍数封顶 2""WebGL 上下文"不适用。
- 常驻"回大厅"（左上角），比赛中离开先确认一次（单机存着下次接着跑；新手教程不存，问一句；好友房车交给电脑）。
- **结算**（0.1.4，维护者的线上反馈）：
  - 冲线的动画放完以后再停约 1.2 秒才弹（看得到冲线，单机、好友房都一样）；系统"减少动态效果"时不等；
  - 不挡赛道中间：靠下边放（盖驾驶台，横屏赛道整个露着，竖屏盖名次栏和驾驶台），不压暗、不挡顶栏；右上角"收起，看看赛道"只剩一条"第几名 · 展开"；
  - 弹窗里有"大厅"，和顶栏的"大厅"走同一段代码（`main.ts` 的 `goHome`：好友房先离座，独立部署时回游戏首页）；
  - 结算开着时顶栏的"规则""离开"点得到：结算是压着的弹窗（`dialog.ts` 的 sticky），先开别的弹窗时藏着，那个关了再出来；驾驶台这时只看不点。

### 8.1 新手教程（0.1.4）

文案和流程是策划定的（`src/game/tutorial.ts`，改字先找策划），流程在 `src/tutor.ts`，气泡和高亮在 `src/view/coach.ts`。教练叫**阿驰**：爱吹牛、心肠好的老车手。

- **头像**（`view/coachart.ts`，设定图 `shots/coach-sheet.png`）：程序画的 SVG，和地图板同一套色板、三档墨线、平涂。红色老式半盔、推到额头上的铜框风镜、八字胡、大鼻头、金围巾，圆形徽章框（金圈里外两道墨线）。
  手机上只有 36–44 像素，所以一眼要认的（红盔、两只风镜、脸、胡子、眼睛和嘴的形状）画大、用主体墨线；盔上的白条、镜片反光、腮红、胡子里的花白放大才看得出，用装饰墨线。
  三个表情按文案挑（`coach.ts` 的 `MOODS`）：**平常**（睁眼、挑一边眉，讲解和操作）；**大笑**（眯眼、张嘴、胡子翘起来：开场吹牛、"冲吧车神"、冲刺尾流拼劲、交罚款那句俏皮话、毕业）；
  **哎哟**（瞪眼、八字眉、波浪嘴、一滴汗：打滑、熄火）。选桌页"新手教程"按钮左头也有一枚大笑的小头像（28 像素）。

- **入口**：选桌页标题旁一个金色的"新手教程"，一直在；没有 `racing.tutorial` 的人旁边冒一个气泡"第一次来？先跟阿驰跑一圈 →"（点气泡也进）。
  一进教程就记下 `racing.tutorial`：跑完、中途退出、关页面都算来过，以后不冒气泡。
- **怎么跑**：一场不存续玩的单机（`Solo` 的 `store = false`）：环湖、1 圈、3 辆车（我加两个新手电脑），写死的密钥（`TUTORIAL_KEY`），开局的手牌和位置每次一样。
  不碰 `racing.solo`（玩家正在跑的那场照样"接着上一场"）、`racing.prefs`（选项、预设）。
  教程里冲刺、尾流、拼劲一律"问我"、不显示预设小签（驾驶台的 `lockPresets`），好让这些提问都出现；弃牌只问第一次（冒提示），
  之后交计划时由 `tutor.plan` 改成"不弃"自动跳过（手里几乎总有能弃的牌，每回合都问太啰嗦，策划 2026-10-20 定）；电脑不催出牌。
- **密钥是挑过的**（用规则核心逐个试，`test/tutorial.test.ts` 锁住）：第一回合手里 1、3、3、4、4、4 加一张手抖（第 1 课有手抖牌可讲，第 3 课挂 2 挡有大牌可踩，第一段直道到不了弯）；
  我在最前面发车，照教程开不管冲不冲，第 1 回合问冲刺、弃牌（弃牌只问这一次），第 3 回合问拼劲、尾流；第一回合随便挑两张、冲不冲，42 种走法里 41 种前三回合能问到尾流和冲刺。
  规则或电脑改了这几条不成立，测试先报，再照 `game/tutorial.ts` 的注释重挑一把。
- **流程**：第 0–3 课在第一回合交计划时（开场、认车、看牌、手抖牌（手里有才讲）、挡位 → 挂 2 挡 → 点"挂好了" → 放满出牌区 → 看虚影车 → 点"出牌"）；
  第 4–6 课在第二回合开始时（大家怎么走、限速牌、引擎热量、制动牌、散热、放手开）；之后自由驾驶。
  第一回合走车时就可能被问冲刺、弃牌，所以情景提示从点了"出牌"起就开着（不等第 6 课），每种情况只冒第一次。
- **气泡的样子**：一张印刷的人物卡——纸面、2 像素墨边、硬边投影（和弹窗一样），头上一条色带印着"阿驰"和纸签样的"跳过教程"：讲解、提示是深绿（顶栏的绿），
  操作步是红（主按钮的红，"该你动手了"），毕业是金。头像徽章压在色带左头、往下伸进正文一行，正文绕开它。气泡贴着目标放时（64 以内、两边有对得上的一段）伸出一个小尖角指过去，离远了或斜对着不伸。
  高亮是一圈金边（里外两道墨线，和"我的车"、能挂的挡同一种金圈）一呼一吸地亮，四周按弹窗遮罩的颜色压暗。选桌页"第一次来？"是同一套纸签，尖角指着按钮。
- **三种气泡**：讲解步"下一步 →"、右上角"跳过教程"；操作步把要点的东西描一圈闪动的金边、周围压暗，别的点不了（舞台上捕获阶段拦掉点击、滚轮，顶栏和气泡除外），
  点对了由驾驶台的样子认出来自动往下走（"出牌"由 `planned()` 直接告诉）；情景提示带"知道了"。
  讲解和提示在单机的 `frame` 里等玩家点完才返回，所以讲的时候电脑也停着。
- **摆放**：每一帧按选择器找目标、量位置（驾驶台、赛道标注每一步都整个重画）；气泡先试目标的上下左右，再试目标连同要躲开的东西整块的上下，再试赛道上几处，
  挑第一个不压目标、不压 avoid 的；横屏、竖屏同一套算法（竖屏气泡宽一些、字大一点）。别的弹窗（确认、规则）开着时整个藏起来。系统"减少动态效果"时金边不闪。
  "①"不是每台手机的字体都有，画成和棋子车顶一样的白圆牌。
- **镜头**：讲到赛道上的东西镜头框过去（`board.ts` 的 `focus`：几个世界坐标的点、至少放大到多少，框着时不跟车、不跟预览）：认车框我的车，虚影车框车和虚影，
  限速牌框我前面最近的那块，制动牌放大到 1.1（低于 0.7 不画）；打滑、熄火、尾流的提示框我的车。讲完回到原来的看法。
- **毕业**：冲线以后照常停一会儿，阿驰的毕业气泡先冒出来，0.6 秒后结算在下边出来（只有"大厅"），气泡躲开结算：第一名"冠军！……"，别的名次"跑完了！……"，
  按钮"正式开跑"（回选桌）、"再练一次"（重跑教程）。
