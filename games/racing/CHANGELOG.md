# 飞驰（games/racing）更新日志

## 0.1.4（2026-10-20）

- 新手教程：选桌页多了一个"新手教程"按钮，头一回来的人旁边还会冒个气泡"第一次来？先跟阿驰跑一圈 →"。
  - 老车手阿驰带你在环湖跑一圈（你加两个新手电脑），开局的牌和位置每次一样：先认车、看牌，再一步步挂挡、出牌、看虚影车；
    第二回合讲弯道限速、引擎热量、制动牌和散热，之后你自己开，第一次碰到冲刺、尾流、拼劲、弃牌、交热量、打滑、熄火时，阿驰在旁边嘀咕两句（弃牌只问第一次，之后不再停下来问）；
  - 要你点的东西描一圈闪动的金边、四周压暗，别的暂时点不了；讲到赛道上的东西时镜头会移过去；随时能"跳过教程"；
  - 冲线以后阿驰给你颁个"毕业"，可以"正式开跑"或者"再练一次"；按钮一直在，想重玩就点；
  - 阿驰有了自己的头像：戴红色老式半盔、风镜推在额头上、一副八字胡，平常讲解一张脸，吹牛、毕业时大笑，打滑、熄火时"哎哟"；
    他的话印在一张人物卡上（讲解绿、要你动手时红、毕业金），贴着要看的东西时伸个小尖角指过去；
  - 教程不碰你正在跑的那场单机（"接着上一场"照样在），也不改你的预设和选项。
- 结算弹窗里多了"大厅"按钮，和左上角的"大厅"一样（原来弹窗把顶栏挡住了，回不去大厅）。
- 冲线以后先停一会儿再弹结算，看得到冲线；结算靠下边放，不再压暗、挡住赛道中间，还能"收起，看看赛道"，想看了再"展开"。
- 电脑的表情和说的话不再盖住名次栏里的车手名：横屏冒在那一行左边（原来横屏说的话被名次栏的边裁掉了，看不见）；手机竖屏说的话冒在名次栏上沿（带它的小车），表情缩到和那一行一样高、贴在那一行右头。

## 0.1.3（2026-10-19）

- 弯道限速一眼看清：每个弯的路边竖一块限速牌，牌杆从路边沿着弯道线垂直伸出去，杆头是白底红圈黑字的圆牌——顺着弯道线就找到牌子，不会对错弯，路面上不压东西
  （原来是弯外的盾牌，两个弯挨得近时被挤开，看不出哪个数字是哪个弯）。挨得近的两个弯，牌子分到路的两边或者杆子加长，不叠在一起。
  放大以后弯道线外端旁边多一块小名牌写弯名，不再重复写数字；你前面的下一个弯，限速牌描一圈金边。

## 0.1.2（2026-10-19）

- 换成桌游风格：整局像摆在木桌上的一盒实体桌游。
  - 赛道是一块印刷的地图板：每条赛道一个颜色的边框，印着赛道名和指北针；赛道是干净的深色路面，每 5 格一道白线，路边有格号；
    每个弯一块红色限速盾牌，下面写着弯名（柳岸弯、梯坎发夹、灯塔发夹……）；弯外印着缓冲区，主直道内侧有维修区；
  - 三条赛道各有场景：环湖是内场的大湖、湖心亭、九曲桥和小船；山城是有等高线的山、山顶的塔、梯坎和一格格的街坊；海港是海、靠岸的集装箱船和岸桥、灯塔、油罐和集装箱堆场；
  - 车是塑料棋子，车顶写着号码（红绿分不清也认得出），自己的车外面一圈金边；
  - 卡牌是印刷卡：速度牌带速度表，改装牌金线，热量牌是一台线描的燃烧的引擎，手抖牌是轮胎拖痕，牌背深绿；
  - 驾驶台是一张玩家板：挂挡是半圆的挡位盘上放一枚标记（原来的挡把会压住挡位数字），引擎热量是一个火苗 × 张数；名次栏是一列纸签，选桌页、弹窗是一张纸。
- 手机上的镜头：
  - 默认跟着自己的车（一格约 40 像素，车在画面偏后、往前多看几格），"全图"一键切换；电脑默认看全图；
  - 出牌时落点或要过的弯不在画面里，镜头自动缩小把它们框进来；车走的时候跟着自己的车；
  - 画面外的车在屏幕边上标出来：号码和比你前后几格；
  - 自己拖过、缩放过就不再自动动，下一回合恢复；
  - 缩得很小时只显示大件（赛道、限速盾牌、车），放大了才出现格号、制动牌和弯名，手机上不再糊成一片。
- 帮你看弯：弯道线前三格印着制动牌 3、2、1（停在这格再跑几格就过弯道线）；你前面的下一个弯，盾牌描一圈金边。
- 竖屏：赛道整张转 90°（横着的赛道在竖着的屏幕上原来只占四成高，现在竖着铺满，字照样是正的）；驾驶台按内容定高，出牌按钮不再被手牌盖住，剩下的高度都给赛道。
- 纹理从 11 张（144 KB）减到 4 张（约 21 KB）：木桌、卡纸、纸纹、斑驳。

## 0.1.1（2026-10-16）

- 驾驶台重画，照一回合的顺序排：
  - 上面一条步骤条（挂挡 → 出牌 → 亮牌移动 → 冲刺·拼劲 → 尾流 → 过弯 → 弃牌·补牌），亮着的是现在这一步，轮到你的那一步是红的；
  - 先在 H 形挡位箱上挂挡（能挂的挡亮黄圈，标着散热几张、跳挡要不要热量，右边说这挡能跑几格），点"挂好了"再出牌；
  - 出牌时点手牌放进出牌区（挂几挡几个空位），点出牌区的牌拿回来；放满了才预览落点和过弯；
  - 左边是自己的车台：挡位箱、引擎热量表、牌堆和弃牌堆；右边只放这一步要做的事。
- 整体换成写实风格：
  - 赛道：沥青路面和白色边线，红白路肩只铺在弯里，弯外是砂石缓冲区和轮胎墙，起终点的发车框，主直道外侧的看台；
  - 场景：环湖有沙岸、水面和小船，山城是各色楼顶，海港是集装箱码头和海面，处处有树；
  - 车换成俯视的方程式赛车，名次栏里也是各自颜色的小赛车；
  - 卡面换成卡纸质感：速度牌带速度表，改装牌金边，手抖牌是轮胎拖痕，牌背是碳纤维；
  - 热量牌是一台烧起来的引擎；别处的热量一律用火苗表示：引擎热量表是一排火苗（用掉的变灰），名次栏、跳挡、过弯付热量、赛道上付热量的飘字都带火苗；
  - 驾驶台是碳纤维底板，挡杆是跑车那种开放式金属挡位板（抛光铝、铣出来的 H 槽、螺丝、刻着挡位）加黑色球头挡把；
  - 选桌页的赛道小图和比赛里是同一套画法。
- 静止的赛道和场景开局时烘焙成一张图，跟车、拖动镜头时手机上也是满帧（4 倍降速时一帧约 17 毫秒，原来全是矢量时约 50 毫秒）。
- 驾驶台加了牌堆区和弃牌区：点弃牌区看这一场用过哪些牌，点牌堆看还剩哪些牌（只有种类和张数）。只能看自己的，别人照旧只看得到你弃牌堆最上面一张。
- 大家同时出牌时，右边名次栏里出完牌的那一行边框变绿，一眼看出还在等谁；单机里电脑出完牌也会马上变绿（原来要等亮牌才刷新）。
- 竖屏铺满细长的手机屏幕，不再上下各空一条黑边（多出来的高度给赛道）。

## 0.1.0（2026-10-16）

- 第一版：回合制卡牌赛车。换挡出牌、热量、过弯限速、打滑、熄火、冲刺、拼劲、尾流。
- 三条固定赛道：环湖（均衡）、山城（技术弯多）、海港（高速、急弯）；1–3 圈，2–6 辆车。
- 单机对电脑：七个性格分三档（新手：嘟嘟、慢半拍；普通：冲冲、跟屁虫、刹车王；老手：弯道王、精算师），新手场、普通场、老手场只派本档的，也可以混着来；
  每个电脑每场有自己的状态（冲劲、手感），这场冲、下场稳。跑到一半关了页面，回来接着跑。
- 出牌前在赛道上画一辆虚影车：落在哪、过哪几个弯、要付几张热量、会不会打滑；手抖牌按点数范围算。
- 冲刺、尾流、拼劲、弃牌可以出牌时预设好，轮到时不用再点。
- 赛道能拖动、缩放，一键"跟车"或看全图。
- 好友房：开房定好赛道和规则，叫朋友（分享链接、房间号），人不够电脑补位；掉线托管、中途接管电脑；跑完"再来一场"跟进新房间。
- 互动（单机和好友房都有）："聊"面板里说一句（可以点名）、表情包、扔道具；电脑按性格主动说话，被点名、被扔东西会回，单机里你想太久它会催；设置里有总开关和按人屏蔽。
- 不要平台也能单独部署（Deploy to Cloudflare 按钮或 `npm run deploy`）：游客打开就能玩，选桌页填昵称。
